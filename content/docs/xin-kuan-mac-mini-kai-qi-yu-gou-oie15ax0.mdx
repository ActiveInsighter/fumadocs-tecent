# 新款 Mac mini 开启预购

有，而且今天对中国大陆用户来说确实是一个关键节点：**新款 Mac mini 今天（2026 年 8 月 27 日）正式开始预购**。不过严格来说，它不是今天才发布的——Apple 是在 **8 月 25 日**正式发布这一代 Mac mini，今天上午 9 点才在中国大陆开放预购，**9 月 22 日正式发售**。([Apple (中国大陆) - 官方网站][1])

这次更新幅度挺大，Mac mini 现在分成 **M6** 和 **M5 Pro** 两条线：

| 项目            | 新款 Mac mini                           |
| ------------- | ------------------------------------- |
| 基础芯片          | **M6**                                |
| 高性能版          | **M5 Pro**                            |
| M6 CPU        | 12 核                                  |
| M6 GPU        | 12 核                                  |
| M6 标配内存       | 16GB                                  |
| M6 最大内存       | 32GB                                  |
| M5 Pro 最大 CPU | 18 核                                  |
| M5 Pro 最大 GPU | 20 核                                  |
| M5 Pro 最大内存   | 64GB                                  |
| 无线            | **Wi-Fi 7 + 蓝牙 6**                    |
| 有线网络          | 标配 **2.5GbE**，可选 10GbE                |
| 雷雳接口          | M6：Thunderbolt 4；M5 Pro：Thunderbolt 5 |
| 中国大陆上市        | 9 月 22 日                              |

Apple 表示，M6 版本相比上一代 M4，CPU 性能最高提升约 **40%**，图形性能最高约 **2 倍**，AI 性能最高约 **4 倍**；M6 的内存带宽也提升到了最高 **170GB/s**。([Apple][2])

### 但有个很重要的变化：涨价了

中国大陆官方价格目前是：

* **M6 Mac mini：¥6,999 起**
* 教育优惠：**¥6,199 起**
* **M5 Pro Mac mini：¥12,999 起**
* 教育优惠：**¥12,199 起**

([Apple (中国大陆) - 官方网站][3])

这意味着你之前问我的“**Mac mini 会不会出 M5/M6，以及苹果涨价会不会恢复**”这个问题，现在已经有答案了：

**Apple 直接跳过了普通 M5 Mac mini，基础款升级成了 M6；专业版则是 M5 Pro。**

而且价格并没有恢复到以前 M4 Mac mini 那种非常有杀伤力的价位，反而明显提高了。新款基础版官方就是 **¥6,999 起**。([Apple (中国大陆) - 官方网站][1])
