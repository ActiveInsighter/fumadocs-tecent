## 一、先建立1949—1956年的时间坐标

这一章如果没有时间线，非常容易把1949、1952、1953、1956几个节点混在一起。

| 时间             | 发生什么                   | 考试定位                        |
| -------------- | ---------------------- | --------------------------- |
| **1949年**      | 中华人民共和国成立              | 新民主主义革命取得基本胜利；开始新民主主义社会     |
| **1949—1952年** | 完成土地改革等民主革命遗留任务、恢复国民经济 | 仍以完成民主革命遗留任务、恢复经济为重点        |
| **1952年底以后**   | 土改基本完成，阶级关系和主要矛盾变化     | 工人阶级与资产阶级的矛盾逐步成为国内主要矛盾      |
| **1953年**      | 正式提出过渡时期总路线            | **一化三改**                    |
| **1953—1956年** | 工业化建设与社会主义改造同时进行       | “建设和改造同时并举”                 |
| **1956年底**     | 三大改造基本完成               | **社会主义基本制度确立，中国进入社会主义初级阶段** |

《史纲》的时间轴也明确把**1949—1956年划为过渡时期**；1956年三大改造基本完成以后，则进入社会主义初级阶段。

一个特别容易错的地方是：

**1949年 ≠ 中国已经进入社会主义社会。**

1949年的历史意义主要是新中国成立、新民主主义革命取得基本胜利，中国结束半殖民地半封建社会；而**1956年社会主义基本制度确立，才标志着我国从新民主主义社会转变为社会主义社会。**

## 二、新民主主义社会到底是什么社会？

这是第三章第一块，也是很多选择题的源头。

### 1. 它是“过渡性社会”，不是独立的社会形态

从中华人民共和国成立到社会主义改造基本完成，我国处于**从新民主主义向社会主义过渡的时期**。

教材特别强调：

**新民主主义社会是一个过渡性的社会形态，而不是一个独立的社会形态；它属于社会主义体系。**

这里有两个非常容易混淆的概念：

| 说法                 | 对错 |
| ------------------ | -- |
| 新民主主义社会已经是社会主义社会   | 错误  |
| 新民主主义社会属于资本主义体系    | 错误  |
| 新民主主义社会是独立的社会形态    | 错误  |
| 新民主主义社会是向社会主义过渡的社会 | 正确  |
| 新民主主义社会属于社会主义体系    | 正确  |

为什么？

因为新民主主义革命虽然还是**资产阶级民主主义性质的革命**，但它不是要建立资产阶级专政的资本主义共和国，而是在无产阶级及其政党领导下进行的，革命发展的方向明确指向社会主义。

这也正好接上第二章：

> **新民主主义革命是社会主义革命的必要准备，社会主义革命是新民主主义革命的必然趋势。**

两阶段之所以能够衔接，就是因为新民主主义革命内部已经包含社会主义因素。真题曾直接考过这一点。

所以可以把第二章和第三章连起来理解：

**第二章回答“怎样取得政权”**；
**第三章回答“取得政权以后怎样走向社会主义”。**

## 三、新民主主义社会为什么必然要“过渡”？

核心原因在它内部存在着不同性质的经济成分和阶级力量。

### 1. 五种经济成分

新民主主义社会并不是单一的公有制经济，而是多种经济成分并存。

教材重点可以整理成：

| 经济成分            | 性质、地位           | 发展方向               |
| --------------- | --------------- | ------------------ |
| **社会主义性质的国营经济** | 在国民经济中居**领导地位** | 社会主义               |
| **合作社经济**       | 过渡性经济           | 个体经济 → 集体经济        |
| **个体经济**        | 数量上占**绝对优势**    | 面临向社会主义还是资本主义发展的选择 |
| **私人资本主义经济**    | 资本主义性质          | 需要进行社会主义改造         |
| **国家资本主义经济**    | 过渡性经济           | 私人资本主义 → 社会主义国营经济  |

其中真正构成社会经济主体的三种基本经济成分是：

**社会主义经济、个体经济、资本主义经济。**

而合作社经济和国家资本主义经济，本身就是两种**过渡形式**。

#### 一个高频陷阱

教材同时说：

* **个体经济占绝对优势**
* **国营经济居领导地位**

二者并不矛盾。

“占绝对优势”主要说当时经济数量、人口覆盖等现实结构；广大农民、手工业者仍然是个体经营。

“领导地位”则说的是谁掌握**国家经济命脉和发展方向**。社会主义国营经济虽然数量没有压倒一切，却掌握重要工业、金融、交通等经济命脉，因此能够发挥领导作用。

所以：

> **数量最多的不等于领导力量。**

## 四、新民主主义社会的阶级结构与主要矛盾

当时主要存在四个阶级：

**工人阶级、农民阶级、城市小资产阶级、民族资产阶级。**

2012年考研政治曾直接把这四个作为多选题，答案是四项全选。

其中最需要理解的是民族资产阶级。

在社会主义革命时期，民族资产阶级仍然具有两面性：

一方面，它通过资本主义经营**剥削工人、获取利润**；

另一方面，在新的国家政权下，又具有**拥护中国共产党领导、拥护宪法、愿意接受社会主义改造**的一面。

这个“两面性”非常重要，因为后面为什么能够对民族资本主义实行**和平赎买**，就建立在这里。

## 五、主要矛盾是怎么变化的？

不能简单地说“1949年以后主要矛盾马上就是工人阶级和资产阶级”。

阶段要分开。

新中国成立初期，还需要继续完成土地改革、清除国民党残余势力、恢复经济等任务。

随着土地改革基本完成，到1952年底以后，民主革命遗留任务基本完成，国内阶级关系发生变化，于是：

> **社会主义和资本主义两条道路之间的矛盾，工人阶级和资产阶级两个阶级之间的矛盾，逐步成为国内主要矛盾。**

《政治考点》和《史纲》的时间线都特别强调了这一阶段变化。

这也意味着：

原来革命的重点是**反帝反封建**；

现在国家进一步面临的是：

> **究竟朝社会主义方向发展，还是朝资本主义方向发展？**

因此社会主义改造被提上日程。

## 六、党在过渡时期的总路线：“一化三改”

1953年，党正式提出过渡时期总路线。

最核心的概括只有四个字：

### **一化三改**

“一化”：

**逐步实现国家的社会主义工业化。**

“三改”：

**逐步实现国家对农业、手工业、资本主义工商业的社会主义改造。**

你一定不要把“一化”和“三改”当成四件互不相关的事。

实际上它们解决的是两个层次的问题：

| 内容       | 主要解决什么                   |
| -------- | ------------------------ |
| 社会主义工业化  | **发展生产力**，把落后的农业国建设成为工业国 |
| 三大社会主义改造 | **变革生产关系**，建立社会主义公有制经济基础 |

所以总路线体现的是：

> **发展生产力与变革生产关系相结合。**

也就是一边搞工业化建设，一边把旧的所有制关系逐步改造为社会主义所有制。

## 七、为什么后来改成“建设和改造同时并举”？

这一段是真题高频理解点。

最初的设想其实不是这样。

开始时曾设想：

**先搞工业化 → 工业化完成 → 再进行社会主义改造 → 一举过渡。**

后来逐渐认识到不能这样等。

新的思路变成：

**社会主义工业化建设与社会主义改造同时进行、逐步过渡。**

而实际历史结果也恰恰说明：

> **1956年社会主义改造已经基本完成，中国已经进入社会主义社会，但社会主义工业化远远没有完成。**

所以凡是选择题说：

“1956年三大改造完成意味着社会主义工业化已经完成”

一定是错的。

## 八、为什么当时已经具备向社会主义过渡的条件？

教材给出的现实依据主要有四方面。

| 现实条件                    | 为什么重要                       |
| ----------------------- | --------------------------- |
| **社会主义国营经济已经比较强大**      | 掌握国家经济命脉，为社会主义改造提供物质基础      |
| **农民有互助合作的要求和实践经验**     | 个体农业力量弱，互助合作能够克服困难、避免重新两极分化 |
| **资本主义工商业已经出现国家资本主义形式** | 已经可以通过国家控制、利用、限制逐步改造        |
| **国际形势有利**              | 为中国向社会主义过渡创造外部条件            |

尤其第二条很重要：

> **农业合作化不能坐等国家完成工业化、实现机械化以后才开始。**

老解放区的互助合作实践已经说明，即使机械化水平不高，也可以先在生产关系上逐步组织起来。

2010年真题就考过为什么从“先工业化再过渡”转变成“建设和改造同时并举”。

正确项包括：

* 社会主义经济因素不断增长；
* 对资本主义经济的限制不断加强；
* 要保证工业化发展的社会主义方向；
* 民主革命遗留任务基本完成。

而“我国工业化建设已经取得重大成就，因此才改造”并不是这一转变的正确理由。

## 九、三大改造之一：农业社会主义改造

这是三大改造中**首先进行**的，也是选择题最爱考“步骤和性质”的部分。

核心任务是：

> **把农民的个体所有制经济逐步改造成社会主义集体所有制经济。**

不是把农民土地简单“没收归国家”，而是通过**合作化道路**组织农民。

教材把农业社会主义改造概括得很完整。

### 农业改造的基本路线

| 项目       | 内容                       |
| -------- | ------------------------ |
| **道路**   | 积极引导农民组织起来，走互助合作道路       |
| **原则**   | **自愿互利、典型示范、国家帮助**       |
| **方针**   | **积极领导、稳步前进**            |
| **阶级政策** | 正确分析农村阶级阶层，依靠贫下中农，发展互助合作 |
| **方法**   | 逐步过渡、循序渐进                |

最重要的是下面三阶段。

### 1. 互助组

性质：

**社会主义萌芽性质。**

为什么只是“萌芽”？

因为农民仍然保留自己的生产资料和个体所有制，只是在生产劳动中进行一定程度的互助合作。

所以：

**互助组 ≠ 社会主义集体所有制已经建立。**

### 2. 初级农业生产合作社

性质：

**半社会主义性质。**

这是历年真题直接考过的结论。

2004年真题问：

“初级农业生产合作社属于什么性质？”

正确答案就是：

**半社会主义性质。**

### 3. 高级农业生产合作社

性质：

**社会主义性质。**

到了高级社，生产资料的集体所有制程度已经发生根本变化。

所以这一条链一定要重点记住：

> **互助组 → 初级社 → 高级社**
>
> **社会主义萌芽 → 半社会主义 → 社会主义**

这是第三章最典型的“按阶段判断性质”题。

## 十、农业改造为什么不能靠强制？

农业改造的关键原则是：

**自愿互利、典型示范、国家帮助。**

这个“自愿”极其重要。

农民刚刚经过土地改革获得土地，如果国家马上用行政命令强行把农民重新组织起来，就违背了农民意愿。

因此采取的是：

先让合作做得好的地方发挥示范作用
→ 农民看到合作能够提高抗灾和生产能力
→ 自愿参加
→ 国家给予帮助
→ 再逐步发展到更高级合作形式。

2011年考研多选考农业合作化经验，正确答案就是：

* 遵循自愿互利、典型示范和国家帮助；
* 土地改革后及时引导个体农民走互助合作道路；
* 从互助组到初级社再到高级社逐步过渡。

答案为 **BCD**。

## 十一、手工业社会主义改造

手工业的情况与农业很相似。

本来也是大量个体手工业者，因此基本方向同样是：

> **个体经济 → 合作化 → 集体经济。**

基本方针仍然是：

**积极领导、稳步前进。**

主要方法是：

**说服教育、典型示范、国家帮助。**

主要经历三个阶段：

| 阶段       | 性质变化     |
| -------- | -------- |
| 手工业供销小组  | 社会主义萌芽因素 |
| 手工业供销合作社 | 半社会主义性质  |
| 手工业生产合作社 | 社会主义性质   |

毛中特资料中第一步通常写作**“手工业供销小组”**。

你的《史纲》中特别提醒了一个教材交叉的小细节：史纲有的地方使用**“手工业生产合作小组”**这一提法，而毛中特通常写“手工业供销小组”，两个表述考试时都应认识。

这个属于非常适合出选择题的小细节。

## 十二、三大改造中最特殊的：资本主义工商业社会主义改造

前面两个是：

**个体经济 → 集体经济**

而资本主义工商业改造解决的是：

**资本主义私有制 → 社会主义公有制。**

它最有中国特色的地方，是没有简单照搬“直接剥夺资本家”的办法，而实行：

## **和平赎买**

2021年考研政治单选对此直接命题，答案就是**和平赎买政策**。

## 十三、什么叫“和平赎买”？

很多人一看到“赎买”，会理解成：

> 国家一次性拿一大笔钱，把资本家的工厂买下来。

这不准确。

教材解释：

> 所谓赎买，是国家**有偿地**将私营企业逐步改变为国营企业，把资本主义私有制改变为社会主义公有制。

但具体形式**并不是国家一次支付巨额补偿金**，而是在一定时期内允许资本家从企业经营所得中取得一定收益。

这就是后面“四马分肥”和“定股定息”的意义。

所以要区分：

**和平赎买 = 对民族资本主义工商业改造的基本政策和方法。**

## 十四、为什么中国能够实行和平赎买？

这是非常适合多选题的知识。

主要有四个现实条件：

| 条件                  | 含义                          |
| ------------------- | --------------------------- |
| 民族资产阶级具有两面性         | 既剥削工人，又有愿意接受共产党领导和社会主义改造的一面 |
| 中共和民族资产阶级长期存在统一战线关系 | 有历史合作基础                     |
| 已建立人民民主专政政权         | 国家具有政治力量                    |
| 社会主义国营经济掌握经济命脉      | 国家具有经济优势，同时还有统购统销、工人监督等条件   |

因此党可以不用大规模暴力冲突来解决民族资本问题，而是把资本家逐步纳入社会主义改造轨道。

这里还要和第二章区分：

**官僚资本**在新民主主义革命时期是革命对象，要**没收**；

**民族资本主义工商业**则是在社会主义改造时期采取**和平赎买**。

这是很经典的跨章节陷阱。

## 十五、和平赎买是“方法”，国家资本主义是“过渡形式”

这一组概念经常混。

记成：

> **怎么改？——和平赎买。**
>
> **通过什么经济形式改？——国家资本主义。**

国家资本主义经济，是在人民政府管理之下，以各种形式同社会主义国营经济发生联系，并受工人监督的资本主义经济。

它不是社会主义经济本身，却能够作为资本主义向社会主义过渡的桥梁。

## 十六、资本主义工商业改造的三个阶段

这一部分必须和农业“三阶段”并排记忆。

| 阶段      | 形式                              | 企业性质变化                    | 利润处理     |
| ------- | ------------------------------- | ------------------------- | -------- |
| **第一步** | 初级形式国家资本主义：委托加工、计划订货、统购包销、经销代销等 | 原资本主义企业性质尚未根本改变，但已有社会主义因素 | **四马分肥** |
| **第二步** | 个别企业公私合营                        | **半社会主义性质**               | **四马分肥** |
| **第三步** | 全行业公私合营                         | 基本成为**社会主义性质**企业          | **定股定息** |

教材对这三步的性质和形式有非常明确的区分。

## 十七、“四马分肥”到底是什么？

它是企业利润分配方式。

所谓“四马”，就是把企业利润大体分给四个方面：

**国家所得税 + 企业公积金 + 工人福利费 + 资方红利。**

考试最重要的不是记具体比例，而是记住：

> **四马分肥出现在初级国家资本主义以及个别企业公私合营阶段。**

2002年考研真题直接问：

“中国对资本主义工商业进行社会主义改造过程中，在利润分配上采取的政策是什么？”

答案就是：

**四马分肥。**

但注意：

“四马分肥”只是**利润分配办法**；

不能说：

“资本主义工商业社会主义改造的基本政策是四马分肥。”

基本政策是：

**和平赎买。**

## 十八、什么叫“定股定息”？

到了**全行业公私合营**阶段，情况已经不同。

企业生产资料基本归国家统一管理，企业已经基本具有社会主义性质。

国家对原资本家的私股进行核定，在一定时期按照核定股份支付固定利息，这就是：

**定股定息。**

因此最简单的记法是：

> 前两级：**四马分肥**
>
> 最高级：**定股定息**

《史纲》也详细说明，全行业公私合营后，企业基本已经成为社会主义性质经济。

## 十九、把三大改造放在一张表里

这是本章最值得背的一张表。

| 对象          | 原来的所有制  | 主要办法              | 主要过程                        | 最终方向    |
| ----------- | ------- | ----------------- | --------------------------- | ------- |
| **农业**      | 农民个体所有制 | 合作化               | 互助组 → 初级社 → 高级社             | 集体所有制   |
| **手工业**     | 个体所有制   | 合作化               | 供销小组 → 供销合作社 → 生产合作社        | 集体所有制   |
| **资本主义工商业** | 资本主义私有制 | **和平赎买**，通过国家资本主义 | 初级国家资本主义 → 个别公私合营 → 全行业公私合营 | 社会主义公有制 |

所以做题时看到：

“互助组” → 想农业；
“供销合作社” → 想手工业；
“国家资本主义” → 想资本主义工商业；
“和平赎买” → 民族资本主义工商业；
“四马分肥” → 国家资本主义前两个阶段；
“定股定息” → 全行业公私合营。

## 二十、社会主义改造的三条历史经验

教材高度概括成三条，属于非常标准的背诵题。

### 第一，坚持社会主义工业化建设与社会主义改造同时并举

不是：

先建设十几年
→ 再改造。

而是：

> **一边发展社会主义工业化，一边改变所有制结构。**

它体现了**发展生产力和变革生产关系相结合**。

### 第二，采取积极引导、逐步过渡的方式

农业不是直接：

个体农民 → 高级社；

而是：

互助组 → 初级社 → 高级社。

资本主义工商业也不是直接：

私人企业 → 国营企业；

而是：

初级国家资本主义 → 个别公私合营 → 全行业公私合营。

所以“逐步过渡”不是一句抽象口号，三大改造的具体制度设计本身就在体现它。

### 第三，用和平方法进行改造

农业、手工业主要通过：

**自愿合作、说服教育、示范帮助。**

民族资本主义工商业则通过：

**和平赎买。**

也就是说，中国社会主义改造一个突出特色就是尽可能减少激烈社会冲突，实现所有制关系的深刻改变。

## 二十一、为什么说社会主义改造是一个伟大的历史性胜利？

《精讲精练》特别强调了两个结果。

第一，在一个几亿人口的大国中完成如此复杂、深刻的社会变革，**没有造成生产力的大破坏，反而推动了工农业和整个国民经济的发展**。

第二，这样深刻的所有制变革**没有造成巨大社会动荡，反而加强了人民团结，并在广大人民拥护下完成**。

所以不能把社会主义改造简单理解为“换了所有制名称”。

它实际上同时涉及：

**经济结构、所有制、阶级关系、国家制度、社会性质**的根本变化。

## 二十二、1956年底到底发生了什么根本变化？

到1956年底，我国对：

**农业、手工业、资本主义工商业**

的社会主义改造基本完成。

最关键的经济结果是：

> **社会主义公有制已经成为我国社会的经济基础。**

这标志着：

> **社会主义基本制度在中国确立。**

教材甚至特别强调：

> **社会主义经济制度的建立，是我国进入社会主义社会最主要的标志。**

所以考试看到：

“我国进入社会主义社会最主要的标志是什么？”

不要答：

新中国成立；

不要答：

第一届全国人大；

不要答：

一五计划完成；

应该抓住：

**社会主义经济制度建立 / 三大改造基本完成 / 社会主义公有制成为经济基础。**

## 二十三、政治制度也在同步确立

社会主义基本制度不只有经济制度。

1954年9月：

**第一届全国人民代表大会召开，《中华人民共和国宪法》制定和颁布。**

社会主义政治制度体系逐步建立，包括：

**人民代表大会制度**——根本政治制度；

以及中国共产党领导的多党合作和政治协商制度、民族区域自治制度等基本政治制度。

所以第三章的制度确立可以理解为三个层次：

| 层面       | 根本变化           |
| -------- | -------------- |
| **经济**   | 社会主义公有制成为经济基础  |
| **政治**   | 社会主义基本政治制度建立   |
| **阶级关系** | 劳动人民成为国家和社会的主人 |

最终：

**我国由新民主主义国家转变为社会主义国家。**

## 二十四、1956年以后中国进入什么阶段？

答案：

## **社会主义初级阶段**

这是一个特别重要的时间分界。

> **1949—1956：新民主主义社会、过渡时期**
>
> **1956以后：社会主义社会，处于社会主义初级阶段**

这里又有一个典型陷阱：

“社会主义初级阶段”不是：

**新民主主义向社会主义过渡的阶段。**

过渡阶段到1956年基本结束。

社会主义初级阶段是：

> **我国已经进入社会主义社会以后，由于生产力水平仍比较落后而必须长期经历的社会主义发展阶段。**

因此：

**过渡时期 ≠ 社会主义初级阶段。**

## 二十五、新民主主义社会和社会主义初级阶段为什么容易混？

因为二者都存在**多种经济成分**。

但性质完全不同。

| 对比   | 新民主主义社会   | 社会主义初级阶段        |
| ---- | --------- | --------------- |
| 时间   | 1949—1956 | 1956以后          |
| 社会性质 | 过渡性社会     | 社会主义社会          |
| 公有制  | 尚未占主体     | 已成为经济基础、占主体     |
| 个体经济 | 占绝对优势     | 不再是社会经济主体       |
| 发展任务 | 完成向社会主义过渡 | 在社会主义制度基础上发展生产力 |

《精讲精练》专门提醒：不能因为两者都允许多种所有制经济，就认为性质一样。

## 二十六、社会主义基本制度确立的重大意义

这一块既可出多选，也非常适合作为分析题背景。

教材可以归纳成五层意义：

第一，这是**中国历史上最深刻最伟大的社会变革之一**，我国进入社会主义初级阶段，为当代中国一切发展进步奠定了重要制度基础。

第二，社会主义制度极大调动了广大劳动人民的积极性，为社会生产力发展开辟了广阔道路。

第三，我国社会阶级关系发生根本变化，广大劳动人民真正成为国家主人。

第四，这是世界社会主义发展史上的重大胜利，对世界政治经济格局产生重要影响。

第五，它以中国自己的实践经验**丰富和发展了科学社会主义理论。**

2013年考研政治多选就考过：

社会主义基本制度确立的意义包括：

A. 中国历史上最深刻最伟大的社会变革
B. 为当代中国发展进步奠定根本政治前提和制度基础
D. 使广大劳动人民真正成为国家主人

正确为 **ABD**。

而：

“标志着马克思主义同中国实际第二次结合已经完成”

是错误的。

为什么？因为1956年以后恰恰才开始进一步探索“怎样建设社会主义”，第四章要讲的就是这个问题。

## 二十七、本章和第四章是怎样接起来的？

第三章解决：

> **社会主义制度怎么建立？**

1956年底以后制度建立了，但一个更难的问题来了：

> **在一个经济文化比较落后的东方大国，社会主义究竟应该怎样建设？**

于是进入第四章：

**社会主义建设道路初步探索的理论成果。**

毛泽东开始提出把马克思列宁主义基本原理同中国社会主义建设具体实际进行“第二次结合”，探索适合中国国情的社会主义建设道路。

所以毛泽东思想前四章其实是一条连续历史线：

**第一章：毛泽东思想是什么**
→ **第二章：怎样革命、夺取政权**
→ **第三章：怎样从新民主主义过渡到社会主义**
→ **第四章：社会主义制度建立以后怎样建设社会主义**

理解这条线，比单独背每个章节容易得多。

## 二十八、本章真题最喜欢怎样设坑？

| 命题点       | 正确结论                   | 常见错误          |
| --------- | ---------------------- | ------------- |
| 新民主主义社会性质 | 过渡性社会，属于社会主义体系         | 已经是社会主义社会     |
| 经济领导力量    | 国营经济                   | 个体经济          |
| 数量上占优势    | 个体经济                   | 国营经济          |
| 一化三改      | 工业化 + 农业、手工业、资本主义工商业改造 | 把工业化算入“三改”    |
| 农业改造原则    | 自愿互利、典型示范、国家帮助         | 强制集体化         |
| 初级农业合作社   | 半社会主义性质                | 社会主义萌芽或完全社会主义 |
| 工商业改造政策   | 和平赎买                   | 没收、剥夺         |
| 工商业过渡形式   | 国家资本主义                 | 合作社经济         |
| 前期利润分配    | 四马分肥                   | 定股定息          |
| 全行业公私合营   | 定股定息                   | 四马分肥始终不变      |
| 1956年     | 社会主义基本制度确立             | 工业化已经完成       |
| 1956以后    | 社会主义初级阶段               | 仍是新民主主义社会     |

## 二十九、典型真题快速判断

### 1. 2017年单选

“过渡时期，个体经济向社会主义集体经济过渡的形式是？”

答案：

**合作社经济。**

因为：

个体经济
→ 合作社经济
→ 社会主义集体经济。

### 2. 2021年单选

“我国对资本主义工商业社会主义改造采取什么政策？”

答案：

**和平赎买。**

不要选“互助合作”，互助合作主要对应农业、手工业。

### 3. 2004年单选

“初级农业生产合作社是什么性质？”

答案：

**半社会主义性质。**

口诀式理解：

互助组——萌芽；
初级社——半；
高级社——社会主义。

### 4. 2020年单选

“1956年社会主义基本制度全面确立标志着中国进入什么历史阶段？”

答案：

**开始全面建设社会主义的历史阶段。**

不是：

“半殖民地半封建社会结束”——这是1949年的历史结果；

也不是：

“社会主义工业化已经完成”——1956年工业化还远未完成。

## 三十、最后把整章压缩成一条“考试逻辑链”

如果考前只剩一分钟，本章至少要能复述下面这一段：

> **1949年中华人民共和国成立以后，我国进入由新民主主义向社会主义过渡的新民主主义社会。新民主主义社会是过渡性社会，不是独立社会形态，属于社会主义体系。当时社会主义经济、个体经济和资本主义经济并存，国营经济居领导地位，而个体经济占绝对优势。土地改革基本完成以后，社会主义道路和资本主义道路、工人阶级和资产阶级之间的矛盾逐步成为国内主要矛盾。1953年党正式提出过渡时期总路线，概括为“一化三改”，即逐步实现社会主义工业化，并逐步实现对农业、手工业和资本主义工商业的社会主义改造。农业和手工业主要走合作化道路；资本主义工商业采取和平赎买政策，通过从低级到高级的国家资本主义形式逐步改造。社会主义改造坚持工业化建设与改造同时并举，采取积极引导、逐步过渡和和平改造的方法。1956年底三大改造基本完成，社会主义公有制成为我国社会经济基础，社会主义基本制度确立，我国由新民主主义社会进入社会主义社会和社会主义初级阶段。**

如果从**做选择题**的角度再压缩，本章最值得死记的就是这四组：

**1949—1956：过渡时期；1956以后：社会主义初级阶段。**

**一化：社会主义工业化；三改：农业、手工业、资本主义工商业。**

**农业：互助组萌芽 → 初级社半社会主义 → 高级社社会主义。**

**资本主义工商业：和平赎买 + 国家资本主义；前期四马分肥 → 全行业公私合营定股定息。**

把这四组和“1956年社会主义基本制度确立”连起来，第三章绝大多数选择题的骨架就已经掌握了。
