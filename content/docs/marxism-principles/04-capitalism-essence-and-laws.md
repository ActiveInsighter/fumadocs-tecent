## 一、先把第四章的整条逻辑链看懂

这一章看起来概念特别多，其实马克思是在回答一个核心问题：

> **资本家的利润究竟从哪里来？资本主义为什么一方面能迅速发展生产力，另一方面又必然产生贫富分化、失业和经济危机？**

整章可以压缩成这样一条逻辑链：

**商品 → 价值 → 劳动 → 货币 → 劳动力商品 → 资本 → 剩余价值 → 资本积累 → 利润 → 经济危机 → 资本主义基本矛盾**

也就是：

商品为什么能够交换
→ 因为有价值；

价值从哪里来
→ 抽象劳动；

价值多少怎么决定
→ 社会必要劳动时间；

货币为什么会变成资本
→ 买到了特殊商品“劳动力”；

劳动力为什么特殊
→ 它能创造出比自身价值更大的价值；

多出来的价值是什么
→ 剩余价值；

资本家为什么不断扩大生产
→ 为了获取更多剩余价值；

为什么出现技术进步、机器换人
→ 资本家追求剩余价值和竞争；

为什么又产生失业、贫富分化和经济危机
→ 资本积累及资本主义基本矛盾发展的结果。

所以不要把第四章学成几十个孤立定义。

## 二、第一部分：商品经济和劳动价值论

这是第四章的理论地基，对应《精讲精练》考点60—67。

### 1. 商品经济为什么会产生？

商品经济，就是**以交换为目的而进行生产的经济形式**。

它产生必须同时具备两个条件：

| 条件               | 含义                       |
| ---------------- | ------------------------ |
| 社会分工             | 不同的人生产不同的东西，因此需要交换       |
| 生产资料和劳动产品属于不同所有者 | 产品归不同主体支配，必须通过交换才能取得别人产品 |

这两个条件缺一不可。

最容易出的陷阱是把“有社会分工”直接等同于“必然有商品经济”。不够，还要求产品属于不同所有者。

资本主义以前已经存在商品经济，但只是**简单商品经济**，主要建立在**生产资料私有制和个体劳动**基础上；到了资本主义社会，商品经济才成为普遍经济形式。2024年真题就直接考过这一点。

## 三、商品为什么有“使用价值”和“价值”？

商品必须同时具有两个因素：

| 商品二因素 | 含义                | 本质   |
| ----- | ----------------- | ---- |
| 使用价值  | 能满足某种需要的有用性       | 自然属性 |
| 价值    | 凝结在商品中的无差别的一般人类劳动 | 社会属性 |

### 1. 使用价值

比如一瓶矿泉水能解渴，一台电脑能写代码。

这些都是使用价值。

使用价值反映的是：

**人与自然之间的关系。**

而且使用价值并不是商品独有的。

例如你自己种菜自己吃，这些菜有使用价值，但并不是商品。

因此：

> **有使用价值 ≠ 一定有价值 ≠ 一定是商品。**

商品还必须是：

**劳动产品 + 用于交换。**

2025年真题已经围绕“劳动产品但不是商品”进行了考查。

### 2. 价值

价值的定义非常重要：

> **价值是凝结在商品中的无差别的一般人类劳动。**

这里的“无差别”，后面其实就是**抽象劳动**。

比如生产一件衣服和生产一本书，具体劳动完全不同：

裁剪、缝纫；

写作、排版、印刷。

为什么仍然能够交换？

因为把具体劳动形式抽掉以后，它们都是人的脑力和体力耗费。

所以不同商品能够进行数量比较的共同基础是：

**价值。**

而价值背后实际上表现的是：

> **商品生产者之间的社会关系。**

马克思正是从“商品之间的交换关系”进入到“人与人的生产关系”。

历年真题也特别喜欢这一层。2012年真题就考过：价值是凝结在商品中的一般人类劳动，并在本质上体现生产者之间的社会关系。

## 四、使用价值、价值、交换价值到底是什么关系？

这是很容易混的一组。

核心关系是：

| 概念   | 关系            |
| ---- | ------------- |
| 使用价值 | 价值、交换价值的物质承担者 |
| 价值   | 交换价值的基础       |
| 交换价值 | 价值的表现形式       |

比如一台电脑卖6000元。

电脑能办公、娱乐，是使用价值；

生产电脑耗费的人类劳动形成价值；

“6000元”则表现为它同货币交换的数量关系。

因此不要说：

“交换价值决定价值。”

方向反了。

应该是：

> **价值决定交换价值，交换价值表现价值。**

## 五、商品的使用价值和价值为什么又“统一又对立”？

商品必须同时具有使用价值和价值，这是**统一性**。

但对于一次具体交换而言，使用价值和价值又不能被同一个主体同时占有。

例如你卖一台电脑。

你作为卖家：

放弃电脑的**使用价值**，

获得6000元，实现电脑的**价值**。

买家则反过来：

放弃货币所代表的价值，

得到电脑的使用价值。

所以：

> **商品使用价值和价值的矛盾，要通过商品交换来解决。**

这一句话后面还会和“私人劳动—社会劳动”的矛盾联系起来。

## 六、劳动二重性：第四章第一大核心

商品具有二因素，原因是什么？

马克思进一步发现：

> **生产商品的劳动本身具有二重性：具体劳动和抽象劳动。**

这是马克思劳动价值论最核心的内容之一。

| 劳动   | 作用     | 属性      |
| ---- | ------ | ------- |
| 具体劳动 | 创造使用价值 | 劳动的自然属性 |
| 抽象劳动 | 形成价值   | 劳动的社会属性 |

例如程序员写程序。

从“写代码这种具体形式”来看，是具体劳动；

把程序员、厨师、工人各种劳动的具体形式全部抽掉，仅仅看成脑力体力支出，就是抽象劳动。

因此可以形成一个极其重要的对应：

**具体劳动 → 使用价值**

**抽象劳动 → 价值**

于是：

> **劳动二重性决定商品二因素。**

这也是为什么马克思把劳动二重性理论称为理解政治经济学的枢纽。

## 七、一个超高频陷阱：劳动是不是财富的唯一源泉？

不是。

这是考研政治经常挖坑的地方。

要区分三句话：

| 问什么       | 正确答案      |
| --------- | --------- |
| 价值的唯一源泉   | 抽象劳动      |
| 使用价值的源泉   | 具体劳动和自然物质 |
| 剩余价值的唯一源泉 | 雇佣工人的剩余劳动 |

所以：

**劳动并不是社会财富的唯一源泉。**

因为自然界也参与使用价值的形成。

但是：

**抽象劳动是价值的唯一源泉。**

## 八、商品价值量到底由什么决定？

这里开始进入第四章的计算和推理重点。

商品价值量最终由：

> **社会必要劳动时间**

决定。

不是某一家企业实际用了多少时间。

例如全社会正常情况下生产一双鞋需要2小时。

A企业需要3小时；

B企业需要1小时。

商品不会因为A企业效率低，就按3小时的价值出售。

市场认可的是社会正常条件下所需要的劳动时间。

教材定义是：

> 在现有社会正常生产条件下，在社会平均劳动熟练程度和劳动强度下，生产某种使用价值所需要的劳动时间。

## 九、价值量和劳动生产率：几乎年年都能变形考

最重要关系：

\[
\text{单位商品价值量}
\propto
\text{社会必要劳动时间}
\]

而：

\[
\text{单位商品价值量}
\propto
\frac{1}{\text{劳动生产率}}
\]

所以：

**劳动生产率越高 → 单位商品价值越低。**

但是有个非常容易做错的地方：

假设原来1小时生产10件，每件价值1单位。

那么总价值：

\[
10\times1=10
\]

现在劳动生产率翻倍，1小时生产20件。

单件价值变成：

\[
\frac{10}{20}=0.5
\]

总价值仍然：

\[
20\times0.5=10
\]

所以最重要的四个关系是：

| 劳动生产率提高          | 变化 |
| ---------------- | -: |
| 单位时间商品数量         | 增加 |
| 单位时间使用价值量        | 增加 |
| 单件商品价值量          | 减少 |
| 同一劳动、同样时间创造的价值总量 | 不变 |

2023年真题就是直接围绕马克思这句话命题的：生产力改变时，同一劳动在同样时间提供的价值量不变，但使用价值数量改变。

## 十、简单劳动和复杂劳动

商品价值量最终统一以**简单劳动**为尺度。

复杂劳动可以理解成：

> 多倍的简单劳动。

如果一个受过专业训练的劳动者1小时形成的价值相当于普通简单劳动3小时，那么这种复杂劳动就相当于3倍简单劳动。

因此，相同劳动时间内：

**复杂劳动创造的价值量可以大于简单劳动。**

这个倍数不是哪个人自己算出来的，而是在商品交换过程中自发形成。

## 十一、货币是怎么来的？

价值形式经历了：

**简单价值形式 → 扩大价值形式 → 一般价值形式 → 货币形式。**

货币的本质：

> **固定充当一般等价物的商品。**

因此货币不是人主观“发明”出来的，它是商品交换长期发展的结果。

货币最终把商品世界分成两极：

一边是各种具体商品；

另一边是代表一般价值的货币。

## 十二、货币的五种职能一定要区分

这是经典选择题区。

| 职能   | 判断方法            |
| ---- | --------------- |
| 价值尺度 | 给商品标价           |
| 流通手段 | 一手交钱，一手交货       |
| 贮藏手段 | 货币退出流通并储存       |
| 支付手段 | 钱货在时间上分离，如赊账、还债 |
| 世界货币 | 在世界市场发挥作用       |

两个最基本职能是：

> **价值尺度 + 流通手段。**

例如：

“苹果10元一斤”——价值尺度。

你现场付10元拿走苹果——流通手段。

你今天拿货，下个月付款——支付手段。

2022年真题给出的“卖者成为债权人，买者成为债务人”，答案就是**支付手段**。

## 十三、价值规律：商品经济最基本的规律

价值规律内容只有两层：

第一，商品价值量由**社会必要劳动时间**决定。

第二，商品交换以价值量为基础，实行**等价交换**。

可以概括成：

> **生产看社会必要劳动时间，交换看等价交换。**

但现实中为什么商品价格天天波动？

因为供求发生变化。

所以在普通商品经济中：

> **价格围绕价值上下波动。**

并不是价格永远等于价值。

长期看，它以价值为中心。

后面资本主义发展以后，还会出现：

平均利润形成后：

**价格围绕生产价格波动。**

垄断阶段：

**价格围绕垄断价格波动。**

这并不是价值规律消失，而是价值规律的**表现形式变化**。

## 十四、价值规律有什么作用？

价值规律通过市场竞争自发发挥作用，主要体现为：

**调节资源配置、刺激生产力发展、调节收入分配。**

但由于是“自发调节”，也可能带来：

资源浪费；

技术封锁或阻碍技术共享；

贫富分化。

这里要理解一个核心：

> 市场中的生产者会围绕社会必要劳动时间竞争。

假如社会必要劳动时间2小时，你只需要1小时生产商品，那么：

你的**个别价值低于社会价值**，

你就会获得额外收益。

后面这个逻辑直接变成：

**超额剩余价值。**

## 十五、私人劳动和社会劳动：商品经济的基本矛盾

这是考研中特别容易把三组矛盾混起来的地方。

商品经济中有三组关系：

商品层面：

**使用价值 ↔ 价值**

劳动层面：

**具体劳动 ↔ 抽象劳动**

更深层的生产关系层面：

**私人劳动 ↔ 社会劳动**

其中最根本的是：

> **私人劳动和社会劳动的矛盾，是以私有制为基础的商品经济的基本矛盾。**

为什么？

生产资料归私人所有，所以每个人自己决定生产什么，这体现为私人劳动。

可是社会存在分工，每个人生产的商品必须满足社会需要，所以劳动又必须成为社会总劳动的一部分。

于是产生问题：

“我自己决定生产出来的东西，社会到底承不承认？”

怎么判断？

**卖出去。**

所以非常重要：

> **交换是解决私人劳动和社会劳动矛盾的唯一途径。**

商品成功出售：

私人劳动得到社会承认；

私人劳动转化为社会劳动；

具体劳动还原为抽象劳动；

商品价值实现；

使用价值与价值矛盾解决。

2019年真题直接考过：私有制商品经济的基本矛盾就是**私人劳动和社会劳动的矛盾**。

## 十六、从商品经济到资本主义：最关键的一次转折

前面还是一般商品经济。

现在问题出现：

假设资本家手里有100万元。

如果只是：

100万元 → 买商品 → 再卖100万元，

没有任何意义。

资本的运动真正追求的是：

\[
G\rightarrow W\rightarrow G'
\]

其中：

\[
G'=G+\Delta G
\]

多出来的：

\[
\Delta G
\]

究竟从哪里来？

这就是马克思政治经济学真正进入资本主义生产秘密的地方。

答案不是机器自己创造的；

不是流通中互相欺骗出来的；

而是因为市场上出现了一种非常特殊的商品：

> **劳动力商品。**

## 十七、资本主义是怎样产生的？

资本主义生产关系主要有两个历史来源：

**小商品生产者分化；商人和高利贷者转化。**

而资本主义迅速发展的重要历史过程是：

> **资本原始积累。**

资本原始积累不是“资本家努力省钱”。

而是：

> **以暴力手段使生产者与生产资料相分离，使资本迅速集中到少数人手中的历史过程。**

主要手段：

剥夺农民土地；

掠夺货币财富。

2017年真题考过，其中“暴力剥夺农民土地”和“殖民掠夺”属于正确项。

## 十八、劳动力为什么能够成为商品？

劳动力成为商品必须有两个条件。

第一：

劳动者在人身上是自由的，可以出售自己的劳动力。

第二：

劳动者没有生产资料和生活资料，因此不得不出售劳动力。

可以很好记成：

> **自由 + 一无所有。**

这两点共同构成资本主义雇佣劳动制度的前提。

劳动力成为商品，标志着简单商品生产发展到资本主义商品生产的新阶段，也是**货币转化为资本的前提**。背诵资料同样将这一点作为必须掌握的核心。

## 十九、劳动力商品的价值

普通商品有价值，劳动力商品同样有价值。

劳动力价值归根到底由维持和再生产劳动力所必需的生活资料价值决定。

主要包括：

劳动者本人生活；

劳动者家庭成员生存；

劳动者教育和训练费用。

为什么家庭成员也算？

因为资本主义生产需要劳动力能够代际延续。

为什么教育训练算？

因为具备一定技能的劳动力不是天然形成的。

## 二十、整个第四章最关键一句：劳动力使用价值的特殊性

普通商品使用后可能就消耗掉。

但劳动力商品的使用就是：

**劳动。**

劳动能创造新价值。

而且资本家购买劳动力后，可以让劳动者创造出：

> **超过劳动力自身价值的新价值。**

这就是劳动力商品最特殊的地方：

> **劳动力商品的使用价值是价值的源泉，而且能够创造比自身价值更大的价值。**

因此：

**劳动力成为商品，是货币转化为资本的前提。**

2010年真题对此直接命题，关键就是“购买的劳动力能够带来剩余价值”。

## 二十一、到底什么是资本？

不要把“钱”直接等于资本。

货币只有能够带来剩余价值时才成为资本。

资本定义是：

> **能够带来剩余价值的价值。**

进一步说：

> **资本不是物，而是一种体现在物上的资本主义生产关系。**

一台机器本身并天然是资本。

如果我自己买机器供自己劳动使用，它只是生产工具。

但当资本家占有机器、购买劳动力、依靠雇佣劳动获得剩余价值以后，机器才作为资本的一部分发挥作用。

肖1000相关题目也专门用“纺纱机为什么成为资本”来考这一点，正确理解就是因为资本家购买到劳动力这一特殊商品，由此能够实现价值增殖。

## 二十二、剩余价值是怎样生产出来的？

现在来到整章最重要的理论——**剩余价值理论**。

资本主义生产过程具有二重性：

> **劳动过程 + 价值增殖过程。**

劳动过程解决：

“生产出有用的商品。”

价值增殖过程解决：

“资本家为什么能得到更多价值。”

真正体现资本主义本质的是第二个。

## 二十三、必要劳动和剩余劳动

假设一个工人每天工作8小时。

假设他每天劳动力的价值相当于400元。

而他4小时就能创造400元的新价值。

于是前4小时：

用于补偿自己的劳动力价值。

叫：

> **必要劳动时间。**

剩下4小时仍然继续劳动。

这部分价值资本家没有额外付工资。

于是叫：

> **剩余劳动时间。**

因此：

\[
\text{工作日}
=
\text{必要劳动时间}
+
\text{剩余劳动时间}
\]

剩余价值就是：

> **雇佣工人在剩余劳动时间创造、被资本家无偿占有的超过劳动力价值的价值。**

所以需要记住：

> **雇佣工人的剩余劳动，是剩余价值的唯一源泉。**

## 二十四、不变资本和可变资本

假设资本家投入：

机器、厂房、原材料80万元；

购买劳动力20万元。

马克思不是按“机器/人”简单划分，而是按照：

> **资本各部分在剩余价值生产中的作用**

划分。

### 不变资本

符号：

\[
c
\]

用于购买生产资料。

生产资料原有价值只是转移到新商品中。

例如一台机器价值10万元，可以生产10000件产品，那么它的价值逐步进入这些产品。

但机器本身不会多创造出第100001元。

所以：

> 不变资本只转移价值，不发生价值增殖。

### 可变资本

符号：

\[
v
\]

用于购买劳动力。

工人的劳动能够重新创造自身劳动力价值，同时还能创造剩余价值。

所以这部分价值发生增殖，叫：

> **可变资本。**

因此：

> **剩余价值不是全部资本创造的，而是由可变资本所购买的劳动力创造的。**

## 二十五、剩余价值率怎么计算？

剩余价值符号：

\[
m
\]

剩余价值率：

\[
m'=\frac{m}{v}
\]

它还可以写成：

\[
m'
=
\frac{\text{剩余劳动时间}}
{\text{必要劳动时间}}
\]

所以剩余价值率反映：

> **资本家对工人的剥削程度。**

例如2016年真题：

资本总额100万，生产结束变120万。

所以：

\[
m=120-100=20
\]

购买劳动力：

\[
v=10
\]

所以：

\[
m'=\frac{20}{10}=200\%
\]

答案就是200%。这一真题在现有资料里明确列在考点70下。

注意：

绝对不能用：

\[
\frac{20}{100}
\]

因为那算的是利润率思路，而不是剩余价值率。

## 二十六、绝对剩余价值

假设：

原来工作8小时：

必要劳动4小时；

剩余劳动4小时。

现在延长到10小时，而必要劳动时间仍然4小时。

那么剩余劳动变成6小时。

这就是：

> **绝对剩余价值生产。**

核心：

> **必要劳动时间不变，延长工作日。**

此外：

**提高劳动强度**

在本质上也等于延长劳动时间，所以也属于绝对剩余价值方法。

可以记：

> 绝对剩余价值 = “直接多干”。

## 二十七、相对剩余价值

现在假设工作日仍然8小时。

原来：

4小时必要劳动 + 4小时剩余劳动。

由于全社会劳动生产率提高，生活资料便宜了，劳动力价值下降。

工人只需要3小时就能再生产劳动力价值。

那么：

3小时必要劳动 + 5小时剩余劳动。

工作日没增加，但剩余劳动增加了。

这就是：

> **相对剩余价值。**

所以：

> 相对剩余价值 = 工作日不变，通过缩短必要劳动时间，相对延长剩余劳动时间。

怎么缩短必要劳动时间？

关键不是某一个资本家提高效率。

而是：

> **全社会劳动生产率提高。**

## 二十八、超额剩余价值

这是三种剩余价值最容易混的一种。

假设全行业生产一件商品需要2小时。

某企业新上机器，只需要1小时。

市场仍按照社会价值出售。

于是：

**个别价值 小于 社会价值。**

这之间的差额就是：

> **超额剩余价值。**

因此：

| 类型     | 核心            |
| ------ | ------------- |
| 绝对剩余价值 | 延长工作日或提高劳动强度  |
| 相对剩余价值 | 全社会劳动生产率提高    |
| 超额剩余价值 | 个别企业劳动生产率率先提高 |

为什么相对剩余价值最终会出现？

因为每个资本家都想获得**超额剩余价值**。

大家都升级技术以后：

个别技术 → 普及成社会技术；

全社会劳动生产率提高；

生活资料价值下降；

劳动力价值下降；

必要劳动时间缩短；

最终整个资本家阶级获得：

> **相对剩余价值。**

这是第四章最漂亮的一条逻辑链。

## 二十九、机器人和AI会不会创造剩余价值？

按照教材中的理论：

**不会成为独立的剩余价值源泉。**

机器人、自动化生产线、“无人工厂”仍属于生产资料，即物化劳动的形式。

归入：

\[
c
\]

也就是不变资本。

它们只把自身已有价值逐步转移到产品，而不是创造新价值。

所以：

> **自动化改变了生产剩余价值的技术手段，但没有改变剩余价值的源泉。**

剩余价值的唯一源泉仍然是：

> **雇佣劳动者的剩余劳动。**

教材和肖1000都专门提醒，这是机器、AI题目的核心陷阱。

## 三十、为什么资本主义又能推动生产力高速发展？

既然资本主义具有剥削性，为什么历史上又极大促进了生产力？

因为存在两股力量：

> **追逐剩余价值的内在动力 + 市场竞争的外在压力。**

资本家为了超额剩余价值，要：

更新技术；

改善管理；

提升劳动生产率；

降低成本。

其他资本家为了不被淘汰，也只能跟进。

所以资本主义追求剩余价值，主观目的是利润，却客观推动了技术和生产力发展。

2022年真题就直接以《共产党宣言》有关资本主义巨大生产力的论述考查这一点。

## 三十一、资本积累

资本家得到剩余价值后可以有两种情况。

全部拿去自己消费：

生产规模不变。

叫：

> **简单再生产。**

把一部分剩余价值重新投入生产：

购买更多机器；

购买更多劳动力；

扩大生产规模。

这叫：

> **扩大再生产。**

把剩余价值重新变成资本，就是：

> **资本积累。**

因此这两组“源泉”一定区别：

> **剩余价值是资本积累的源泉。**

> **资本积累是资本主义扩大再生产的源泉。**

这也是背诵资料专门要求区分的一组表述。

## 三十二、资本积累的本质

资本积累不是简单的“企业把利润拿来投资”。

教材强调它在资本主义关系中的本质：

> **资本家利用无偿占有的剩余价值扩大自己的资本规模，从而进一步扩大和加强对雇佣劳动者的剥削和统治。**

所以：

剩余价值 → 再资本化 → 更多资本 → 雇佣更多劳动 / 改进技术 → 生产更多剩余价值。

形成不断扩大的循环。

## 三十三、资本积累规模由什么决定？

主要看四个因素：

| 因素          | 越高时        |
| ----------- | ---------- |
| 对工人剥削程度     | 可积累剩余价值越多  |
| 劳动生产率       | 越高越有利于积累   |
| 所用资本与所费资本差额 | 越大越有利      |
| 预付资本规模      | 越大通常积累能力越强 |

2018年真题直接把四项一起考过。

## 三十四、资本技术构成、价值构成、有机构成

这是第四章最容易做错的概念之一。

### 资本技术构成

看实物比例：

> **生产资料数量 : 劳动力数量**

例如原来：

10台机器配10个人。

后来：

100台机器配10个人。

技术构成提高。

### 资本价值构成

换成价值看：

> **不变资本 : 可变资本**

即：

\[
c:v
\]

### 资本有机构成

定义必须准确：

> **由资本技术构成决定并反映资本技术构成变化的资本价值构成。**

所以：

\[
\text{资本有机构成}=c:v
\]

但是不是所有价值构成变化都是有机构成变化。

例如：

机器数量完全不变，只是机器市场价格突然上涨。

此时：

资本价值构成变了；

技术构成没变；

因此这种价值构成变化不能单纯归因于资本有机构成提高。

这正是2021年服装厂“机器换人 + 原材料价格下降”真题的考查逻辑。

## 三十五、为什么资本有机构成会提高？

资本主义的直接目的：

**剩余价值。**

资本家为了竞争和取得更多剩余价值，会：

采用机器；

提高技术；

提高生产效率。

于是每个工人推动的生产资料越来越多。

表现为：

\[
\frac{c}{v}\uparrow
\]

也就是：

> **资本有机构成提高。**

这被教材作为资本主义发展的一般趋势。

## 三十六、为什么资本主义会产生失业？

这就自然接上了。

随着：

\[
\frac{c}{v}\uparrow
\]

意味着相对于资本总量而言：

购买生产资料的资本越来越多；

购买劳动力的资本比例越来越小。

资本对劳动力的需求增长慢于资本增长。

于是产生：

> **相对过剩人口。**

“相对过剩”不是社会真的完全不需要这些人。

而是：

> **这些劳动力相对于资本价值增殖的需要而言过剩。**

这句话是选择题核心。

主要有三种：

**流动的、潜在的、停滞的相对过剩人口。**

> **“浅停留”——潜、停、流。**

## 三十七、资本积聚和资本集中

这两个也很容易混。

资本积聚：

> **靠自身剩余价值资本化把一个资本做大。**

比如原来100万资本，今年利润20万，再拿10万追加投资，变110万。

资本集中：

> **多个已有资本合并成为大资本。**

比如企业并购。

两大杠杆是：

> **竞争和信用。**

因此：

**积聚 = 自己长大。**

**集中 = 合并长大。**

## 三十八、资本积累最终会导致什么？

教材主要指出：

资本积累导致：

**财富两极分化；**

**相对过剩人口；**

**资本主义基本矛盾进一步尖锐化。**

最后使：

> **资本主义制度被更适应社会化生产的社会形态所代替具有历史必然性。**

这就把第四章与第三章的生产力—生产关系规律连接起来了。

## 三十九、资本循环：钱不是放着就能增殖

产业资本需要经历三个阶段：

| 阶段         | 资本形式 |
| ---------- | ---- |
| 购买生产资料和劳动力 | 货币资本 |
| 实际生产       | 生产资本 |
| 出售商品       | 商品资本 |

简化理解：

**钱 → 机器和工人 → 商品 → 更多的钱。**

资本只有运动起来才能实现价值增殖。

## 四十、资本连续循环的两个条件

三个形式必须：

> **空间上并存。**

也就是一家正常企业必须同时：

有现金；

有正在生产的机器原料；

有等待出售的商品。

还必须：

> **时间上继起。**

购买以后进入生产；

生产以后进入销售；

销售后再进入新一轮购买。

所以记：

> **空间并存，时间继起。**

2020年真题就直接考产业资本在空间上同时存在的形式：

货币资本、生产资本、商品资本。

## 四十一、资本循环和资本周转有什么区别？

**循环**强调完成一次：

从一个形式出发再回到原来形式。

**周转**强调：

这种循环周而复始地不断进行。

如果资本周转越快，一年能够循环越多次，在每轮剩余价值一定的情况下，全年得到的剩余价值就越多。

## 四十二、资本周转速度受什么影响？

两个关键因素：

第一：

**资本周转时间。**

周转时间越短：

周转越快。

第二：

**固定资本和流动资本的比例。**

固定资本占比越高：

一般整个资本周转更慢。

流动资本占比越高：

一般整个资本周转更快。

## 四十三、这里又出现一套资本分类，别和c、v混了

同一笔资本可以按照不同标准分类。

| 分类标准        | 分类                 |
| ----------- | ------------------ |
| 在剩余价值生产中的作用 | 不变资本 / 可变资本        |
| 在资本循环中的职能   | 货币资本 / 生产资本 / 商品资本 |
| 价值周转方式      | 固定资本 / 流动资本        |

例如机器：

在第一种分类里：

**不变资本。**

在第三种分类里：

**固定资本。**

原材料：

第一种分类：

**不变资本。**

第三种分类：

**流动资本。**

工资即购买劳动力：

第一种分类：

**可变资本。**

第三种分类：

**流动资本。**

所以：

> **不变资本 ≠ 固定资本。**

这是经典陷阱。

## 四十四、社会总资本再生产

现在马克思从“一个企业”扩大到“整个社会”。

社会总产品价值构成：

\[
c+v+m
\]

其中：

\[
c=\text{不变资本转移价值}
\]

\[
v=\text{劳动力价值}
\]

\[
m=\text{剩余价值}
\]

从实物用途看，社会生产分为两大部类：

第一部类：

> **生产生产资料。**

第二部类：

> **生产消费资料。**

## 四十五、社会再生产的核心问题是什么？

这是必须直接背下来的K：

> **社会总产品的实现问题。**

所谓实现有两方面：

> **价值补偿 + 实物补偿。**

举例：

一个钢铁厂卖掉钢材，收回投入的钱，是价值补偿。

同时下一轮生产还需要重新买矿石、机器、能源等，是实物补偿。

整个社会只有两大部类保持合理比例，才能使两种补偿顺利完成。

所以社会再生产顺利进行要求：

> **两大部类之间以及各自内部保持适当比例关系。**

背诵版资料对此也进行了专门总结。

## 四十六、资本主义工资的本质

工资表面上看：

> 工人劳动8小时，资本家付你工资。

于是很容易产生错觉：

“工资就是劳动的价格。”

马克思认为这只是**表现形式**。

工资的本质是：

> **劳动力的价值或价格。**

为什么不能说“劳动的价格”？

因为劳动是在资本家购买劳动力以后才发生。

市场上出售的是：

**劳动力。**

而不是已经发生的劳动。

因此工资表现为整个劳动的报酬，就把：

必要劳动；

剩余劳动

掩盖起来了。

于是资本主义剥削关系具有隐蔽性。

2012年真题就直接问“资本主义工资的本质”，正确答案就是劳动力的价值或价格。

## 四十七、剩余价值为什么会“变成”利润？

假设：

\[
c=80
\]

\[
v=20
\]

工人创造：

\[
m=20
\]

实际上这20来源于可变资本所购买劳动力的剩余劳动。

但是资本家不会认为：

“我的20万元利润是工人创造的。”

他看到的是：

“我总共投100万元，赚20万元。”

于是剩余价值表现为：

> **全部预付资本的增殖额。**

这样：

**剩余价值转化为利润。**

因此：

> **剩余价值是利润的本质。**

> **利润是剩余价值的转化形式。**

这个转化进一步掩盖资本主义剥削关系。

## 四十八、剩余价值率和利润率一定要会区别

剩余价值率：

\[
m'=\frac{m}{v}
\]

利润率：

\[
p'=\frac{m}{c+v}
\]

因为：

\[
c+v>v
\]

所以一般有：

\[
p'<m'
\]

含义也不同：

| 指标    | 反映什么        |
| ----- | ----------- |
| 剩余价值率 | 资本家对工人的剥削程度 |
| 利润率   | 全部预付资本的增殖程度 |

例如：

\[
c=80,\quad v=20,\quad m=20
\]

则：

\[
m'=\frac{20}{20}=100\%
\]

利润率：

\[
p'=\frac{20}{80+20}=20\%
\]

所以利润率表面上把所有资本都看成利润来源，进一步掩盖剩余价值的真正源泉。

## 四十九、平均利润为什么出现？

不同部门资本有机构成不同。

有些部门利润率高，有些低。

资本的特点是逐利。

于是资本从：

低利润率行业 → 高利润率行业。

资本大量进入高利润率行业后：

供给增加；

利润率下降。

低利润率行业资本流出后：

供给减少；

利润率上升。

不断竞争以后，各部门利润率趋于平均。

于是形成：

> **平均利润率。**

资本家最终按照：

> **等量资本获得等量利润**

的原则瓜分全社会剩余价值。

## 五十、平均利润最重要的政治经济学意义

这说明一个企业资本家的利润，不一定完全等于这个企业工人创造的剩余价值。

例如：

A部门创造100剩余价值；

B部门创造200剩余价值。

通过部门间竞争，最后可能分别获得150平均利润。

那么A部门资本家就获得了其他部门劳动者创造的一部分剩余价值。

因此：

> **整个资产阶级共同瓜分整个工人阶级创造的剩余价值。**

所以资本家之间虽然在瓜分剩余价值时存在竞争，但：

> **在加强对工人阶级的剥削问题上具有共同阶级利益。**

2019、2023年真题都围绕利润率平均化和平均利润进行了考查。

## 五十一、生产价格

平均利润形成以后，商品的价格基础也发生变化。

生产价格：

\[
\text{生产价格}
=
\text{生产成本}
+
\text{平均利润}
\]

于是商品市场价格不再单纯：

围绕价值上下波动，

而是：

> **围绕生产价格上下波动。**

但是千万别选：

“价值规律失效了。”

没有。

生产价格只是：

> **价值的转化形式。**

价值规律作用形式发生了变化。

## 五十二、一道经典计算题：生产价格

2017年真题：

生产资料价值：

\[
15
\]

工资：

\[
5
\]

预付资本：

\[
15+5=20
\]

平均利润率：

\[
10\%
\]

平均利润：

\[
20\times10\%=2
\]

于是生产价格：

\[
20+2=22
\]

答案是22万元。题目就在真题资料第四章平均利润部分。

## 五十三、为什么剩余价值理论如此重要？

> **马克思经济学说的核心内容和基石。**

它主要完成了三件事：

揭示资本主义剥削的本质；

说明资产阶级与无产阶级斗争的经济根源；

说明无产阶级革命的历史必然性。

所以马克思的两大发现：

> **唯物史观 + 剩余价值学说**

使社会主义：

> **从空想变成科学。**

你的肖1000解析也明确把剩余价值理论称为马克思经济学说的核心内容和基石。

## 五十四、资本主义基本矛盾：整章最后的总解释

前面所有问题最后都归结到这个矛盾：

> **生产社会化和生产资料资本主义私人占有之间的矛盾。**

这是：

> **资本主义基本矛盾。**

可以和前面三个“基本”区分：

| 问题      | 基本矛盾               |
| ------- | ------------------ |
| 商品自身    | 使用价值与价值            |
| 私有制商品经济 | 私人劳动与社会劳动          |
| 资本主义社会  | 生产社会化与生产资料资本主义私人占有 |

其中最后一个，是资本主义制度层面的根本矛盾。

## 五十五、什么叫生产社会化？

现代生产越来越不是孤立个人完成。

例如一部手机：

设计；

芯片；

屏幕；

操作系统；

组装；

运输；

销售；

供应链；

金融服务

可能横跨几十个国家、几千家企业。

整个生产过程高度：

**社会化、协作化、全球化。**

但是生产资料以及生产成果，却主要服从资本所有者私人增殖的需要。

于是：

生产越来越社会化；

占有却仍然具有资本主义私人性质。

矛盾不断发展。

## 五十六、资本主义经济危机的本质是什么？

这是绝对高频：

> **生产相对过剩。**

注意是：

**相对过剩。**

不是生产出来的商品超过所有人的实际需要。

而是：

> **超过劳动人民有支付能力的需求。**

比如仓库堆满食品。

同时仍然有人吃不起。

这不是食品相对于人的生理需要过剩。

而是：

食品相对于**有支付能力的市场需求**过剩。

所以叫：

> **相对过剩。**

## 五十七、经济危机的根本原因

答案必须写：

> **资本主义基本矛盾。**

也就是：

> **生产社会化和生产资料资本主义私人占有之间的矛盾。**

这个基本矛盾具体表现成两方面。

一方面：

> **生产无限扩大的趋势，与劳动人民有支付能力的需求相对缩小之间的矛盾。**

另一方面：

> **单个企业生产的有组织性，与整个社会生产的无政府状态之间的矛盾。**

企业内部高度计划：

今年生产多少；

采购多少原料；

安排多少员工。

但是社会总体上各个私人资本家独立决策。

所以整个社会并没有一个统一的生产协调机制。

最终可能造成结构性失衡和生产过剩。

2016年真题引用马克思关于“群众贫穷和群众消费受到限制”的话，考的就是这套逻辑。

## 五十八、为什么经济危机会周期性发生？

因为：

> **资本主义基本矛盾运动具有阶段性。**

典型周期：

**危机 → 萧条 → 复苏 → 高涨 → 新危机**

其中：

> **危机是资本主义再生产周期的基本阶段，也是必经阶段。**

资本主义再生产不一定每一次都机械经历完全相同的四阶段，但只要资本主义基本矛盾存在，危机仍存在客观基础。

## 五十九、一个非常深的理解：危机也是强制恢复比例的方式

前面讲社会再生产时说：

两大部类必须保持适当比例。

但是资本主义生产具有盲目性。

于是比例不断失衡。

最后爆发危机：

企业破产；

商品降价；

生产缩减；

资本淘汰；

库存清理。

结果供给重新缩小，社会比例暂时得到调整。

因此教材有一句非常值得理解的话：

> **经济危机实际上是资本主义条件下以强制方式解决社会再生产实现问题的途径。**

但这种“解决”以：

失业；

企业倒闭；

生产停滞；

财富浪费

为巨大代价。

而且只解决暂时失衡，并没有消灭资本主义基本矛盾，所以以后还会再次出现危机。

## 六十、资本主义政治制度

前面主要分析经济基础。

最后教材继续分析资本主义上层建筑。

资本主义国家职能主要包括：

对内：

政治统治 + 社会管理；

对外：

国际交往、国家安全和利益维护。

但根本性质是：

> **资本主义国家是资产阶级进行阶级统治的工具。**

资本主义政治制度包括：

法律制度；

政权组织形式；

选举制度；

政党制度等。

其本质仍然服从资本主义经济基础和资产阶级统治需要。

## 六十一、为什么又必须承认资本主义政治制度有历史进步性？

考研政治不会简单地说资本主义政治制度“一无是处”。

教材要求辩证评价。

相对于封建专制制度，它曾发挥明显历史进步作用：

促进资本主义生产方式发展和生产力进步；

扩大了人们相对于封建时代的政治自由；

积累了政治治理和社会管理经验。

但是它同时具有阶级局限性。

现有资料将主要局限概括为：

**金钱操纵的民主；**

**法律形式平等掩盖事实不平等；**

**政党制度服务资产阶级统治；**

**政党恶斗和相互掣肘影响决策效率。**

所以这类题目的正确态度通常是：

> **既承认资本主义民主政治相对于封建制度的历史进步性，又看到其资产阶级阶级本质和历史局限性。**

## 六十二、资本主义意识形态

资本主义上层建筑可以分成：

政治上层建筑；

观念上层建筑。

资本主义意识形态属于：

> **观念上层建筑。**

它是为资本主义经济基础服务的。

从阶级实质上看：

> **资本主义意识形态是资产阶级阶级意识的集中体现。**

这里其实是在和第三章“经济基础—上层建筑”原理衔接。

第四章并不是突然出现一个新理论，而是在具体分析：

> 资本主义生产关系形成怎样的政治制度和意识形态。

## 六十三、第四章最重要的五条因果链

这部分建议你真正理解，而不是死背。

#### 第一条：劳动价值论

**商品 → 使用价值/价值 → 具体劳动/抽象劳动 → 社会必要劳动时间 → 价值规律**

核心回答：

> **商品价值究竟是什么、怎么来的、多少怎么决定。**

#### 第二条：剩余价值理论

**劳动力成为商品 → 劳动力使用价值特殊 → 必要劳动/剩余劳动 → 剩余价值**

核心回答：

> **利润最深层的来源是什么。**

#### 第三条：技术进步

**追逐超额剩余价值 → 个别企业提高生产率 → 全社会提高生产率 → 劳动力价值下降 → 必要劳动时间缩短 → 相对剩余价值增加**

这条特别容易出综合题。

#### 第四条：资本积累和失业

**剩余价值 → 资本积累 → 技术升级 → 资本有机构成提高 → 对劳动力需求相对减少 → 相对过剩人口**

解释资本主义条件下失业问题。

#### 第五条：经济危机

**资本积累 → 生产社会化不断提高 → 私人资本占有 → 基本矛盾尖锐化 → 社会生产比例失调 → 相对生产过剩 → 经济危机**

这条是整个第四章的终点。

| 抽象劳动        | 形成价值                  |

| 利润          | 剩余价值的转化形式             |

## 六十五、第四章的公式实际上并不多

考研里真正需要熟练的主要是以下几个。

商品总价值可以从资本主义生产角度表示成：

\[
W=c+v+m
\]

剩余价值率：

\[
m'=\frac{m}{v}
\]

也可表示为：

\[
m'=
\frac{\text{剩余劳动时间}}
{\text{必要劳动时间}}
\]

利润率：

\[
p'=\frac{m}{c+v}
\]

因此通常：

\[
p'<m'
\]

生产价格：

\[
\text{生产价格}
=
\text{生产成本}
+
\text{平均利润}
\]

资本有机构成：

\[
c:v
\]

掌握这些以后，第四章大多数计算题实际上不难，真正难的是**题目到底让你算哪一个概念**。

## 六十六、从真题看，第四章到底喜欢怎么考？

真题资料显示，近年第四章命题非常稳定，反复集中在这些位置：

2024年考**商品经济的产生条件和简单商品经济基础**；

2023年考**劳动生产率与商品价值量、平均利润**；

2022年考**货币支付手段、资本追逐剩余价值与生产力发展**；

2021年考**资本技术构成、价值构成、有机构成**；

2019年考**私人劳动与社会劳动、利润率平均化**；

2017年考**资本原始积累、生产价格**；

2016年考**剩余价值率、经济危机**。

这说明第四章复习不能只背定义，尤其需要重点理解：

**劳动生产率题、剩余价值题、资本构成题、平均利润题、经济危机题。**

## 六十七、最后一个“考研版”整章理解

如果只用一段话理解第四章，可以这样想：

人类存在社会分工和不同所有者，于是产生商品交换；商品具有使用价值和价值，生产商品的具体劳动创造使用价值，抽象劳动形成价值，而商品价值量由社会必要劳动时间决定，整个商品经济受价值规律支配。随着资本主义产生，劳动者虽然获得人身自由，却与生产资料相分离，只能出售劳动力。劳动力成为一种特殊商品，因为它在使用过程中能够创造比自身价值更大的价值，于是货币转化为资本。工人在必要劳动时间再生产劳动力价值，在剩余劳动时间创造被资本家无偿占有的剩余价值。资本家为了获得更多剩余价值，通过延长劳动时间、提高劳动强度和提高劳动生产率获取绝对、相对和超额剩余价值，并把一部分剩余价值重新资本化形成资本积累。资本积累推动技术进步和资本有机构成提高，同时形成相对过剩人口和财富两极分化。资本不断循环、周转，并通过社会再生产实现价值补偿和实物补偿；剩余价值又在表面上转化为利润，经过部门竞争转化为平均利润，价值进而转化为生产价格。随着资本主义发展，生产越来越社会化，而生产资料仍由资本主义私人占有，这一基本矛盾不断尖锐化，周期性表现为以生产相对过剩为本质特征的经济危机。资本主义政治制度和意识形态则建立在这一经济基础之上。

把这一整段真正理解以后，**第四章就不再是“几十个名词”，而是一个从“商品为什么能交换”一直推演到“资本主义为什么发生经济危机”的完整理论体系。**

其中最值得你现在优先吃透的其实只有四块：**劳动价值量及生产率、剩余价值三种形式、资本有机构成与失业、平均利润与生产价格**。这四块也是第四章最容易因为“似懂非懂”而丢选择题分数的地方。
