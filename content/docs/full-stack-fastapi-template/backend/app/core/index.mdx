## 设计原则

- **集中配置**：上层模块只依赖 `settings`，不直接到处读取环境变量。
- **单一引擎**：数据库引擎在进程内集中创建，会话则按请求产生和释放。
- **安全封装**：路由不直接操作哈希算法或 JWT 库，而调用稳定的安全函数。
- **依赖向下**：Core 不知道具体路由细节，减少耦合和循环导入。
