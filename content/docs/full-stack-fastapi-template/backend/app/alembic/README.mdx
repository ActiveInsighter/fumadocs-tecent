<Callout title="文件定位">

该文件来自 Alembic 初始化模板，声明当前目录采用 **generic single-database configuration**：一套迁移版本链对应一个主要数据库连接。

</Callout>

## 这意味着什么

- `env.py` 每次从应用配置中取得一个 PostgreSQL URL。
- 所有 revision 共享同一份 `SQLModel.metadata`。
- `versions/` 中的 `down_revision` 形成一条主要迁移链。
- 如果未来需要同时迁移多个独立数据库，必须扩展环境配置，而不是简单复制脚本。
