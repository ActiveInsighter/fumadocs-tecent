## 路由设计检查表

- 使用 `prefix` 和 `tags` 形成清晰的 URL 与 OpenAPI 分组。
- 使用 `response_model` 限制对外字段，避免泄露密码哈希等内部数据。
- 在访问对象前同时检查“对象是否存在”和“当前用户是否有权限”。
- 事务修改后执行 `commit()`；需要返回数据库生成字段时再 `refresh()`。
- 对登录、找回密码等接口避免泄露“邮箱是否存在”之类的敏感信息。
