## 请求处理分层

```mermaid
flowchart LR
  Router[路由函数] --> SessionDep[SessionDep]
  Router --> CurrentUser[CurrentUser]
  CurrentUser --> OAuth[OAuth2 Bearer Token]
  OAuth --> JWT[JWT 解码]
  JWT --> User[(查询 User)]
  Router --> Response[响应模型序列化]
```

<Callout type="idea" title="依赖注入的价值">

路由函数只声明自己需要什么，FastAPI 负责创建数据库会话、提取令牌、验证用户并把结果传入函数。这样权限和资源释放逻辑能被复用与测试。

</Callout>
