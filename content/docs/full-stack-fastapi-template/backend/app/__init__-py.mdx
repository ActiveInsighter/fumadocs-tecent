<Callout type="idea" title="文件定位">

这个文件本身不承载业务逻辑，它的主要价值是明确 `app` 是后端应用的顶层 Python 包。保持为空可以避免导入 `app` 时意外连接数据库、加载路由或执行初始化任务。

</Callout>

## 它为什么可以是空文件

- Python 在导入 `app.main`、`app.models` 等模块时，会先识别 `app` 包。
- 显式保留 `__init__.py` 能让编辑器、测试工具和不同 Python 版本更稳定地识别包边界。
- 不在这里集中导入全部子模块，可以降低循环依赖和启动副作用的风险。

<Callout type="warn" title="不要把启动逻辑放在这里">

数据库迁移、初始数据创建和服务探活应由独立脚本完成。否则任何 `import app` 都可能触发耗时或不可逆操作。

</Callout>
