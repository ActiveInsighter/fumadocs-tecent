## 依赖方向

```mermaid
flowchart TD
  Main[main.py] --> ApiMain[api/main.py]
  ApiMain --> Routes[api/routes/*]
  Routes --> Deps[api/deps.py]
  Routes --> Crud[crud.py]
  Deps --> Core[core/*]
  Crud --> Security[core/security.py]
  Routes --> Models[models.py]
  Crud --> Models
  Core --> Settings[core/config.py]
```

<Callout type="warn" title="避免循环依赖">

基础设施层应尽量位于依赖图下方。模型不应反向导入路由，核心配置也不应依赖具体业务接口。

</Callout>
