## 一次请求的完整路径

```mermaid
sequenceDiagram
  participant C as 客户端
  participant F as FastAPI 路由
  participant D as deps.py
  participant R as CRUD / 路由逻辑
  participant S as SQLModel Session
  participant P as PostgreSQL
  C->>F: HTTP 请求 + Bearer Token
  F->>D: 解析依赖
  D->>D: 验证 JWT 与用户状态
  D->>S: 获取数据库会话
  F->>R: 执行业务逻辑
  R->>S: 查询 / 修改模型
  S->>P: SQL
  P-->>C: JSON 响应
```
