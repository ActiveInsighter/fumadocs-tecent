<Callout type="idea" title="包边界">

`tests.api` 是测试代码的 Python 包。这个 `__init__.py` 刻意保持为空，只负责稳定包识别与导入路径，不在导入阶段执行测试准备、数据库连接或 fixture 注册。

</Callout>

## 为什么保留空文件

- 明确该目录是可导入的 Python 包，便于 Pytest、编辑器和静态分析工具解析绝对导入。
- 避免把共享 fixture 隐藏在包初始化中；共享 fixture 应放在 `conftest.py`。
- 避免导入测试包时产生数据库写入、网络请求或环境变量修改等副作用。
