<Callout type="idea" title="目录定位">

启动前探活脚本本质上是基础设施胶水代码。测试目标不是再次证明 PostgreSQL 能执行 `SELECT 1`，而是证明脚本正确创建 Session、执行查询并在成功时退出。

</Callout>

## Mock 边界

```mermaid
flowchart LR
  Test --> Patch[patch Session]
  Patch --> FakeSession[MagicMock 上下文管理器]
  Script[init(engine)] --> FakeSession
  FakeSession --> Assert[断言 exec 被调用]
```
