## 如何组织

```mermaid
flowchart TD
  Template[Copier] --> Project[生成项目]
  Editor[VS Code] --> Developer[开发者]
  Skills[Agent Skills] --> Agent[编码智能体]
  Developer --> Git[GitHub]
  Agent --> Git
  Git --> Actions[CI / Deploy]
  Dependabot[Dependabot] --> Git
  Actions --> Quality[测试与质量门禁]
  Actions --> Envs[Staging / Production]
```

## 组织原则

- 运行时代码与维护工具分层，避免应用依赖仓库自动化。
- 本地命令和 CI 尽量复用相同脚本。
- 生成工具保留答案与可更新性。
- 编辑器配置只提供推荐，不锁死个人环境。
- 自动化权限和秘密按环境隔离。
