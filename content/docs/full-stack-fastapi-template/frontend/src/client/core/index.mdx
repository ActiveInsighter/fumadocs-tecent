## 完整调用链

```mermaid
sequenceDiagram
  participant UI as React / Query
  participant SDK as sdk.gen.ts
  participant Opt as ApiRequestOptions
  participant Cfg as OpenAPI Config
  participant Req as request.ts
  participant HTTP as Axios / FastAPI
  UI->>SDK: 调用业务方法
  SDK->>Opt: 构造 method/url/body
  SDK->>Req: request(options)
  Req->>Cfg: 解析 BASE/TOKEN/HEADERS
  Req->>HTTP: 发送 HTTP 请求
  alt 2xx
    HTTP-->>Req: AxiosResponse
    Req-->>UI: typed body
  else 非成功状态
    HTTP-->>Req: error response
    Req-->>UI: throw ApiError
  end
```
