<Callout type="idea" title="目录定位">

`frontend/src/client/` 由 FastAPI 的 OpenAPI Schema 自动生成。它把后端的数据模型和路由契约转换成 TypeScript 类型、服务方法和通用请求运行时，减少手写 URL、请求体和响应类型造成的漂移。

</Callout>

## 再生成流程

<Steps>
  <Step>启动或提供可访问的 FastAPI OpenAPI 文档。</Step>
  <Step>运行项目的 `scripts/generate-client.sh`。</Step>
  <Step>生成器读取 Schema 并覆盖 `src/client/`。</Step>
  <Step>执行 TypeScript、Lint 和前端测试，确认契约变化已被处理。</Step>
</Steps>

<Callout type="warn" title="不要把生成文件当手写业务代码">

学习时可以逐行阅读，但长期定制应放在生成器配置、后端 Schema、封装层或独立适配器中。直接修改生成文件会在下一次生成时丢失。

</Callout>

## 组织原则

- 依赖方向应保持为“业务层 → 生成客户端 → 请求运行时”，不要让生成代码反向依赖具体页面。
- 后端字段或路由改变后应立即重新生成，利用 TypeScript 编译错误定位受影响的前端代码。
- 业务规则不应写入 `sdk.gen.ts`；可在 hooks 或 service adapter 中组合多个端点。
- 提交生成文件能让 CI 和部署无需在构建阶段依赖运行中的后端。
