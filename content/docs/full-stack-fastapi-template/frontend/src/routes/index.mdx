<Callout type="idea" title="目录定位">

`frontend/src/routes` 是 URL 结构的源代码。每个文件导出一个 `Route`，TanStack Router 插件据此生成 `routeTree.gen.ts` 和精确路径类型。

</Callout>

## 如何组织

<Tabs items={['公开页面', '受保护页面', '根边界']}>
  <Tab>登录、注册和密码恢复页面直接挂在 `__root` 下，并把已登录用户重定向首页。</Tab>
  <Tab>Dashboard、Items、Settings、Admin 先经过 `_layout` 登录守卫；Admin 再加超级用户守卫。</Tab>
  <Tab>`__root` 统一处理 head、404、错误边界和开发工具。</Tab>
</Tabs>

```mermaid
flowchart TD
  Root[__root] --> Login[/login]
  Root --> Signup[/signup]
  Root --> Recover[/recover-password]
  Root --> Reset[/reset-password]
  Root --> Layout[_layout auth guard]
  Layout --> Dashboard[/]
  Layout --> Items[/items]
  Layout --> Settings[/settings]
  Layout --> Admin[/admin + superuser guard]
```

## 组织原则

- URL 与文件结构由生成器连接，不手工维护 routeTree。
- 公开认证页阻止已登录用户重复进入。
- 受保护页面共享 `_layout` 守卫和页面框架。
- 额外权限放在具体页面 beforeLoad。
- 表单校验使用 Zod，提交状态使用 React Query Mutation。
- 页面 head 元数据与路由定义放在一起。
