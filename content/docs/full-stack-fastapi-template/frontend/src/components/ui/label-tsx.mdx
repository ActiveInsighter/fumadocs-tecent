<Callout type="idea" title="文件定位">

Label 为输入控件提供可见名称。与 `htmlFor`/`id` 正确关联后，点击文本可聚焦控件，读屏器也能获得字段名称。

</Callout>

## 这个文件负责什么

- 包装 Radix Label Root。
- 透传 htmlFor 与事件。
- 统一字号和字重。
- 响应同组控件 disabled 状态。

## 执行思路

1. Label 接收 htmlFor。
2. 浏览器将文本与同 id 控件关联。
3. 点击标签触发控件聚焦/切换。

## 与其他模块的关系

| 模块 | 关系 |
| --- | --- |
| `Radix Label` | 标签行为。 |
| `FormLabel` | 增加错误状态与自动 htmlFor。 |
| `Input/Checkbox` | 被标注的控件。 |

## 导出 API

| 导出 | 类型 | 用途 |
| --- | --- | --- |
| `Label` | `component` | 基础标签。 |

## 组合结构

```tsx title="usage.tsx"
<Label htmlFor="project-name">Project name</Label>
<Input id="project-name" />
```

## 带注释源码

> 原始路径：`frontend/src/components/ui/label.tsx`。以下仅增加学习性注释，不改变程序行为。

```tsx title="label.tsx" lineNumbers
"use client"

import * as React from "react"
import * as LabelPrimitive from "@radix-ui/react-label"

import { cn } from "@/lib/utils"

// Radix Label 让点击文字聚焦关联控件，并处理禁用态样式。
function Label({
  className,
  ...props
}: React.ComponentProps<typeof LabelPrimitive.Root>) {
  return (
    <LabelPrimitive.Root
      data-slot="label"
      className={cn(
        "flex items-center gap-2 text-sm leading-none font-medium select-none group-data-[disabled=true]:pointer-events-none group-data-[disabled=true]:opacity-50 peer-disabled:cursor-not-allowed peer-disabled:opacity-50",
        className
      )}
      {...props}
    />
  )
}

export { Label }
```

## 阅读重点

- 每个可编辑控件都应有可访问名称。
- placeholder 不能代替 Label。
- 隐藏标签时使用 sr-only，而不是完全移除。
- 复选框标签通常放在控件右侧，但 htmlFor 规则相同。
