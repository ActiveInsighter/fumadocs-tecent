<Callout type="idea" title="目录定位">

当前 `lib` 目录非常克制，只包含 Tailwind 类名合并函数。它是 UI 原语的最低依赖层，不应反向依赖路由、API 或业务组件。

</Callout>

## 目录结构

## 如何组织

```mermaid
flowchart LR
  Routes[路由] --> Components[业务组件]
  Components --> UI[UI 原语]
  UI --> Lib[lib/utils.ts]
```

依赖箭头应保持单向。`lib` 可以被上层使用，但不应导入上层模块。

## 组织原则

- 只放跨业务通用的纯函数或基础适配。
- 避免读取全局状态、路由或浏览器存储。
- 保持依赖少、体积小、易测试。
- 函数命名应表达机制，而不是某个页面用途。
