## 文件标题

```tsx title="components/button.tsx"
type ButtonProps = {
  children: React.ReactNode;
  disabled?: boolean;
};

export function Button({ children, disabled = false }: ButtonProps) {
  return <button disabled={disabled}>{children}</button>;
}
```

## 行内代码

行内代码适合文件名和短表达式，例如 `app/global.css`、`font-size: 1.0625rem` 和 `npm run build`。它应当使用较小字号、弱化背景、细边框和适度圆角。
