这是一段用于检查正文字号和行高的中文长段落。当前正文基准为 17px，行高为 1.85，目标是在桌面端保持清晰舒展，同时避免中文文档显得过于紧凑。英文和数字使用 Outfit，中文则回退到系统中文字体，例如 Fumadocs、Next.js 16、React 19 和 Tailwind CSS 4。

第二段用于观察段落之间的距离。正文应该比导航、表格和代码稍大，但不能破坏组件自身的字号层级。你可以切换深色模式，确认前景色、弱化文字和链接在两种主题下都具有足够对比度。

## 标题层级

### 三级标题

三级标题适合文档中的主要小节，当前统一使用中等字重。

#### 四级标题

四级标题适合更细的解释，不应比正文显得过重。

##### 五级标题

五级标题通常用于参数说明或补充主题。

###### 六级标题

六级标题是最弱的一层标题。

## 行内文本

普通文本、**粗体文本**、*斜体文本*、***粗斜体文本***、~~删除线文本~~、`inline code`，以及一个[内部链接](/docs/test/components)和一个[外部链接](https://fumadocs.dev)。

键盘操作可以写成 <kbd>Ctrl</kbd> + <kbd>K</kbd>，也可以使用 <mark>高亮文本</mark> 表示值得注意的内容。

## 引用

> 这是一个普通引用块。它适合摘录定义、提醒背景信息，或者突出一段需要单独阅读的内容。
>
> 引用块内部也可以包含多个段落、**强调文本**和 `code`。
