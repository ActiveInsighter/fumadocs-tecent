## 一、先把第八章整条主线看懂

建议先不要急着背几十个知识点，而是记住这一条发展链：

| 阶段            | 核心问题         | 关键内容                                   |
| ------------- | ------------ | -------------------------------------- |
| **1949—1952** | 新政权能不能活下来、站稳 | 新中国成立、土地改革、镇反、抗美援朝、恢复国民经济、三反五反         |
| **1953—1956** | 中国往哪里走       | 过渡时期总路线、“一五”计划、三大改造                    |
| **1956年底**    | 社会性质发生根本变化   | 社会主义基本制度确立，中国进入社会主义社会                  |
| **1956以后**    | 社会主义究竟怎么建设   | “第二次结合”、《论十大关系》、中共八大、《关于正确处理人民内部矛盾的问题》 |
| **1958以后**    | 探索出现严重曲折     | “大跃进”、人民公社化、随后国民经济调整                   |
| **1960年代以后**  | 在曲折中继续建设     | 八字方针、七千人大会、“四个现代化”                     |
| **改革开放前夕总结**  | 这一时期到底留下了什么  | 建立工业体系、科技国防成就、国际地位提高，为改革开放提供物质基础和经验    |

所以第八章实际上有三个“大故事”：

> **建国并站稳 → 完成社会主义改造 → 探索社会主义建设道路**

这就是整章的骨架。

## 二、第一个大转折：中华人民共和国成立

### 1. 新中国成立到底意味着什么？

这里非常容易出“标志类”选择题。

中华人民共和国成立后，资料概括了几个“彻底结束”和几个“实现”：

**彻底结束了旧中国半殖民地半封建社会的历史；彻底结束了极少数剥削者统治广大劳动人民的历史；彻底结束了旧中国一盘散沙的局面；彻底废除了列强强加给中国的不平等条约和帝国主义在中国的一切特权。**

与此同时，实现了中国从几千年封建专制政治向人民民主的伟大飞跃，实现了中国高度统一和各民族空前团结。

这里最需要防一个坑：

**1949 年新中国成立 ≠ 社会主义制度已经确立。**

1949 年完成的是：

**新民主主义革命取得基本胜利，半殖民地半封建社会结束，中华人民共和国建立。**

而中国正式进入社会主义社会的最主要标志，要等到 **1956 年社会主义经济制度建立、社会主义改造基本完成**。

真题就专门这样考过。2019 年多选把“新民主主义革命基本胜利、半殖民地半封建社会结束、中国共产党地位发生根本性变化”放在一起考，而“社会主义基本制度确立”不能选。

## 三、新中国虽然成立了，但1949年并不是“大功告成”

这是理解本章的第一个关键点。

新中国成立的时候，面对的不是一个已经稳定富强的国家，而是一个战争创伤严重、经济濒临崩溃、国际上遭受封锁、国内还有大量遗留问题的新国家。

资料把新中国成立初期的考验概括为四方面：

| 考验              | 本质         |
| --------------- | ---------- |
| 保卫革命胜利成果        | **政权问题**   |
| 战胜经济困难、恢复国民经济   | **经济问题**   |
| 巩固民族独立、维护主权安全   | **外部安全问题** |
| 经受全国执政考验、保持优良作风 | **党的建设问题** |

也就是可以压缩成：

**政权、经济、安全、执政。**

当时解放全中国的任务尚未完成，大量新解放区尚未完成土地改革；经济方面有工厂倒闭、工人失业、通货膨胀、物价上涨；国际上又面对政治孤立、经济封锁和军事包围；共产党自身则从革命党转变为全国执政党，党员干部面临全新的执政环境。

所以1949—1952年的主要任务可以概括成一句话：

> **把新中国从“建立起来”变成“真正站稳”。**

## 四、怎样巩固新生人民政权？

这一部分史实比较多，但可以按照四条线理解。

### 第一条线：完成民主革命遗留任务

主要包括继续解放国土、摧毁旧政权、土地改革、婚姻制度改革以及镇压反革命等。

这里的土地改革尤其重要。

新中国成立后的土改继续废除封建土地制度，但对富农政策发生了变化：

**由解放战争时期征收富农多余土地财产，改为保存富农经济。**

为什么？

因为新中国已经建立，首要问题之一是迅速恢复农业生产、稳定农村经济，政策不能简单照搬战争时期。

这里要注意性质：

**土地改革仍然属于民主革命遗留任务，而不是社会主义改造。**

这是很容易混的。

## 五、抗美援朝：不仅是一场战争，更是“新中国站稳”的关键事件

这是本章最重要的历史事件之一。

新中国成立后，在外交上实行了三个非常重要的方针：

**“另起炉灶”——“打扫干净屋子再请客”——“一边倒”。**

并与苏联签订《中苏友好同盟互助条约》。

1950 年朝鲜战争爆发，美国军队把战火烧到鸭绿江边，同时美国第七舰队进入台湾海峡。在这样的情况下，中国作出抗美援朝、保家卫国的决策。

资料对抗美援朝胜利的评价非常高：

**新中国真正站稳了脚跟，中国人民真正扬眉吐气；打破了美军不可战胜的神话；彰显了新中国的大国地位；极大促进了国防和军队现代化。**

最需要直接记忆的一句话是：

> **抗美援朝战争的伟大胜利，是中国人民站起来后屹立于世界东方的宣言书，是中华民族走向伟大复兴的重要里程碑。**

2020 年真题也直接考过这一点。正确理解是：抗美援朝提高国际威望、保卫国家安全、维护亚洲和世界和平、打破美军不可战胜的神话；但不能说它“结束了美国在东方的霸权”。

## 六、为什么1952年是另一个重要节点？

因为到 **1952年底，国民经济得到全面恢复和初步发展**。

这个过程非常重要，因为它给下一阶段的社会主义改造准备了经济条件。

这里重点掌握三件事。

第一是**没收官僚资本**。

官僚资本不是一般的民族资本。没收官僚资本以后，建立起社会主义性质的国营经济，并且使国营经济取得国民经济中的领导地位。

因此：

> **建立社会主义国营经济的主要途径，是没收官僚资本。**

不是直接把民族资本全部没收。

第二是逐步限制和利用民族资本主义工商业，把相当一部分引向**国家资本主义**道路。

第三是农村土地改革以后，开始发展互助合作组织，引导农民逐步走互助合作道路。

所以可以发现：

**1949—1952年虽然总体上仍在完成民主革命遗留任务，但社会主义革命的因素已经开始出现。**

资料对此的总结非常适合考试：

| 属于民主革命遗留任务 | 已经具有向社会主义过渡性质     |
| ---------- | ----------------- |
| 土地改革       | 没收官僚资本            |
| 镇压反革命等     | 将资本主义逐步纳入国家资本主义轨道 |
| 其他旧制度改革    | 引导农民走互助合作道路       |

## 七、“三反”“五反”不要混

这也是选择题喜欢出的地方。

**三反**主要针对党政机关和工作人员：

**反贪污、反浪费、反官僚主义。**

**五反**主要针对不法资本家：

**反行贿、反偷税漏税、反盗窃国家财产、反偷工减料、反盗窃经济情报。**

简单记：

> **三反治“内部作风”，五反治“不法资本”。**

这与新中国建立后执政党的自身建设密切相关。

## 八、为什么从1953年开始，中国要向社会主义过渡？

这就是本章第二个大问题。

从1949年到1956年，是从**新民主主义社会向社会主义社会过渡的时期**。

这里首先必须解决一个认识误区：

**新民主主义社会不是一个准备长期独立发展的社会形态，而是一个过渡性质的社会。**

当时社会主义因素和非社会主义因素并存，社会内部存在着社会主义和资本主义两种发展方向。

到了1952年前后，条件发生变化：

社会主义国营经济发展壮大；资本主义工商业越来越被纳入国家调控；农村互助合作发展；民主革命遗留任务基本完成；国家工业化的要求越来越迫切。

于是党提出了**过渡时期总路线**。

## 九、过渡时期总路线：一定要把“一化三改”理解透

这一部分和毛中特第三章高度重合。

总路线的核心概括是：

> **一化三改。**

其中：

| 内容     | 含义                   |
| ------ | -------------------- |
| **一化** | 社会主义工业化              |
| **三改** | 农业、手工业、资本主义工商业社会主义改造 |

关系是：

**“一化”是主体，“三改”是两翼。**

更重要的是理解它的特点：

> **社会主义建设和社会主义改造同时并举。**

不是“先完成工业化，再进行社会主义改造”；而是边建设、边改造。

为什么？

因为工业化需要新的经济制度作为支撑，而社会主义改造又需要工业化提供物质条件，两者是互相联系的。毛中特资料对此进一步概括为工业化建设与社会主义改造紧密结合，体现变革生产关系与发展生产力的统一。

## 十、为什么当时选择社会主义道路？

这不是简单的“因为想这样做”，而是当时经济社会条件的结果。

《精讲精练》主要强调四个理由：

**社会主义工业化是国家独立富强的首要条件；资本主义经济力量弱小，无法成为中国工业化起飞的基础；改造个体农业是工业化的重要条件；当时国际环境也推动中国选择社会主义道路。**

特别是农业。

如果农村长期停留在一家一户的小农经济状态，就难以稳定地为工业化提供粮食、原料、市场和积累。

所以农业合作化与工业化并不是两个完全独立的政策。

2018 年多选题直接考过上述原因。

## 十一、“一五”计划：新中国工业化真正起步

中国从 1953 年开始实施第一个五年计划。

核心思路是：

**集中主要力量发展重工业，建立国家工业化和国防现代化的初步基础。**

同时发展交通、轻工业、农业、商业，并培养建设人才。

这里有一个非常典型的考点：

> **以苏联援助的156项工程为中心的工业建设。**

“一五”时期，中国工业生产能力和技术水平大幅提高。

资料对此评价：

**这一时期工业生产取得的成就远远超过旧中国一百年，新中国为建立独立完整工业体系奠定了基础。**

所以要把两个东西区分开：

**“一五”计划 = 工业化建设。**

**三大改造 = 生产资料所有制的社会主义改造。**

二者是在同一时期同时推进的。

## 十二、农业社会主义改造：最重要的是三步性质

农业改造走的是**合作化道路**。

三个阶段非常爱考：

| 组织            | 性质       |
| ------------- | -------- |
| **互助组**       | 社会主义萌芽性质 |
| **初级农业生产合作社** | 半社会主义性质  |
| **高级农业生产合作社** | 社会主义性质   |

核心逻辑：

> **萌芽 → 半社会主义 → 社会主义。**

在方法上，强调农民自愿，采取说服、示范、国家援助的方法。

1955 年后农业合作化形成高潮，**到1956年底农业合作化基本完成**。

这意味着中国农村完成了从几千年的分散个体劳动向集体所有、集体经营的历史性转变。

## 十三、手工业社会主义改造

逻辑与农业基本相似，也是合作化。

主要记：

**方针：积极引导、稳步前进。**

组织由低到高：

| 组织        | 性质       |
| --------- | -------- |
| 手工业生产合作小组 | 社会主义萌芽性质 |
| 手工业供销合作社  | 半社会主义性质  |
| 手工业生产合作社  | 社会主义性质   |

到 **1956年底**，手工业合作化基本完成。

## 十四、资本主义工商业改造：本章难点之一

它和农业、手工业最大不同，是不能简单走“合作社”道路。

核心政策是：

> **和平赎买。**

实现形式：

> **国家资本主义。**

发展过程大致可以理解成：

**初级国家资本主义 → 个别企业公私合营 → 全行业公私合营。**

初级国家资本主义主要还是国家与私人企业在企业外部进行联系，例如加工、订货、统购、包销、经销、代销等。

进入个别企业公私合营后，社会主义经济与私人资本开始在企业内部结合。

最后全行业公私合营，企业基本成为社会主义性质。

利润分配也是高频考点：

**前期、个别公私合营阶段：四马分肥。**

全行业公私合营后则实行：

**定股定息。**

这里特别容易出现一个错误选项：

“社会主义改造就是无偿没收民族资本家的资产。”

错误。

官僚资本是没收，**民族资本主义工商业主要采取和平赎买。**

中国把马克思、恩格斯关于赎买资产阶级的设想成功付诸实践，被资料评价为中国共产党的独创性经验，丰富发展了科学社会主义理论。

## 十五、1956年：这一章最重要的年份

如果第八章只让你记一个年份，就是 **1956**。

因为到1956年底，社会主义改造基本完成。

结果是：

> **社会主义经济制度建立。**

它以：

**生产资料公有制、按劳分配、计划经济体制**

为基本特征。

资料特别强调：

> **社会主义经济制度的建立，是中国进入社会主义社会最主要的标志。**

不是1949年建国，也不是1954年宪法，而是**社会主义经济制度建立**。

2023 年考研政治单选第12题就直接考过，答案是“社会主义经济制度的确立”。

## 十六、1954年宪法与社会主义政治制度

1954年召开第一届全国人大第一次会议，通过《中华人民共和国宪法》。

这一事件的核心考法：

> **人民代表大会制度这一国家根本政治制度正式建立。**

1954年宪法是一部**社会主义类型的宪法**，体现人民民主原则和社会主义原则。

与此同时，逐步形成了我国社会主义政治制度体系：

| 制度                  | 地位     |
| ------------------- | ------ |
| **人民代表大会制度**        | 根本政治制度 |
| 中国共产党领导的多党合作和政治协商制度 | 基本政治制度 |
| 民族区域自治制度            | 基本政治制度 |

这里还要特别注意：

1954年一届全国人大召开以后，**人民政协不再代行全国人大职权**，但人民政协并没有消失，而是继续作为人民民主统一战线的组织存在。

## 十七、社会主义制度确立有什么意义？

这里非常适合作为分析题语言积累。

资料把它概括成一个极大的历史飞跃：

**中华人民共和国成立、社会主义制度建立，是中华民族有史以来最为广泛而深刻的社会变革。**

最重要的是：

**为当代中国一切发展进步奠定了根本政治前提和制度基础。**

而且，社会主义基本制度确立以后，工人阶级和广大劳动人民的积极性、创造性得到提高，为社会生产力发展开辟道路；社会主义经济、政治制度也为社会主义文化发展提供了基础和方向。

到这里，第八章前半段就结束了。

可以把前半段一句话概括为：

> **1949解决“建立国家”，1952解决“站稳脚跟”，1956解决“建立社会主义制度”。**

## 十八、1956年以后：问题变成“社会主义怎么建设”

这就是本章下半段。

社会主义基本制度已经建立，可是新的问题出现了：

> 中国人口这么多、经济文化这么落后，到底怎么建设社会主义？

苏联已经建设社会主义很多年，但中国能不能简单照抄苏联模式？

答案是否定的。

1956 年苏共二十大进一步暴露苏联社会主义建设中的一些问题，中国共产党由此更加明确提出：

**以苏为鉴，探索自己的社会主义建设道路。**

这就引出非常重要的：

> **马克思主义同中国实际的“第二次结合”。**

## 十九、“第二次结合”到底是什么意思？

1956年4月，毛泽东提出：

过去民主革命时期，我们把马克思主义基本原理和中国革命实际结合，走出了中国革命道路；现在进入社会主义革命和建设时期，也必须进行新的结合，**找出在中国怎样建设社会主义的道路。**

所以考研最标准的对应关系是：

| 第一次结合      | 第二次结合          |
| ---------- | -------------- |
| 主要解决中国革命问题 | 主要解决中国社会主义建设问题 |
| 形成中国革命道路   | 探索中国社会主义建设道路   |

资料特别提醒：

**是“提出进行第二次结合”，不是说1956年已经“完成了第二次结合”。**

2022 年单选直接问“目的是什么”，答案就是：

> **找出在中国怎样建设社会主义的道路。**

## 二十、《论十大关系》：社会主义建设探索的开篇性成果

这是本章下半部分最重要的文献之一。

1956 年4—5月，毛泽东发表《论十大关系》。

它最核心的一个基本方针是：

> **调动一切积极因素为社会主义事业服务。**

你千万别把它和别的方针混。

不是：

“正确处理人民内部矛盾”；

不是：

“既反保守又反冒进”；

而是：

**调动一切积极因素。**

《论十大关系》讨论十大关系，前五大体偏经济，后五大体偏政治和社会关系。

前五包括重工业和轻工业、农业，沿海和内地，经济建设和国防建设，国家、生产单位和个人，中央和地方等关系。

后五包括汉族和少数民族、党和非党、革命和反革命、是非、中国和外国等关系。

这里尤其要记住第一大关系：

> **重工业和轻工业、农业的关系。**

因为这实际是在思考：

> **中国工业化道路应该怎样走？**

## 二十一、《论十大关系》的历史地位

这一句非常重要：

> **《论十大关系》是以毛泽东为主要代表的中国共产党人开始探索适合中国国情的社会主义建设道路的标志。**

它为中共八大的召开作了理论准备。

因此出现下面选项时：

“已经找到完整的中国特色社会主义道路”——错。

“已经完成第二次结合”——错。

“已经完全突破苏联模式”——过头。

正确表述通常是：

> **开始探索中国自己的社会主义建设道路。**

2010年真题就是这样考的。

## 二十二、1956年中共八大：第八章超级重点

1956年9月，中共八大召开。

为什么重要？

因为社会主义改造即将完成，社会关系发生了巨大变化，党必须重新判断：

**现在中国最主要的问题到底是什么？**

八大作出了当时非常重要的正确判断：

> **国内主要矛盾已经是人民对于经济文化迅速发展的需要同当前经济文化不能满足人民需要的状况之间的矛盾。**

因此：

> **全国人民的主要任务是集中力量发展社会生产力，实现国家工业化，逐步满足人民日益增长的物质和文化需要。**

这里要特别对比几套“主要矛盾”。

| 时期             | 主要矛盾                              |
| -------------- | --------------------------------- |
| 近代半殖民地半封建社会    | 帝国主义与中华民族；封建主义与人民大众               |
| 1953—1956过渡时期  | 工人阶级与资产阶级等社会主义、资本主义方向的矛盾          |
| **1956中共八大判断** | **人民经济文化发展的需要与当前经济文化不能满足需要之间的矛盾** |
| 改革开放后经典表述      | 人民日益增长的物质文化需要同落后的社会生产之间的矛盾        |
| 新时代            | 人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾      |

这张对比表非常重要，因为考研特别喜欢“把后一时期的提法塞到前一时期”。

## 二十三、中共八大还有哪些考点？

经济建设：

> **既反保守又反冒进，即在综合平衡中稳步前进。**

经济体制探索：

> **“三个主体，三个补充”。**

这是探索突破高度集中的计划经济模式的一种尝试。

政治建设：

> 扩大社会主义民主，健全社会主义法制，做到“有法可依”“有法必依”。

党建方面：

八大通过了中国共产党全国执政以后制定的第一部党章。

所以2024年真题考1956年提出的一系列方针，正确的是：

**既反保守又反冒进；百花齐放、百家争鸣；长期共存、互相监督。**

而“一边倒”是建国初期外交方针，不是1956年提出的。答案是 **ACD**。

## 二十四、《关于正确处理人民内部矛盾的问题》

1957年，毛泽东系统讨论社会主义社会矛盾问题。

第一层：

> **社会主义社会仍然有矛盾。**

不能认为社会主义制度建立后矛盾就消失了。

社会主义社会的基本矛盾仍然是：

> **生产关系和生产力之间的矛盾，上层建筑和经济基础之间的矛盾。**

但是与旧社会的基本矛盾相比，有一个重要特征：

> **又相适应又相矛盾，相适应的一面是基本方面。**

因此这种基本矛盾可以通过：

> **社会主义制度本身的调整不断得到解决。**

## 二十五、敌我矛盾和人民内部矛盾一定区分

社会主义社会的矛盾在政治上，可以分成两类：

| 矛盾         | 性质      | 方法       |
| ---------- | ------- | -------- |
| **敌我矛盾**   | 对抗性     | **专政方法** |
| **人民内部矛盾** | 一般为非对抗性 | **民主方法** |

所以：

> **正确处理人民内部矛盾，是社会主义国家政治生活的主题。**

它的根本着眼点是：

> **调动一切积极因素，把力量转到社会主义建设上来。**

不同领域又有不同方针：

| 领域      | 方针            |
| ------- | ------------- |
| 政治思想    | **团结—批评—团结**  |
| 物质利益、分配 | **统筹兼顾、适当安排** |
| 科学文化    | **百花齐放、百家争鸣** |
| 党和民主党派  | **长期共存、互相监督** |
| 民族关系    | **民族平等、团结互助** |

这些方针非常适合做配对题。

## 二十六、探索为什么后来发生曲折？

1956年前后的探索有很多正确成果，但之后出现了急于求成的倾向。

这就进入考点78：

**“大跃进”和人民公社化运动。**

该版《精讲精练》对于“大跃进”没有在第八章展开很多细节，但对人民公社化给了非常典型的考点：

> **人民公社实行“政社合一”，基本特点是“一大二公”。**

“大”：

**规模大。**

“公”：

**公有化程度高。**

在实践中又出现“一平二调”的“共产风”，平均主义和无偿调拨严重损害农民生产积极性。

从考试理解上来说，问题本质在于：

**超越当时生产力水平和实际条件，急于求成。**

## 二十七、1959—1961困难与“八字方针”

由于探索中的严重失误以及其他因素，1959—1961 年国民经济出现严重困难。

1961 年1月，中共八届九中全会决定实行：

> **调整、巩固、充实、提高。**

这就是著名的：

> **“八字方针”。**

一定要背顺序：

**调—巩—充—提。**

不是“大跃进”时期的建设口号，也不是三大改造方针。

同时毛泽东号召：

**大兴调查研究之风。**

这体现的其实还是实事求是——重新回到实际情况中认识问题。

## 二十八、七千人大会

1962 年1—2月召开扩大的中央工作会议，因为参加者约七千人，通常称：

> **七千人大会。**

资料强调它：

**发扬了党内民主和自我批评精神，统一了全党的认识，对动员全党团结奋斗、战胜困难起了重要作用。**

因此这次会议和遵义会议、十一届三中全会等不能混：

七千人大会主要是：

> **总结社会主义建设中的问题，推动克服困难。**

不是改革开放的转折点。

## 二十九、“四个现代化”战略目标

1964年底到1965年初，第三届全国人大提出把我国建设成为具有：

> **现代农业、现代工业、现代国防、现代科学技术**

的社会主义强国。

这就是当时的：

> **四个现代化。**

同时提出分“两步走”实现现代化的战略构想。

这里容易和1954年周恩来的早期现代化表述混淆。

资料还特别指出，1954 年第一次提出的表述中包括：

**现代化工业、现代化农业、现代化交通运输业、现代化国防。**

后来“四个现代化”的经典表述则是：

**农业、工业、国防、科学技术。**

这是一个很适合出细节题的区别。

## 三十、怎样评价改革开放前的社会主义建设？

这是学这一章最容易犯的错误：

看到探索中出现“大跃进”等严重曲折，就把整个时期简单评价为“没有成就”。

这与资料的框架不符。

《精讲精练》的评价是：

> 在探索过程中虽然经历严重曲折，但是社会主义革命和建设取得的独创性理论成果和巨大成就，为新的历史时期开创中国特色社会主义提供了**宝贵经验、理论准备、物质基础**。

这是一个非常重要的三词组合：

> **宝贵经验 + 理论准备 + 物质基础。**

## 三十一、第一个巨大成就：工业体系真正“从无到有”

从新中国成立到改革开放前，中国逐步建立起：

> **独立的、比较完整的工业体系和国民经济体系。**

资料对这个成果的评价是：

> **从根本上解决了工业化中“从无到有”的问题。**

这非常重要。

1949年前中国虽然已经存在一些近代工业，但没有建立独立完整的现代工业体系，而且经济命脉长期受外部势力和官僚资本控制。

到这一时期，中国不仅政治上独立，而且逐步形成独立的工业和国民经济体系。

因此后来改革开放不是在“一无所有”基础上启动的，而是在此前形成的工业、交通、能源、国防、科研和人才基础上继续发展。

## 三十二、人民生活和社会面貌也发生巨大变化

资料并没有说这一时期已经富裕，而是非常准确地表述为：

**占世界1/4人口的基本生活需求初步得到满足。**

同时基层社会组织逐步建立，社会治安和社会风气发生巨大变化，人民生命财产安全得到改善。

所以这里要区分：

**基本生活得到保障**

和

**已经实现富裕**

完全不是一回事。

## 三十三、“两弹一星”相关时间要认识

这属于本章很典型的科技史细节。

| 时间        | 成就                   |
| --------- | -------------------- |
| **1964年** | 第一颗原子弹爆炸成功           |
| **1966年** | 第一次成功进行发射导弹核武器试验     |
| **1967年** | 第一颗氢弹爆炸成功            |
| **1970年** | 第一颗人造地球卫星“东方红一号”成功发射 |

这些成果不仅具有科技意义，也大大增强了：

**综合国力、国防战略防御能力以及国际政治影响力。**

## 三十四、国际地位发生重要变化

这里主要抓两个时间：

**1971年**

中国恢复在联合国的合法席位。

**1972年**

随着中美关系开始正常化，出现西方国家对华建交热潮。

所以到改革开放前，中国的外交环境已经出现明显改善，这也为后来逐步实行对外开放创造了外部条件。

## 三十五、这章最重要的“标志题”一次性归纳

这一组建议直接形成条件反射：

| 问题                  | 正确答案                |
| ------------------- | ------------------- |
| 新民主主义革命基本胜利         | **中华人民共和国成立**       |
| 半殖民地半封建社会结束         | **中华人民共和国成立**       |
| 人民代表大会制度正式建立        | **1954年一届全国人大一次会议** |
| 中国进入社会主义社会最主要标志     | **社会主义经济制度建立**      |
| 社会主义基本制度确立          | **1956年社会主义改造基本完成** |
| 开始探索适合中国国情的社会主义建设道路 | **《论十大关系》**         |
| 全面建设社会主义重要正确路线      | **中共八大路线**          |

这一张表，是第八章选择题得分效率最高的部分。

## 三十六、几个最容易混淆的概念

### 1. 1949 与 1956

**1949：**

中华人民共和国成立，新民主主义革命基本胜利。

**1956：**

社会主义改造基本完成，社会主义基本制度确立，进入社会主义社会。

不要提前七年。

### 2. 没收官僚资本 与 改造民族资本

官僚资本：

> **没收。**

民族资本主义工商业：

> **和平赎买，通过国家资本主义逐步改造。**

### 3. 农业改造三阶段

> **互助组 → 初级社 → 高级社**

对应：

> **萌芽 → 半社会主义 → 社会主义。**

### 4. 三大理论节点

《论十大关系》：

> **调动一切积极因素。**

中共八大：

> **正确判断主要矛盾，中心任务转向发展生产力。**

《关于正确处理人民内部矛盾的问题》：

> **社会主义仍有矛盾，正确处理人民内部矛盾成为国家政治生活主题。**

这三个必须分开。

## 三十七、历年真题与命题方式

真题资料显示，本章近年来非常喜欢考几个核心节点：

**2023年**考“中国进入社会主义社会最主要标志”，答案是**社会主义经济制度确立**；**2022年**考“第二次结合”的目的，答案是**找出在中国怎样建设社会主义的道路**；**2024年**考1956年的社会主义建设方针，答案为**既反保守又反冒进、百花齐放百家争鸣、长期共存互相监督**；2010年则考《论十大关系》代表**开始探索中国自己的社会主义建设道路**。

所以考研命题并不是让你背一长串历史流水账，而是特别喜欢问：

> **什么时候发生了什么转折？什么事件标志什么？为什么这样做？这个政策与另一个政策有什么区别？**

这正是史纲的典型考法。

## 三十八、最后把整章压缩成一张“脑图”

实际复习时，可以在脑中形成这样一条链：

> **1949 新中国成立**
> ↓
> 新民主主义革命基本胜利，半殖民地半封建社会结束
> ↓
> **1949—1952 巩固政权**
> 土改、镇反、抗美援朝、恢复经济、三反五反
> ↓
> **1953 过渡时期总路线**
> 一化三改
> ↓
> **一五计划 + 三大改造**
> 工业化与社会主义改造同时并举
> ↓
> 农业合作化、手工业合作化、资本主义工商业和平赎买
> ↓
> **1956 社会主义基本制度确立**
> 中国进入社会主义社会
> ↓
> 新问题：社会主义怎么建设？
> ↓
> **第二次结合**
> ↓
> **《论十大关系》**
> 调动一切积极因素，开始探索自己的建设道路
> ↓
> **中共八大**
> 主要矛盾变化，中心任务转向发展生产力
> ↓
> **《关于正确处理人民内部矛盾的问题》**
> ↓
> 探索出现曲折：“大跃进”、人民公社化
> ↓
> **1961 八字方针**
> 调整、巩固、充实、提高
> ↓
> **1962 七千人大会**
> ↓
> **四个现代化**
> ↓
> 建成独立、比较完整的工业体系和国民经济体系，科技国防和外交取得重大成就
> ↓
> **为改革开放后的中国特色社会主义建设提供宝贵经验、理论准备和物质基础**

这条链真正理解以后，第八章就不会再是几十个孤立考点，而会变成一个非常清楚的历史过程：

**“先解决国家能不能站住，再解决国家走什么制度，最后解决社会主义到底怎么建设。”**

如果按**考研做题优先级**来排，第八章最值得你第一轮先吃透的是：**新中国成立的意义 → 抗美援朝 → 一化三改 → 三大改造三种道路 → 1956社会主义制度确立 → 第二次结合 →《论十大关系》→ 中共八大 → 人民内部矛盾 → 八字方针 → 社会主义建设成就。**这基本覆盖本章绝大多数高价值选择题命题点。
