## 一、先看第一章到底在讲什么

这一章表面上知识点很多，实际上只是在连续回答几个问题：

> **人是什么**？
> ↓
> **个人和社会是什么关系**？
> ↓
> **人为什么活、应该怎样活、怎样的人生才有价值**？
> ↓
> **什么样的人生追求是正确的**？
> ↓
> **人生价值怎么看、怎么实现**？
> ↓
> **遇到得失、苦乐、顺逆怎么办**？
> ↓
> **最后怎样创造有意义的人生**？

所以整章可以压缩成：

**人的本质 → 个人与社会 → 人生观 → 人生追求、人生态度 → 人生价值 → 人生矛盾 → 错误人生观 → 出彩人生**。

这是一个非常重要的结构。做选择题时，很多干扰项本身不是完全错误，而是**把不同层级的概念偷换了**。


## 二、第一层：首先搞清楚“人是什么”

### 1. 对人的认识，核心是认识人的本质

教材的核心表述是：

**人的本质是一切社会关系的总和，社会属性是人的本质属性**。

任何现实中的人，都不是脱离家庭、学校、职业、国家、时代而孤立存在的人，而是处在一定社会关系中、从事社会实践活动的人。因此，对人的认识不能从一种抽象不变的“人性”出发，而要把人放到**具体的、历史的社会关系**中去理解。

这一点和马原唯物史观是直接相通的，你的《政治考点》在马原部分同样强调：“人的本质不是单个人所固有的抽象物，在其现实性上，是一切社会关系的总和”，人的本质属性是社会属性。

#### 怎么理解“社会属性是人的本质属性”？

它**不是说人没有自然属性**。

人当然要吃饭、睡觉、繁衍，也有生物学结构，这些都是人的自然属性。

但考试问“什么最能从根本上说明一个现实的人是谁”，答案不是身高、体重、生理结构，而是他的**社会关系和社会实践**。

比如，同一个自然意义上的人，可以同时是：

父母的子女、同学的朋友、学校的学生、社会的公民、某项工作的承担者。

这些社会关系共同塑造了现实中的这个人。

所以：

| 说法                 | 判断 |
| ------------------ | -- |
| 人具有自然属性            | 对  |
| 人具有社会属性            | 对  |
| 人的本质属性是自然属性        | 错  |
| 人的本质属性是社会属性        | 对  |
| 人的本质是一种永恒不变的抽象人性   | 错  |
| 人的本质要放在具体历史社会关系中把握 | 对  |

这里非常容易和生物学意义上的“人”混淆。


## 三、第二层：个人与社会到底是什么关系

这是本章第一个真题高频点。

教材先给一个定位：

**个人与社会的关系问题，是认识和处理人生问题的重要着眼点和出发点**。

个人和社会是**对立统一的关系**。

一方面，没有一个个具体的人，也就没有社会；另一方面，人不可能脱离社会孤立生存，**社会是人的存在形式**。

社会的发展依靠社会成员，社会成员的发展又必须依托社会。社会成员素质提高是社会发展的重要基础，而推动和实现人的全面发展，又是社会发展的根本目标。

### 最重要的一句话

**个人与社会的关系，最根本的是个人利益与社会利益的关系**。

这个“最根本”一定要背。

2021 年考研政治就直接考了：

“个人与社会的关系最根本的是？”

答案是：

**个人利益与社会利益的关系**。

#### 为什么不是“个人价值与社会价值”？

因为“个人价值—社会价值”是在讲**人生价值内部的两个方面**。

而这里问的是更大的“个人—社会关系”，教材规定最根本落到：

**个人利益 ↔ 社会利益**。

这是典型的选择题偷换概念。

### 社会利益是不是所有个人利益简单加起来？

不是。

资料明确指出：

**社会利益不是个人利益的简单相加，而是所有人利益的有机统一**。

而且社会利益体现了社会成员的**根本利益和长远利益**，是个人利益实现的前提和基础，同时保障个人利益实现。

因此，这一章不是简单说：

> “个人不重要，社会重要。”

这种理解是错误的。

正确逻辑是：

**个人与社会相互联系，但个人的发展必须在社会中实现；社会整体条件又为个人发展提供基础**。


## 四、第三层：人生观到底是什么

理解这一部分时，最重要的是记住三个问题。

| 人生观内容    | 回答的问题      | 考试关键词 |
| -------- | ---------- | ----- |
| **人生目的** | 人为什么活着     | 为什么   |
| **人生态度** | 人应当如何活着    | 怎么活   |
| **人生价值** | 什么样的人生才有价值 | 值不值   |

这三个合起来，就是人生观的主要内容。


## 五、人生目的：最重要，因为它是人生观的核心

### 1. 人生目的回答什么？

**人为什么活着**。

2012 年真题几乎原句考过：

> 人生目的所认识和回答的根本问题是什么？

答案就是：

**人为什么活着**。

### 2. 为什么人生目的是人生观的核心？

因为它具有方向性作用：

**人生目的决定人生道路，决定人生态度，决定人生价值选择**。

可以理解为：

人生目的就是整个“人生系统”的总目标。

如果总目标不一样，后面的选择自然都会变化。

例如，一个人把“获得最多金钱”作为唯一人生目的，那么他的职业、消费、交往甚至道德选择都可能围绕金钱展开。

如果一个人把“服务人民、奉献社会”作为人生追求，那么他对成功、得失、职业和价值的判断都会不同。

所以教材把**人生目的**放在核心地位。

#### 高频陷阱

“人生目的决定人的本质”——错。

人的本质属于前面讲的社会关系范畴，不是由一个人的人生目的决定的。

肖 1000 题里也专门把这一项设置成干扰项。


## 六、人生态度：回答“应该怎样活”

人生态度是：

**人们通过生活实践形成的对人生问题的一种稳定的心理倾向和精神状态，回答的是人应当如何活着**。

现有的《精讲精练》要求掌握四个关键词：

**人生须认真、人生当务实、人生应乐观、人生要进取**。

教材整理给的是四个结论，理解时可以这样把握：

| 人生态度  | 做题理解             |
| ----- | ---------------- |
| 人生须认真 | 对自己、社会、人生负责任，不敷衍 |
| 人生当务实 | 从实际出发，脚踏实地，不空想   |
| 人生应乐观 | 正确认识困难，对未来保持积极态度 |
| 人生要进取 | 不停滞、不消沉，在实践中不断发展 |

最重要的一句前提是：

**没有积极进取的人生态度，再崇高的人生追求也难以实现**。

也就是说，“目的”解决方向，“态度”决定你以什么精神状态朝这个方向走。


## 七、人生价值：这一章最容易出选择题的地方

人生价值回答：

**什么样的人生才有价值**。

教材把人生价值定义为：

人的生命及其实践活动对于社会和个人所具有的作用和意义。

注意，它不是只问：

“我从社会得到了什么？”

而是同时包括两个方向：

**自我价值 + 社会价值**。


## 八、人生的自我价值和社会价值

这是本章绝对重点。

### 1. 自我价值

人生的自我价值，是：

**个体的人生活动对自己的生存和发展所具有的价值**。

主要表现为自身物质和精神需要得到满足的程度。

例如学习知识、提升能力、获得正常收入、改善生活、实现个人发展，都可以属于自我价值的实现。

而且教材明确：

**人生的自我价值是个体生存和发展的必要条件；自我价值的实现，是个体为社会创造更大价值的前提**。

所以考研政治并不否定合理的个人发展、自我完善。


### 2. 社会价值

人生的社会价值，是：

**个体的实践活动对社会、他人所具有的价值**。

比如教师教书育人、医生救治患者、科研人员推动科技进步、普通劳动者提供产品和服务，这些都体现社会价值。

教材进一步说：

**人生的社会价值是社会存在和发展的重要条件；社会价值的实现，是个体自我完善、全面发展的保障**。

并且有一句很强的表述：

**没有社会价值，人生的自我价值就无法存在**。


## 九、自我价值和社会价值是什么关系

不是二选一。

更不是：

> 有社会价值就不需要自我价值。

而是：

**既相互区别，又密切联系、相互依存**。

可以把它理解成一个循环：

**个人成长 → 获得知识、能力 → 更有能力贡献社会 → 社会发展 → 又为个人发展创造条件**。

因此人生价值是：

**自我价值与社会价值的统一**。

2019 年真题中，马克思谈“为同时代人的幸福工作”，正确答案就是：

**人生价值是自我价值和社会价值的统一**。

所以碰到这些选项要特别小心：

| 选项               | 判断 |
| ---------------- | -- |
| 社会价值可以取代自我价值     | 错  |
| 自我价值和社会价值相互排斥    | 错  |
| 自我价值是创造更大社会价值的前提 | 对  |
| 社会价值实现是个体全面发展的保障 | 对  |
| 人生价值是二者统一        | 对  |


## 十、人生目的、人生态度、人生价值三者怎样联系

教材不是简单列三个概念，而是强调三者**相互影响、紧密关联**。

《精讲精练》的表述是：

**人生目的决定**人们对待实际生活的态度和对人生价值的评判；

**人生态度影响**人们对人生目的的持守和人生价值的实现；

**人生价值制约**人们对人生目的和人生态度的选择。

这三句可以理解为：

> **目的管方向，态度管过程，价值管评价**。

需要注意，你的《政治考点》整理中有一处把第二句写成了“人生态度影响……人生价值的评判”，而《精讲精练》完整版写的是“人生价值的**实现**”。复习和做题建议以《精讲精练》版本的“实现”为准。


## 十一、人生观、世界观、价值观的关系

这三个词特别容易串。

### 世界观 → 决定人生观

世界观，是对整个世界以及人与世界关系的总体看法和根本观点。

所以教材明确：

**世界观决定人生观**。

一个人怎样理解世界、人类社会和自己在社会中的地位，自然会影响他怎样理解人生。

但是人生观也不是完全被动的：

**人生观对世界观的巩固、发展和变化起重要作用**。

所以不是：

“人生观决定世界观。”

而是：

**世界观决定人生观，人生观反作用于世界观的发展**。

### 价值观 → 对人生观具有重要引导作用

价值观解决的是：

什么是好的、什么是坏的，什么值得追求，应按什么标准评价人和事。

因此：

**价值观对于人生观的形成和发展具有重要的引导作用**。

可以记成：

> **世界观决定，价值观引导，人生观反作用**。


## 十二、什么是正确、高尚的人生追求

本章给出的核心答案非常明确：

**服务人民、奉献社会，代表了人类社会迄今最先进的人生追求**。

这句话属于明显的背诵点。

为什么？

教材从三个层面解释。

首先，它解决**人生目的**问题。确立这种追求，才能正确把握人生奋斗目标，理解为什么活、走什么路。

其次，它解决**人生态度**问题。能够以人民利益为重，以责任感处理现实人生问题，在服务人民和奉献社会中实现价值。

最后，它解决**人生价值标准**问题。它使人认识到：

**人生的价值首先在于奉献**。

所以这不是一个孤立口号，而是把前面三个概念串起来：

**人生目的 → 人生态度 → 人生价值**。


## 十三、人生价值到底怎样评价

这部分有三个不同层次，非常容易混。

### 第一层：根本尺度

评价人生价值的**根本尺度**是：

**看一个人的实践活动是否符合社会发展的客观规律，是否促进了历史的进步**。

教材把它概括为：

**历史标准**。

2017 年真题直接问“根本尺度是什么”，正确答案就是：

**历史标准**。

为什么叫历史标准？

因为评价一个人的人生，不能只看他个人赚了多少钱、职位多高、名声多大，而要放入社会历史发展中，看他的实践到底促进还是阻碍了社会进步。


### 第二层：今天衡量人生价值最重要的标准

教材又有一句：

**今天衡量人生价值的标准，最重要的就是看一个人是否用自己的劳动和聪明才智为国家和社会真诚奉献，为人民群众尽心尽力服务**。

注意：

“**根本尺度**”与“**今天最重要的衡量标准**”不是同一句话。

选择题很容易偷换。

| 问法             | 答案                        |
| -------------- | ------------------------- |
| 人生价值评价的根本尺度    | 是否符合社会发展客观规律、促进历史进步，即历史标准 |
| 今天衡量人生价值最重要的标准 | 为国家社会真诚奉献、为人民群众尽心尽力服务     |


## 十四、怎样科学评价一个人的人生价值

教材给出三组辩证统一。

**既看贡献大小，也看尽力程度；既尊重物质贡献，也尊重精神贡献；既注重社会贡献，也注重自身完善**。

这三组背后的思想非常重要。

不能只看最终成果，因为每个人面临的条件不同，所以还要看他是否尽力。

不能只看创造了多少物质财富，因为思想、文化、教育、道德等精神贡献同样重要。

不能只讲社会贡献而完全忽视个体发展，因为自我完善本身也是创造更大社会价值的重要基础。

因此政治题里的正确评价通常是**全面的、辩证的**，而绝少是“只看某一个方面”。


## 十五、人生价值怎样实现

教材给三个条件：

**从社会客观条件出发；从个体自身条件出发；不断增强实现人生价值的能力和本领**。

这可以直接和马原“主观能动性与客观规律性”联系起来理解。

只讲客观条件：

> “环境不好，所以什么也做不了。”

不对。

只讲主观努力：

> “只要足够努力，任何事情都一定能做到。”

也不对。

正确逻辑是：

**客观条件 + 自身实际 + 主观努力和能力提升**。

例如，一个人的职业选择既受到社会需求、时代条件影响，也受到知识结构、能力、兴趣等自身条件影响；最后还需要通过学习和实践不断提升本领。


## 十六、怎样正确面对人生中的矛盾

这一部分很适合材料题，也非常适合做价值判断题。

《精讲精练》归纳为五对：

| 人生矛盾 | 正确认识                      |
| ---- | ------------------------- |
| 得与失  | 不过分看一时之得，不斤斤计较一时之失，跳出个人得失 |
| 苦与乐  | 苦乐可以转化，真正的快乐往往来自奋斗        |
| 顺与逆  | 两者作用都可能是双面的，关键在人如何对待      |
| 生与死  | 生命有限，但可以通过有意义的实践赋予生命更大价值  |
| 荣与辱  | 荣辱观对人的思想行为具有导向和调节作用       |


### 1. 得与失

不要把一时得失等同于整个人生价值。

有时个人短期“失去”时间、精力和利益，可能换来能力成长或社会贡献。

所以教材进一步强调：

**把小我融入大我，在奉献社会中才能实现更大的人生价值**。


### 2. 苦与乐

苦和乐不是绝对割裂的。

教材强调：

**真正的快乐往往由奋斗的艰苦转化而来**。

所以政治题如果把“幸福”解释成：

“不劳动、不付出、单纯追求感官享受”，一般就是错的。


### 3. 顺境与逆境

非常典型的辩证法思路：

**顺境和逆境都有两面性**。

顺境可能给人良好条件，也可能使人骄傲懈怠。

逆境可能带来困难，也可能磨炼意志、促进成长。

所以不是：

“顺境一定好，逆境一定坏。”

而是：

**处优而不养尊，受挫而不短志**。


### 4. 生与死

教材不是抽象讨论死亡，而是强调：

**人的生命价值在于个体生命付出背后的意义**。

生命在时间上有限，但可以通过对社会和他人的贡献获得更深的意义。


### 5. 荣与辱

荣辱观具有：

**鲜明的导向和调节作用**。

一个人认为什么值得荣耀、什么值得羞耻，会直接影响行为选择。


## 十七、必须反对三种错误人生观

这里要重点掌握：

**拜金主义、享乐主义、极端个人主义**。

它们共同的问题是：

**没有正确把握个人与社会的辩证关系，具有极端、狭隘、片面的特点，出发点和落脚点都是一己私利**。

### 拜金主义

不是“承认金钱有用”就叫拜金主义。

错误在于：

**把金钱看成可以主宰一切，把追逐金钱作为人生唯一目的，把金钱作为衡量人生价值的唯一标准**。

所以看到“唯一目的”“唯一标准”这种绝对化表述，要非常敏感。


### 享乐主义

不是说不能享受正常生活。

问题在于：

**把享乐尤其感官享乐变成人生的唯一目的**。

典型表现就是只求享受、不愿奋斗，攀比消费、讲排场，甚至超出个人和家庭承受能力。

所以政治教材反对的不是幸福生活，而是**把享乐绝对化、目的化**。


### 极端个人主义

资料进一步指出：

**个人主义是生产资料私有制的产物，是资产阶级人生观的核心；极端个人主义是个人主义的一种表现形式**。

它把个人放在中心，在个人与他人、个人与社会关系中表现为：

**极端利己主义和狭隘功利主义**。

同样需要注意：

政治教材并不等于否认个人正当利益。

它反对的是把个人利益**绝对化、唯一化**，为了自己利益损害他人与社会。


## 十八、这一章最后落到哪里——成就出彩人生

前面讲了这么多，最终不是停留在“知道正确人生观”，而是要变成实践。

教材总结了三层意思。

第一，**把小我融入大我**。当代青年只有把自己的小我融入祖国的大我、人民的大我之中，与历史同向、与祖国同行、与人民同在，才能更好实现人生价值、升华人生境界。

第二，**在实践中创造有价值的人生**。教材的固定表述是：

**社会实践是实现人生价值的必由之路**。

第三，**在奋斗中创造幸福人生**。人世间的一切幸福都需要靠辛勤劳动创造，追求幸福本身就是不断追求和创造更美好生活的过程。

所以第一章最后实际上形成一个闭环：

> 人的本质是社会性的
> → 人不能脱离社会
> → 人生价值包含社会价值
> → 正确的人生追求是服务人民、奉献社会
> → 人生价值必须通过社会实践来实现
> → 最终把“小我”融入“大我”。

这就是本章最核心的理论逻辑。


## 十九、历年真题告诉我们本章到底怎么考

此处整理的真题非常典型，基本把本章最重要的“词语对应关系”全考过了。

| 真题         | 考点                 | 正确答案          |
| ---------- | ------------------ | ------------- |
| 2021 单选 13 | 个人与社会关系最根本的是什么     | **个人利益与社会利益** |
| 2019 单选 14 | 自我价值和社会价值          | **二者的统一**     |
| 2012 单选 13 | 人生目的回答什么           | **人为什么活着**    |
| 2017 单选 14 | 人生价值评价根本尺度         | **历史标准**      |
| 2013 单选 13 | 个人需要能否从社会得到满足取决于什么 | **社会价值**      |


你会发现，本章的真题特点非常明显：

**不是要求考生写哲学论文，而是精确地区分概念**。

例如：

“核心”“根本”“前提”“保障”“必由之路”“最重要标准”，这些词是不能随便换的。


## 二十、第一章最容易混淆的 12 个点

最后建议直接把这一组背下来：

1. **人的本质**：一切社会关系的总和。
2. **人的本质属性**：社会属性。
3. **认识和处理人生问题的重要着眼点和出发点**：个人与社会的关系。
4. **个人与社会关系最根本的关系**：个人利益与社会利益。
5. **人生观三个主要内容**：人生目的、人生态度、人生价值。
6. **人生观的核心**：人生目的。
7. **人生目的回答**：为什么活着。
8. **人生态度回答**：应当怎样活着。
9. **人生价值回答**：什么样的人生才有价值。
10. **高尚人生追求**：服务人民、奉献社会。
11. **人生价值评价根本尺度**：是否符合社会发展客观规律、促进历史进步，即历史标准。
12. **实现人生价值的必由之路**：社会实践。

如果把整章再压成一句做题口诀，可以记成：

> “**人是社会人，目的定人生；价值有两面，奉献看历史；实践出价值，奋斗创幸福**。”

这章真正需要你吃透的不是大量文字，而是“**人的社会性”这一根主线**：因为人是社会的人，所以个人离不开社会；因为个人离不开社会，所以人生价值不只是满足自己，还包含社会价值；因此正确人生追求最终落到服务人民、奉献社会，并通过实践和奋斗实现人生价值。
