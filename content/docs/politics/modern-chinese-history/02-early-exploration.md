## 一、为什么会出现这些“国家出路的探索”？

第一章解决的是一个前提问题：

**中国为什么落到半殖民地半封建社会**？

而第二章开始回答：

**落到这种境地以后，中国人准备怎么办**？

1840年以后，中国面临两对主要矛盾：

帝国主义和中华民族的矛盾，以及封建主义和人民大众的矛盾。

其中帝国主义和中华民族的矛盾是最主要的矛盾。因此，近代中国必须完成两大历史任务：首先实现**民族独立和人民解放**，然后才可能实现**国家富强和人民幸福**。这也是为什么简单的“实业救国”“教育救国”等方案无法独立解决中国问题。

于是不同阶级都根据自己的阶级地位，提出了自己的答案。

这也是理解本章最重要的一点：

> **不同阶级的方案为什么不同？根本上由它们自己的阶级地位和阶级局限决定**。

## 二、第一种探索：太平天国农民战争

### 1. 为什么首先是农民起来反抗？

太平天国爆发于 **1851—1864年**。

教材指出，鸦片战争以后，清政府为了支付战争赔款、弥补财政亏空，加重赋税；同时外国商品进入中国，自然经济逐渐解体，鸦片贸易进一步泛滥，造成白银外流、银贵钱贱，广大农民负担更加沉重。

所以这里实际上有两层压迫：

**国内封建统治的压迫 + 外国资本主义侵略带来的冲击**。

农民本来就是人口最多、受封建剥削最严重的阶级，在这种情况下自然最容易形成大规模反抗。

## 三、太平天国的发展过程

几个时间点不用背得特别碎，但下面这几个一定要认识：

| 时间      | 事件                 | 考试定位         |
| ------- | ------------------ | ------------ |
| 1851年1月 | 洪秀全在广西桂平县**金田村起义** | 太平天国运动开始     |
| 1853年3月 | 占领南京，改名**天京**      | 正式建立太平天国农民政权 |
| 定都天京后   | 北伐、西征              | 很快进入军事全盛时期   |
| 1856年9月 | **天京事变**           | **由盛转衰的分水岭** |
| 1864年   | 天京陷落               | 太平天国运动失败     |

特别容易考的是：

> **天京事变 = 太平天国由盛转衰的分水岭**。

不是太平天国失败的最终标志，而是“由盛转衰”。

教材明确作此定位。

## 四、太平天国最重要的两个文件

这是太平天国部分最值得认真学的地方：

《**天朝田亩制度**》和《**资政新篇**》。

这两个文件看起来都属于太平天国，但思想方向其实差别非常大，是考研政治非常喜欢进行对比的地方。

### 1. 《天朝田亩制度》

这是太平天国定都天京以后颁布的纲领性文件，而且是：

> **最能体现太平天国社会理想和这次农民起义特色的纲领性文件**。

它的核心问题只有一个：

> **土地**。

它希望平均分配土地，建立：

“有田同耕，有饭同食，有衣同穿，有钱同使，无处不均匀，无人不饱暖”

的理想社会。

因此教材给它的定位是：

> **一个以解决土地问题为中心的比较完整的社会改革方案**。

#### 它为什么有进步性？

因为中国封建社会经济基础的核心是**封建地主土地所有制**。

农民贫困的一个根本社会经济原因，就是土地大量掌握在地主手中。

而《天朝田亩制度》提出平均土地，实际上就是从根本上否定封建地主土地所有制。

所以它不是普通的“减税”“减租”，而是触及了封建经济制度的基础。

#### 它为什么又具有空想性？

关键在于，它所设想的并不是现代资本主义社会，更不是社会主义社会。

它想建立的是一种：

**平均土地 + 小农经济 + 家庭手工业 + 自给自足 + 没有商品交换 + 绝对平均**

的社会。

这还是传统的小生产经济。

所以教材认为，它：

> **没有超出农民小生产者的狭隘眼界**。

而且这种绝对平均主义现实中根本难以长期运行。

因此，《天朝田亩制度》即使在太平军实际控制地区，也没有真正贯彻实行。

## 五、《资政新篇》：完全不同的方向

1859年，洪仁玕来到天京，提出《资政新篇》。

它的重要定位一定要记：

> **中国近代史上第一个比较系统的发展资本主义的方案**。

注意关键词：

**第一个 + 比较系统 + 发展资本主义**。

它和《天朝田亩制度》的方向几乎完全不同。

| 比较     | 《天朝田亩制度》  | 《资政新篇》        |
| ------ | --------- | ------------- |
| 思想基础   | 农民平均主义    | 近代资本主义思想      |
| 核心问题   | 土地        | 近代化和资本主义发展    |
| 经济方向   | 小农经济、自给自足 | 工矿、交通、银行、雇佣劳动 |
| 商品经济   | 排斥        | 发展            |
| 体现阶级特征 | 典型农民阶级理想  | 有明显资本主义色彩     |
| 是否真正实施 | 没有        | 也没有           |

《资政新篇》的内容非常现代化。

政治上，主张加强中央集权，并学习西方制定法律和制度。

经济上，主张发展近代工矿、交通、邮政、银行，奖励科技发明和机器制造。

尤其值得注意的是，它提出富人可以雇工，穷人通过劳动领取工资，相当于把学习西方从单纯的技术层面推进到了**资本主义雇佣劳动关系**。

文化上，提出新闻、学校、医院、社会福利等。

外交上，主张与外国平等交往、自由通商，同时严禁鸦片。

所以教材评价：

> 《资政新篇》是一个**具有资本主义色彩的方案**，在近代中国向西方学习、追求近代化的过程中具有重要意义。

## 六、一个特别容易混淆的问题：《资政新篇》是不是太平天国的实际政策？

**不是**。

它虽然得到洪秀全赞同并颁布，但由于当时战争环境和历史条件限制，并没有真正付诸实施。

所以看到类似选项：

“《资政新篇》是太平天国后期得到全面贯彻的实际政策”

直接判错。

同样，《天朝田亩制度》中的平均土地方案实际上也没有真正贯彻。

因此两部文件有一个共同特点：

> **都没有真正得到全面实施**。

## 七、太平天国有什么历史意义？

这部分很适合材料题或多选题。

教材总结了五个方面。

第一，**沉重打击封建统治阶级，强烈撼动清政府统治根基**。

第二，太平天国是：

> **中国旧式农民战争的最高峰**。

为什么是“最高峰”？

因为它不仅规模巨大，而且第一次把传统农民要求土地的愿望比较完整地写入《天朝田亩制度》，后期甚至出现《资政新篇》这种近代资本主义色彩的方案。

因此它具有不同于传统农民战争的新特点。

第三，它冲击了**孔子和儒家经典的正统权威**，在一定程度上削弱封建统治的精神支柱。

第四，它还**打击了外国侵略势力**。

第五，在19世纪中叶亚洲民族解放运动中，它是：

> **时间最久、规模最大、影响最深的一次**。

因此它同时对西方殖民主义在亚洲的统治形成冲击。

## 八、为什么太平天国最后还是失败了？

这里一定区分：

**客观原因**和**根本的主观原因**。

客观原因是：

> **中外反动势力联合绞杀**。

但考试问“根本原因”，不能选这个。

根本原因是：

> **农民阶级自身的局限性**。

为什么？

因为农民阶级本身不是新的生产力和新的生产关系的代表者。

它可以猛烈反抗旧社会，却很难提出一个真正先进、科学、可持续的新社会制度。

所以教材进一步指出：农民阶级无法克服小生产者阶级局限，缺乏科学理论指导，也没有先进阶级领导，因此难以提出完整、正确的政治纲领和社会改革方案。

除此之外，太平天国后期还出现领导集团腐败和内部分裂、军事战略失误、拜上帝教无法提供科学指导、没有正确对待儒学、没有正确认识西方资本主义侵略者等问题。

因此太平天国给近代中国留下的核心教训是：

> **农民具有伟大的革命潜力，但农民阶级自身不能担负领导反帝反封建斗争取得胜利的重任；单纯的农民战争不能完成民族独立和人民解放的历史任务**。

这句话非常重要。

注意教材绝不是说：

“农民不重要”。

而是说：

**农民是重要革命力量，但农民阶级不能成为近代民主革命最终取得胜利的领导阶级**。

以后学习新民主主义革命，可以看到：

**农民仍然是中国革命的主力军，但领导者变成了无产阶级及其政党**。

## 九、第二种探索：洋务运动

太平天国把清政府打得摇摇欲坠，第二次鸦片战争又让清政府再次看到西方“船坚炮利”。

清朝统治集团内部的一部分人开始意识到：

> 再完全拒绝西方技术，清政府可能连政权都保不住。

于是出现洋务派。

代表人物主要包括奕䜣、曾国藩、李鸿章、左宗棠、张之洞等。

洋务运动大约从**19世纪60年代到90年代**，持续30多年。

## 十、洋务运动最容易考的四个概念

这几个概念一定不能混。

| 问什么              | 答什么                  |
| ---------------- | -------------------- |
| 洋务运动的**主要、根本目的** | **维护、挽救清政府的封建统治**    |
| 最初最直接的目的         | 制造、购买洋枪洋炮，**镇压农民起义** |
| 洋务运动的**指导思想**    | **中学为体，西学为用**        |
| 洋务运动的**目标**      | **自强、求富**            |

2018年真题直接问：

“洋务派兴办洋务新政的主要目的是什么？”

答案就是：

> **维护封建统治**。

不是发展资本主义。

这是一个极典型的史纲陷阱：

**客观结果 ≠ 主观目的**。

洋务运动客观上促进了民族资本主义发展，但洋务派主观上并不是为了发展资本主义。

## 十一、什么叫“中学为体，西学为用”？

这是理解洋务运动成败最核心的概念。

所谓：

> **中体西用**

就是：

以中国封建伦理纲常以及它维护的政治统治秩序作为“体”，即根本；

把西方近代军事技术、工业技术等作为“用”，即工具。

简单说就是：

> **制度不能变，技术可以学**。

他们并不是想把中国改造成英国、法国那样的资本主义国家，而是希望：

**用资本主义国家的先进技术，让中国原来的封建统治活得更久**。

这就是洋务运动的内在矛盾。

它想引进新的生产力，却不愿改变旧的生产关系和上层建筑。

教材把这看作洋务运动最终失败的根本制度性原因。

## 十二、“自强”和“求富”是什么关系？

早期重点是：

> **自强**。

主要发展军事工业，解决“打不过别人”“镇压不了农民起义”的问题。

后来洋务派发现：

造军舰、枪炮需要大量资金，军用工业本身又无法持续盈利。

于是后期提出：

> **求富**。

发展民用工业，希望提供财政和经济支撑。

所以记成：

> **前期自强——军事；后期求富——民用**。

## 十三、洋务运动到底干了什么？

教材把洋务事业归纳为三大方面。

| 领域   | 主要内容    | 高频考点                           |
| ---- | ------- | ------------------------------ |
| 近代企业 | 先军用，后民用 | 军用工业官办；多数官督商办民用企业基本属**资本主义性质** |
| 新式军队 | 新式陆军、海军 | 福建、广东、南洋、**北洋水师**；北洋水师为主力      |
| 新式教育 | 学堂、留学生  | 翻译学堂、工艺学堂、军事学堂                 |

### 1. 军用工业

洋务派首先发展军用工业。

这些军用企业主要是**官办**。

本质上是利用国家权力发展近代军事生产能力。

## 十四、为什么洋务派后来又发展民用企业？

因为军工产业要花很多钱。

铁路、煤矿、轮船、电报等民用产业一方面可以服务军工，另一方面也能提供收入。

这些民用企业有官办、官商合办，也有大量“官督商办”。

考试尤其爱问：

> 洋务运动中采取官督商办方式的民用企业基本属于什么性质？

答案：

> **资本主义性质的近代企业**。

2021年真题就直接考过，答案是 C。

这里特别容易错成“封建主义性质”。

为什么不能因为洋务派是地主阶级，就说企业一定是封建企业？

因为判断一个企业的经济性质，要看它采用什么生产关系和经营方式，而不是只看是谁主持的。

## 十五、新式海陆军

洋务派引进西式武器装备军队，又开始筹建海军。

后来形成：

福建水师、广东水师、南洋水师、北洋水师。

其中最重要的是：

> **北洋水师是清政府海军主力**。

后面甲午战争失败，北洋海军全军覆没，于是成为洋务运动失败的象征。

## 十六、新式教育

洋务派为了培养懂外语、懂军事、懂技术的人才，又创办新式学校。

教材主要归纳为三类：

| 类型   | 典型内容         |
| ---- | ------------ |
| 翻译学堂 | 如**京师同文馆**   |
| 工艺学堂 | 电报、铁路、矿务、西医等 |
| 军事学堂 | 如船政学堂等       |

同时还派赴美幼童和赴欧留学生。

有一个经典干扰项：

> **法政学堂**

洋务时期的新式学堂主要是翻译、工艺、军事三类，真题中法政学堂不能选。

2012年真题答案为 **ABC**。

这背后的逻辑也很好理解：

洋务派主要愿意学习**技术、军事、实用知识**，并不准备系统学习西方政治制度。

## 十七、洋务运动有没有意义？

有，而且不能因为它失败就说它“一无是处”。

这是政治选择题特别喜欢设计的陷阱。

洋务运动有三大客观作用。

第一，它客观上促进了中国早期工业和民族资本主义发展。

第二，创办新式学堂、派留学生、翻译西方自然科学著作，带来新知识，因此：

> **洋务运动时期是中国近代教育的开始**。

第三，它冲击了传统“重本抑末”“奇技淫巧”等观念，提高工商业者的社会地位，推动社会风气改变。

在复习资料中还特别强调：

> **洋务运动是中国近代化的开始**。

这里一定和另一个概念区分：

| 概念            | 对应事件   |
| ------------- | ------ |
| **中国近代史的起点**  | 鸦片战争   |
| **中国近代化的开始**  | 洋务运动   |
| **中国近代教育的开始** | 洋务运动时期 |

非常容易串。

## 十八、洋务运动为什么失败？

1894—1895年中日甲午战争中：

> **北洋海军全军覆没**。

这标志着历时30多年的洋务运动失败。

失败原因非常经典，可以直接记成三个词：

**封建性、依赖性、腐朽性**。

#### 封建性

它引进资本主义生产技术，却试图服务封建制度。

新的生产力和旧的封建生产关系、上层建筑发生冲突。

这是最本质的一层。

#### 依赖性

洋务派大量依赖外国设备、技术和人员。

可是西方列强根本不希望中国真正独立富强。

所以依靠侵略中国的列强帮助中国实现“自强”，本身就是矛盾的。

#### 腐朽性

虽然办的是“近代企业”，很多管理方法却仍然是封建衙门式管理，官僚主义、贪腐严重。

2010年真题考过洋务运动失败原因，正确选项就是：

> **封建性 + 对外国依赖性 + 管理腐朽性**。

“资金人才匮乏”不是教材归纳的主要原因。

## 十九、洋务运动真正告诉我们什么？

这句话值得直接记：

> **在维持封建经济基础和封建上层建筑的前提下，仅仅依靠学习西方近代技术来“自强”“求富”，这条道路走不通**。

所以历史探索继续往前推进。

洋务派说：

> “制度别动，学技术就够了。”

甲午战争却证明：

> **只学“器物”不够**。

于是先进知识分子开始追问：

> 西方强大是不是不仅因为枪炮，更与政治制度有关？

于是就进入第三种探索——戊戌维新。

## 二十、第三种探索：戊戌维新运动

戊戌维新的大背景是：

> **甲午战争惨败**。

甲午战争以后，中国民族危机进一步加深，而且民族意识开始普遍觉醒。

与此同时，中国民族资本主义得到初步发展，民族资产阶级开始提出自己的政治要求。

于是中国向西方学习开始发生明显升级：

> **从学习军事和科学技术，推进到学习政治制度和思想文化**。

这是理解“洋务→维新”的关键。

## 二十一、维新派有哪些主要人物？

最典型的是：

**康有为、梁启超、谭嗣同、严复**。

他们采取上书皇帝、著书立说、办学会、设学堂、办报纸等方式宣传维新思想。

例如著名的“公车上书”。

但是他们有一个非常重要的战略特点：

> **重点争取光绪皇帝及其周围帝党官员，希望依靠统治者自上而下进行改革**。

这一点后来恰恰成为其失败的重要原因之一。

## 二十二、维新派和洋务派到底有什么根本区别？

这是2013年考研政治真题。

两派并不是：

一个要学习西方，一个不学习西方。

他们都主张学习西方。

真正的分歧是：

> **学习西方究竟只学技术，还是连政治制度和思想文化也要学**。

洋务派：

> 中体西用。

维新派：

> 仅靠“中体西用”已经不够，中国还必须改变政治制度。

2013年真题答案因此是：

> **D：要不要学习西方的政治制度与思想文化**。

## 二十三、维新派想建立什么制度？

维新派不是辛亥革命时期的革命派。

所以不要选“民主共和”。

他们主张：

> **君主立宪制**。

也就是皇帝还可以存在，但皇权应受宪法、议会和制度限制。

因此：

| 政治力量       | 政治制度主张   |
| ---------- | -------- |
| 洋务派        | 保持封建君主专制 |
| 维新派        | **君主立宪** |
| 后来的资产阶级革命派 | **民主共和** |

2022年真题直接问：

维新派突破“中体西用”，主张什么？

答案就是：

> **用君主立宪制取代君主专制制度**。

## 二十四、维新派和守旧派的论战

维新思想越来越活跃以后，封建守旧派和反对改变政治制度的洋务派开始攻击维新派。

双方围绕三个问题争论：

| 论战问题              | 本质         |
| ----------------- | ---------- |
| 要不要变法             | 是否改革旧制度    |
| 要不要兴民权、设议院、实行君主立宪 | 是否改革政治制度   |
| 要不要废八股、改科举、兴西学    | 是否改革思想文化教育 |

这一场论战有一个非常重要的定位：

> **资产阶级思想与封建主义思想在中国的第一次正面交锋**。

注意：

**第一次正面交锋**。

不要和后面革命派、改良派的论战混在一起。

通过这次论战，西方资产阶级社会政治学说进一步传播，人们思想得到解放，为戊戌变法作了思想准备。

## 二十五、百日维新

1898年6月11日，光绪皇帝颁布“明定国是”诏书，开始变法。

之后持续了：

> **103天**。

因此称：

**戊戌变法**，又叫**百日维新**。

维新政令涉及政治、经济、军事、文化教育等多个方面。

但是要特别注意：

它并没有真正彻底改革封建制度。

教材明确指出，它是一种：

> **十分温和、不彻底的改革方案**。

比如它没有真正实现开国会、定宪法等最核心的制度主张，也没有触及封建制度的根本。

因此尽管它具有资本主义性质，但准确说法是：

> **资产阶级性质的政治改良运动**。

不是资产阶级革命。

2019年真题问：

为什么说戊戌维新是资产阶级性质的改良运动？

答案不是因为它“彻底推翻封建制度”，而是：

> **其政令在一定程度上反映了资产阶级的政治和经济诉求**。

## 二十六、戊戌政变

1898年9月21日，以慈禧太后为首的守旧势力发动政变。

慈禧重新掌权，光绪皇帝被软禁，康有为、梁启超逃亡，“戊戌六君子”被杀。

百日维新最终失败。

除了：

> **京师大学堂**

被保留下来以外，大多数新政措施被废除。

所以看到选择题：

“戊戌政变后维新措施全部废除”

要警惕。

因为还有：

> **京师大学堂保留下来**。

## 二十七、戊戌维新的三个历史性质

这一部分非常适合多选。

戊戌维新同时具有三个性质。

| 性质                | 为什么                |
| ----------------- | ------------------ |
| **爱国救亡运动**        | 民族危亡背景下要求救亡图存、富国强兵 |
| **资产阶级性质的政治改良运动** | 要求君主立宪，推动资本主义发展    |
| **思想启蒙运动**        | 传播西方政治学说、民主思想和自然科学 |

第一，它是一场**爱国救亡运动**，推动中华民族觉醒。

第二，它是一场**资产阶级性质的政治改良运动**，突破洋务派“中体西用”的局限。

第三，它是一场**思想启蒙运动**，传播西方资产阶级政治学说和自然科学知识，促进民主思想传播，并推动社会风气改变。

因此第二章出现了一个非常重要的思想史升级：

> **洋务运动更多停留在“技术、器物”层面；维新运动则明确进入“政治制度、思想文化”层面**。

## 二十八、为什么戊戌维新失败？

这里同样分客观、主观两方面。

客观上：

> **以慈禧太后为首的封建守旧势力十分强大**。

但是从更深层看，是因为当时中国民族资产阶级自身力量弱小。

民族资本主义发展程度很低，维新派没有军队、没有掌握实际国家权力、组织也很薄弱。

于是形成教材特别强调的三大局限。

| 局限            | 具体表现                                 |
| ------------- | ------------------------------------ |
| **不敢否定封建主义**  | 政治上没有彻底否定君主专制，经济上没有触及封建土地所有制，思想上托古改制 |
| **对帝国主义抱有幻想** | 希望列强帮助、支持中国变法                        |
| **惧怕人民群众**    | 没有发动群众，把希望寄托在无实权的光绪帝身上               |

2016年真题就围绕“维新派为什么无力回天”出过多选题，守旧势力强大、惧怕群众、不敢触及封建主义经济基础都是正确原因。

## 二十九、戊戌维新最大的历史教训

教材结论非常明确：

> **在半殖民地半封建的旧中国，企图通过统治者实行自上而下的改良，实现国家独立、民主和富强，根本行不通**。

这就和洋务运动的教训形成递进：

洋务运动证明：

> **只学技术，不改制度不行**。

维新运动进一步证明：

> **即使提出政治制度改革，如果依靠封建统治者、脱离广大人民群众，走温和改良道路，也不行**。

于是下一章自然就出现了新的问题：

> 既然改良不行，是不是要直接进行革命？

这正是第三章**辛亥革命与君主专制制度的终结**要解决的问题。

## 三十、把三大探索放在一起理解

这是整章最重要的一张表。

| 项目      | 太平天国           | 洋务运动        | 戊戌维新               |
| ------- | -------------- | ----------- | ------------------ |
| 时间大致    | 1851—1864      | 19世纪60—90年代 | 1898               |
| 领导阶级    | 农民阶级           | 地主阶级洋务派     | 民族资产阶级维新派          |
| 基本方式    | 农民战争           | 封建自救        | 政治改良               |
| 是否反清    | 是              | 否           | 否                  |
| 是否学习西方  | 后期《资政新篇》有明显学习  | 学技术         | 学技术+制度+思想          |
| 核心文件/思想 | 《天朝田亩制度》《资政新篇》 | 中体西用        | 君主立宪               |
| 核心目标    | 农民理想社会         | 自强、求富       | 救亡图存、变法维新          |
| 最大局限    | 农民阶级局限         | 不改变封建制度     | 民族资产阶级软弱、依赖皇权、脱离群众 |
| 最终结论    | 单纯农民战争不行       | 封建自救不行      | 自上而下改良不行           |

教材最后本身也用三种探索进行横向总结：太平天国说明单纯农民战争不能完成民族独立和人民解放；洋务运动说明在维持封建生产关系和上层建筑的条件下靠学习西方技术来自强求富行不通；戊戌维新则说明依靠统治者走自上而下改良道路行不通。

## 三十一、为什么三种探索都失败？——理解本章的最高层逻辑

如果只背事件，会觉得这一章只是：

“太平天国失败了，洋务失败了，戊戌也失败了。”

实际上教材是在用三个失败逐步说明一个更大的历史问题。

近代中国面临的不是单纯的：

> “技术落后。”

而是一个完整的**半殖民地半封建社会结构问题**。

因此，仅解决其中某一个局部问题是不够的。

太平天国看到的是：

> **封建土地关系和农民贫困**。

但农民阶级本身无法提出先进完整的现代国家方案。

洋务派看到的是：

> **军事技术和工业落后**。

但是它不愿改变封建制度。

维新派进一步看到：

> **政治制度也必须改革**。

但是民族资产阶级过于软弱，既不敢彻底反封建，又依赖皇帝、幻想帝国主义支持，还不敢发动广大人民群众。

所以三个方案依次失败。

可以把它概括成一条非常清晰的认识深化：

> **农民战争 → 技术自强 → 制度改良 → 接下来走向资产阶级革命**。

但第三章又会继续说明：

> **资产阶级革命虽然比维新改良进一步，却依然不能最终完成反帝反封建的历史任务**。

于是历史才继续发展到五四运动、中国共产党成立和新民主主义革命。

这就是前三章乃至整个旧民主主义革命史的总逻辑。

## 三十二、第二章最容易出的真题陷阱

史纲选择题特别喜欢把“本身正确但属于另一个事件”的说法拿来做干扰项，资料的考情分析也特别强调要用**对比**学习。

所以这一章至少要重点记住下面这些对应关系：

| 以土地问题为中心            | 《天朝田亩制度》             |
| 中国近代第一个比较系统发展资本主义方案 | 《资政新篇》               |

## 三十三、结合真题看看出题人怎么考

近年和历年真题对本章的考查高度集中在“概念辨析”。

**2021年第9题**：官督商办的民用企业基本是什么性质？

答案：**资本主义性质**。

**2018年第10题**：洋务派办洋务主要目的？

答案：**维护封建统治**。

**2012年第27题**：洋务派新式学堂包括哪些？

答案：**翻译、工艺、军事；不包括法政学堂**。

**2010年第26题**：洋务运动失败主要原因？

答案：**封建性、依赖性、管理腐朽性**。

**2013年第9题**：维新派与洋务派分歧实质？

答案：**要不要学习西方政治制度和思想文化**。

**2022年第9题**：维新派突破“中体西用”以后主张什么？

答案：**君主立宪取代君主专制**。

**2019年第9题**：为什么说戊戌维新是资产阶级性质的改良？

答案：**变法政令一定程度上反映了资产阶级政治和经济诉求**。

可以发现，本章真正要求的不是背一堆年份，而是把：

**谁、为什么做、做什么、做到哪一步、为什么失败、说明什么**

完整对应起来。
