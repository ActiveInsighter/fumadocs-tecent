## 一、先把第十章的整条历史主线串起来

这章其实只需要先记住这样一条线：

**十八大开启新时代 → 十九大确立新时代重大理论和政治判断 → 十九届四中全会推进制度和治理现代化 → 脱贫攻坚、全面小康完成 → 十九届六中全会总结百年奋斗 → 二十大转入全面建设社会主义现代化国家 → 二十届三中全会进一步全面深化改革**。

把它具体化就是：

| 时间           | 历史事件             | 最核心考点                                      |

| **2012年11月** | 党的十八大            | 开启中国特色社会主义新时代；进入全面建成小康社会决定性阶段              |

## 二、考点93：党的十八大——全面建成小康社会目标的确定

2012年11月，党的十八大召开。

理解十八大，首先要抓住一个核心：

> **党的十八大精神归结到一点，就是坚持和发展中国特色社会主义**。

《精讲精练》归纳了十八大的几个主要内容：阐明中国特色社会主义的**总依据、总布局、总任务**；阐明中国特色社会主义道路、理论体系、制度的科学内涵及其相互关系；在十六大、十七大提出的“全面建设小康社会”基础上，提出确保到2020年实现**全面建成小康社会**。

这里特别容易考一个字：

**全面建设小康社会 → 全面建成小康社会**。

“建设”强调过程，“建成”强调结果。

从史纲的历史分期看，党的十八大召开后，中国特色社会主义进入新时代。《精讲精练》表述为：十八大的召开标志着中国进入全面建成小康社会的决定性阶段，开启了中国特色社会主义新时代，新时代成为我国发展的新的**历史方位**。

这里有个特别容易困惑的地方：

**为什么说2012年十八大进入新时代，但2017年十九大又提出“中国特色社会主义进入新时代**”？

可以理解为：

**十八大开启新时代的历史实践；十九大在总结十八大以来五年实践基础上，对“中国特色社会主义进入新时代”作出正式、系统的重大政治判断**。

所以选择题看到“十八大开启新时代”不要判错；看到“十九大作出中国特色社会主义进入新时代重大政治论断”也不要判错。

## 三、考点94：党的十九大——新时代重大理论和政治判断集中确立

2017年10月，党的十九大召开。

这是本章非常重要的会议。

《精讲精练》给十九大概括了五个主要贡献，其中最需要掌握的是：

**确立习近平新时代中国特色社会主义思想的指导地位；作出中国特色社会主义进入新时代、我国社会主要矛盾发生转化的重大政治论断；部署决胜全面建成小康社会并开启全面建设社会主义现代化国家新征程；提出新时代党的建设总要求；修改党章，把习近平新时代中国特色社会主义思想写入党章，确立为党的行动指南**。

这里一定注意两个时间点不要混：

**2016年十八届六中全会**明确习近平同志党中央的核心、全党的核心地位；

**2017年党的十九大**把习近平新时代中国特色社会主义思想确立为党必须长期坚持的指导思想。

## 四、新时代最重要的历史方位变化：社会主要矛盾发生变化

虽然《精讲精练》史纲第十章没有把这一块全部重复展开，但它明确把它作为十九大的重大政治判断之一。

进入新时代，我国社会主要矛盾转化为：

> **人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾**。

要重点理解两边分别变了什么。

过去说的是：

**人民日益增长的物质文化需要 ↔ 落后的社会生产**。

新时代变成：

**美好生活需要 ↔ 不平衡不充分的发展**。

为什么需求从“物质文化”变成“美好生活”？

因为人民的需求已经不仅是“有没有”，还越来越关心“好不好”，涉及民主、法治、公平、正义、安全、环境等更加广泛的方面。

为什么供给侧从“落后的社会生产”变成“不平衡不充分的发展”？

因为我国生产力水平已经总体显著提高，问题越来越表现为不同地区、城乡、领域发展不平衡，以及某些领域发展质量不高、不充分。

真题就经常围绕这个逻辑命题。资料中的真题明确强调：中国特色社会主义进入新时代后，人民群众不仅关注“有没有”，更关注“好不好”；这种变化反映的是我国社会主要矛盾发生历史性变化。

但是最重要的陷阱是：

**主要矛盾变了，不等于社会主义初级阶段变了**。

我国仍处于并将长期处于社会主义初级阶段，我国仍然是世界最大发展中国家。

所以：

**主要矛盾变 = 阶段内部发生历史性变化；基本国情没有根本改变**。

## 五、考点95：党的全面领导——新时代最根本的政治保证

这一部分是本章真正考过真题的重点。

十九大把一个重大政治原则写入党章：

> **中国特色社会主义最本质的特征是中国共产党领导**。

同时：

> **中国特色社会主义制度的最大优势是中国共产党领导**。

以及：

> **党是最高政治领导力量**。

十九大又把“坚持党对一切工作的领导”放在新时代坚持和发展中国特色社会主义基本方略的第一条。

这三个表述一定不要换位置：

| 问法                  | 答案       |
| ------------------- | -------- |
| 中国特色社会主义**最本质的特征**  | 中国共产党领导  |
| 中国特色社会主义制度的**最大优势** | 中国共产党领导  |
| 最高政治领导力量            | 中国共产党    |
| 实现中华民族伟大复兴的根本保证     | 中国共产党的领导 |

为什么这一点在史纲里特别重要？

因为史纲从1840年一路讲下来，其实一直在回答一个问题：

**谁能够领导中国人民完成民族独立、人民解放、国家富强、人民幸福**？

太平天国失败、洋务运动失败、戊戌维新失败、辛亥革命最终没有改变中国半殖民地半封建社会性质；而中国共产党成立后，中国革命面貌发生根本变化。

因此到第十章回头看整个中国近现代史，就会得到一个历史结论：

**中国人民和中华民族能够扭转近代以来的历史命运，最根本的是有中国共产党的坚强领导**。相关资料也将党的领导概括为实现中华民族伟大复兴的根本保证。

## 六、考点95的第二部分：为什么新时代特别强调“自我革命”

这是高频点，而且2024年真题直接考过。

中国共产党不仅要领导伟大的**社会革命**，还必须不断进行伟大的**自我革命**。

两者可以这样理解：

**社会革命解决“改造社会、推动事业发展”的问题；自我革命解决“党自身怎样始终先进、纯洁、有力量”的问题**。

为什么执政时间越长，反而越要自我革命？

因为长期执政以后，权力、利益、腐败、脱离群众、精神懈怠等风险都可能出现。如果自身不能不断发现问题、纠正问题，就可能丧失先进性和执政能力。

因此教材给出的几个高频表述必须记住：

**勇于自我革命，是中国共产党区别于其他政党的显著标志；是党跳出治乱兴衰历史周期率、历经百年沧桑更加充满活力的成功秘诀；全面从严治党是新时代党的自我革命的伟大实践**。

再向“习思想”联动一个非常重要的知识点：

毛泽东当年在延安窑洞谈如何跳出历史周期率，给出的第一个答案是：

**让人民监督政府**。

新时代经过实践探索，我们党找到的第二个答案是：

**自我革命**。

## 七、2024年真题：这一考点到底怎么出题

2024年史纲多选第29题直接考：

关于党的自我革命，哪些表述正确？

其中包括：

A. 勇于自我革命是中国共产党区别于其他政党的显著标志
B. 自我革命精神是党永葆青春活力的强大支撑
C. 所有政党都是在不断自我革命中淬炼而成的
D. 自我革命是我们党跳出治乱兴衰历史周期率的第二个答案

答案是：

**A、B、D**。

C为什么错？

因为“所有政党”是典型的过度扩大。教材强调的是**中国共产党勇于自我革命的鲜明政治品格**，并不能推出所有政党都通过自我革命发展壮大。

这道题很好地体现了史纲现在的命题特点：

不是单纯考查“哪一年发生什么”，而是用历史材料考你对历史结论的理解。

## 八、考点96：十九届四中全会——制度优势与治理现代化

2019年10月，十九届四中全会召开。

主题一定要原句掌握：

> **坚持和完善中国特色社会主义制度、推进国家治理体系和治理能力现代化**。

会议最重要成果是通过：

《中共中央关于坚持和完善中国特色社会主义制度、推进国家治理体系和治理能力现代化若干重大问题的决定》。

这个决定集中回答了一个非常重要的问题：

> **在我国国家制度和国家治理上，应该“坚持和巩固什么，完善和发展什么**”。

教材将这一决定评价为坚持和完善中国特色社会主义制度、推进国家治理体系和治理能力现代化的**政治宣言和行动纲领**。

这里要理解“制度”和“治理能力”不是一回事。

**制度体系**可以理解为“我们按照什么规则治理国家”；

**治理能力**则是“能不能把这些制度真正运行好”。

所以不能认为：

“有好的制度 → 自动产生好的治理效果。”

还需要把制度优势转化为治理效能。

这也是新时代为什么不仅强调“制度自信”，还强调“国家治理体系和治理能力现代化”。

## 九、考点97：脱贫攻坚全面胜利——全面小康的关键组成部分

2021年2月25日，全国脱贫攻坚总结表彰大会召开。

庄严宣告：

> **我国脱贫攻坚战取得了全面胜利**。

农村贫困人口全部脱贫，这对全面建成小康社会具有关键作用；同时，教材还特别强调我国创造了减贫治理的中国样本，为全球减贫事业作出了重大贡献。

这里史纲非常喜欢把“中国意义”和“世界意义”一起考：

对中国而言，它直接关系全面小康和共同发展；

对世界而言，它形成减贫治理的中国经验，为全球减贫事业作出贡献。

## 十、2021年7月1日：全面建成小康社会——第一个百年奋斗目标实现

2021年7月1日，庆祝中国共产党成立100周年大会召开。

正式宣告：

**全面建成小康社会，实现第一个百年奋斗目标**。

这句话一定要形成固定搭配：

**第一个百年奋斗目标 = 全面建成小康社会**。

接下来：

**第二个百年奋斗目标 = 全面建成社会主义现代化强国**。

全面建成小康社会的历史意义，《精讲精练》概括得非常完整：

它实现了中华民族千百年来的夙愿，是迈向中华民族伟大复兴的关键一步，为实现第二个百年奋斗目标奠定坚实基础，实现了中华民族从大幅落后于时代到大踏步赶上时代的新跨越，同时也是对人类社会的重大贡献。

所以不要把“小康社会”看成单纯经济指标。

在史纲的历史纵深中，它的意义是：

1840年以来中国长期积贫积弱；

1949年解决“站起来”；

改革开放推动“富起来”；

全面建成小康社会则成为从“富起来”进一步迈向“强起来”的重大历史节点。

## 十一、考点98：“四新一高”怎么理解

这一考点标题非常长：

**把握新发展阶段、贯彻新发展理念、构建新发展格局、推动高质量发展**。

在史纲里，《精讲精练》没有重复展开，而是直接要求去“习近平新时代中国特色社会主义思想概论”第六章学习。

因此史纲复习只需要先建立历史联系：

**全面建成小康社会 → 第一个百年目标完成 → 开启全面建设社会主义现代化国家新征程 → 进入新发展阶段**。

资料明确指出，全面建成小康社会、实现第一个百年奋斗目标之后，乘势而上开启全面建设社会主义现代化国家新征程，标志着我国进入一个**新发展阶段**。

“新发展理念”则是：

**创新、协调、绿色、开放、共享**。

对应关系是：

| 理念 | 核心解决的问题  |
| -- | -------- |
| 创新 | 发展动力     |
| 协调 | 发展不平衡    |
| 绿色 | 人与自然和谐共生 |
| 开放 | 发展内外联动   |
| 共享 | 社会公平正义   |

其中几个高频“唯一搭配”尤其要记：

**创新——第一动力；协调——持续健康发展的内在要求；绿色——永续发展的必要条件；开放——国家繁荣发展的必由之路；共享——中国特色社会主义的本质要求**。

“新发展格局”指：

> **以国内大循环为主体、国内国际双循环相互促进**。

历年真题已经直接考过这一固定表述。

最后落脚到：

**高质量发展**。

它不是简单追求GDP速度，而是从“有没有”转向“好不好”，强调能够更好满足人民美好生活需要的发展。资料还特别强调：高质量发展是全面建设社会主义现代化国家的**首要任务**。

所以这一整套关系可以压缩成：

**阶段决定我们“站在哪里” → 理念解决“怎样发展” → 格局解决“怎样组织经济循环” → 高质量发展解决“要什么样的发展**”。

## 十二、考点99：十九届六中全会——为什么叫“第三个历史决议”

2021年11月，党的十九届六中全会召开。

最重要成果：

> 《中共中央关于党的百年奋斗重大成就和历史经验的决议》

这被称为中国共产党历史上的**第三个历史决议**。

三个历史决议可以这样比较：

| 时间    | 会议      | 文件                         | 主要历史作用                      |
| ----- | ------- | -------------------------- | --------------------------- |
| 1945年 | 六届七中全会  | 《关于若干历史问题的决议》              | 总结建党以来特别是六届四中全会至遵义会议前党的历史经验 |
| 1981年 | 十一届六中全会 | 《关于建国以来党的若干历史问题的决议》        | 科学评价新中国成立以来历史特别是毛泽东和毛泽东思想   |
| 2021年 | 十九届六中全会 | 《中共中央关于党的百年奋斗重大成就和历史经验的决议》 | 全面总结党的百年奋斗重大成就和历史经验         |

这一部分之所以特别重要，是因为它把前面史纲几乎所有章节重新总结了一遍。

## 十三、四个历史时期的“主要任务”一定要会对比

十九届六中全会《决议》把党的百年奋斗划分为四个大的历史时期。

这四段实际上就是你学史纲的总框架：

| 历史时期              | 时间        | 主要任务                       | 对民族复兴的贡献                      |
| ----------------- | --------- | -------------------------- | ----------------------------- |
| 新民主主义革命时期         | 1921—1949 | 反帝、反封建、反官僚资本主义，争取民族独立、人民解放 | 创造**根本社会条件**                  |
| 社会主义革命和建设时期       | 1949—1978 | 实现从新民主主义到社会主义转变，推进社会主义建设   | 奠定**根本政治前提和制度基础**             |
| 改革开放和社会主义现代化建设新时期 | 1978—2012 | 解放和发展生产力，使人民摆脱贫困、尽快富裕起来    | 提供**新的活力的体制保证和快速发展的物质条件**     |
| 中国特色社会主义新时代       | 2012—     | 实现第一个百年目标，开启第二个百年目标新征程     | 提供**更完善制度保证、更坚实物质基础、更主动精神力量** |

这一张表实际上可以贯穿史纲第4章到第10章。

尤其要注意不同阶段对应的关键词不能串：

新民主主义革命时期不是“制度基础”；

社会主义革命和建设时期不是“根本社会条件”；

改革开放时期不是“根本政治前提”；

新时代对应的是：

**更为完善的制度保证、更为坚实的物质基础、更为主动的精神力量**。

## 十四、党的百年奋斗五大历史意义

十九届六中全会对百年奋斗的历史意义作了高度概括。

考试时看到相关材料，重点锁定这五个维度：

| 角度    | 历史意义               |
| ----- | ------------------ |
| 中国人民  | 从根本上改变了中国人民的前途命运   |
| 中华民族  | 开辟了实现中华民族伟大复兴的正确道路 |
| 马克思主义 | 展示了马克思主义的强大生命力     |
| 世界    | 深刻影响了世界历史进程        |
| 中国共产党 | 锻造了走在时代前列的中国共产党    |

这个其实很好记：

**人民—民族—理论—世界—党**。

题目一旦问“党的百年奋斗历史意义”，不要去选具体经济数字或者某项政策成果，因为这里问的是高度概括的**历史意义**。

## 十五、党的百年奋斗“十个坚持”

十九届六中全会还总结了百年奋斗十条历史经验：

**坚持党的领导、坚持人民至上、坚持理论创新、坚持独立自主、坚持中国道路、坚持胸怀天下、坚持开拓创新、坚持敢于斗争、坚持统一战线、坚持自我革命**。

这一部分纯记忆性较强，但理解后会轻松很多：

党的领导解决“谁领导”；

人民至上解决“为了谁”；

理论创新解决“用什么理论指导”；

独立自主、中国道路解决“走什么路”；

胸怀天下解决“中国与世界”；

开拓创新、敢于斗争解决“怎样应对变化和风险”；

统一战线解决“团结谁”；

自我革命解决“党自身怎样永葆先进性”。

## 十六、“两个确立”放在这里怎么理解

十九届六中全会还形成一个新时代极重要的政治结论：

**确立习近平同志党中央的核心、全党的核心地位；确立习近平新时代中国特色社会主义思想的指导地位**。

这就是“两个确立”。

资料强调，“两个确立”是深刻总结党的百年奋斗历史经验特别是新时代伟大实践得出的重大历史结论，是党的十八大以来重要的政治成果。

容易和另外一个概念混淆：

**两个确立 ≠ 两个维护**。

“两个确立”主要回答政治和理论上的**确立什么**；

“两个维护”则强调在行动上维护党中央权威和集中统一领导。

## 十七、考点100：党的二十大——历史重心从“全面小康”转向“社会主义现代化强国”

2022年10月，党的二十大召开。

这一节点非常重要，因为它意味着：

**第一个百年奋斗目标已经完成，党和国家进入实现第二个百年奋斗目标的新征程**。

党的二十大明确：

> **从现在起，中国共产党的中心任务，就是团结带领全国各族人民全面建成社会主义现代化强国、实现第二个百年奋斗目标，以中国式现代化全面推进中华民族伟大复兴**。

这句话是必背原句。

可以压缩为逻辑关系：

**目标：社会主义现代化强国**。

**时间维度：第二个百年奋斗目标**。

**路径：中国式现代化**。

**最终历史主题：中华民族伟大复兴**。

## 十八、党的二十大总结的“三件大事”

《政治考点》补充了一个非常适合考选择题的内容。

党的二十大总结新时代十年，指出经历了三件具有重大现实意义和深远历史意义的大事：

| 三件大事                        |
| --------------------------- |
| 迎来中国共产党成立一百周年               |
| 中国特色社会主义进入新时代               |
| 完成脱贫攻坚、全面建成小康社会，实现第一个百年奋斗目标 |

这三件大事是中国共产党和中国人民团结奋斗赢得的历史性胜利。

最容易设置的干扰项就是把：

“实现第二个百年奋斗目标”

塞进三件大事。

这是错的，因为第二个百年奋斗目标仍然是**正在奋斗的目标**。

## 十九、新时代十年伟大变革的历史意义

党的二十大还作了一个非常高层次的总结：

> **新时代十年的伟大变革，在党史、新中国史、改革开放史、社会主义发展史、中华民族发展史上具有里程碑意义**。

资料进一步概括：

中国共产党在革命性锻造中更加坚强有力；

中国人民焕发出更加强烈的历史自觉和主动精神；

中华民族伟大复兴进入不可逆转的历史进程；

科学社会主义在21世纪中国焕发新的蓬勃生机。

这里非常适合作为分析题或时政材料的背景性语言。

## 二十、考点101：二十届三中全会——进一步全面深化改革

学到这里要重新接回第九章。

第九章从1978年讲：

**改革开放开启中国特色社会主义**。

第十章最后则说明：

进入新时代以后，

**改革开放并没有结束，而是进入进一步全面深化改革的新阶段**。

二十届三中全会的主题：

> **进一步全面深化改革、推进中国式现代化**。

最重要成果是审议通过：

《中共中央关于进一步全面深化改革、推进中国式现代化的决定》。

教材特别强调一句非常适合选择题和材料题：

> **中国式现代化是在改革开放中不断推进的，也必将在改革开放中开辟广阔前景**。

全会部署未来改革任务，并提出到**2029年中华人民共和国成立80周年时**完成《决定》提出的改革任务；同时强调：

> **党的领导是进一步全面深化改革、推进中国式现代化的根本保证**。

所以第九章和第十章其实首尾相接：

**十一届三中全会 → 改革开放开启**

到

**新时代 → 全面深化改革**

再到

**二十届三中全会 → 进一步全面深化改革、推进中国式现代化**。

## 二十二、从整个中国近现代史看，第十章真正想表达什么

如果只背会议和年份，就没有真正学懂第十章。

把1840—新时代连起来，可以发现整部《纲要》实际上有一条非常清晰的主线：

**近代中国为什么衰落 → 不同阶级为什么救国失败 → 为什么中国共产党成为历史和人民的选择 → 中国共产党怎样完成民族独立和人民解放 → 怎样建立社会主义制度 → 怎样通过改革开放推动国家富强和人民富裕 → 新时代怎样继续推进中华民族伟大复兴**。

因此：

**第1—3章回答“为什么旧道路走不通**”；

**第4—7章回答“为什么中国共产党能够领导革命胜利**”；

**第8章回答“新中国和社会主义制度怎样建立**”；

**第9章回答“改革开放怎样改变中国**”；

而**第10章回答“经过长期奋斗，中国走到什么新的历史方位，以及接下来向哪里走**”。

这正是史纲所谓的“史论结合”。资料的复习建议也明确指出，本课程不能只是记史实，而要重点掌握事件的**原因、意义、经验和历史规律性**。

## 二十三、考研复习时，这章真正需要背到什么程度

如果按重要程度排序，第十章最值得背熟的是：

**第一层：必须能直接做选择题**

十八大开启新时代；十九大的主要历史贡献；社会主要矛盾；党的领导三个固定表述；自我革命；十九届四中全会主题；脱贫攻坚、全面小康时间节点；十九届六中全会及“十个坚持”；党的二十大中心任务；二十届三中全会主题。

**第二层：能够识别正确选项**

百年奋斗五大历史意义；四个历史时期主要任务；新时代十年“三件大事”；新时代十年伟大变革的里程碑意义。

**第三层：以理解为主**

新发展阶段、新发展理念、新发展格局、高质量发展。这部分理论考查更多会放在“习近平新时代中国特色社会主义思想概论”里，而不是单独以史纲第十章身份出现。

因此如果时间有限，这章不能和第5、6、7章一样花大量时间背历史细节；应该采用：

“**时间轴 + 会议—文件—结论 + 易混关键词**”

的方式复习。

一句话把整个第十章压缩下来就是：

> **十八大开启新时代，十九大确立新时代的理论和政治判断；新时代坚持党的全面领导、推进自我革命和国家治理现代化，完成脱贫攻坚和全面小康；十九届六中全会总结百年奋斗，党的二十大开启以中国式现代化全面推进中华民族伟大复兴的新征程，进一步全面深化改革继续为中国式现代化提供动力**。

这条主线掌握后，第十章的大部分选择题都能从历史位置和逻辑关系中直接判断出来。
