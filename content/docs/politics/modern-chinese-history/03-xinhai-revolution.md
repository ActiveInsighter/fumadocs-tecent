## 一、第三章在整个史纲中的位置

1840—1919年属于旧民主主义革命时期。前三章实际上是在回答：“面对半殖民地半封建中国的危机，各阶级到底有没有能力救中国？”

| 探索力量        | 代表运动     | 想解决问题的方法          | 最终结论              |
| ----------- | -------- | ----------------- | ----------------- |
| 农民阶级        | 太平天国运动   | 农民战争              | 不能成功              |
| 地主阶级洋务派     | 洋务运动     | 学西方技术             | 不能成功              |
| 资产阶级维新派     | 戊戌维新     | 君主立宪、改良           | 不能成功              |
| **资产阶级革命派** | **辛亥革命** | **革命推翻清政府、建立共和国** | **仍然没有完成反帝反封建任务** |

所以第三章比第二章前进了一大步。

维新派还想：

> **保留皇帝，改造制度**。

革命派则认为：

> **清王朝本身就是问题，必须把它推翻，建立共和国**。

这就是从**改良**走向**革命**。

第三章在《精讲精练》中主要对应考点17—25：辛亥革命爆发的历史条件、资产阶级革命派、三民主义、革命与改良论战、辛亥革命爆发、中华民国建立、历史意义、北洋军阀统治以及旧民主主义革命失败。

## 二、为什么辛亥革命会爆发？

### 1. 民族危机、社会矛盾已经十分严重

1901年《辛丑条约》签订后，清政府更加严重地受制于帝国主义。

考试中经常出现一句高度概括的话：

**清政府已经成为“洋人的朝廷**”。

这意味着清政府已经不只是一个腐朽的封建政府，而且越来越成为帝国主义统治中国的工具。

所以当时存在两个紧密联系的问题：

一方面，帝国主义对中国侵略越来越深；另一方面，清政府不仅没有能力抵抗帝国主义，反而成为中外反动势力联合统治中国的重要工具。

因此，民族危机和国内社会矛盾进一步激化。辛亥革命并不是几个人突然想推翻清政府，而是在这种社会矛盾中逐步成熟起来的。

## 三、为什么清政府自己的“新政”反而加快了灭亡？

这是一个非常值得理解的地方。

很多人会产生疑问：

> 清政府不是已经开始改革了吗？为什么革命反而越来越近？

因为清政府的改革不是为了真正建立现代民主政治，而是为了**延续清王朝的统治**。

1901年以后，清政府开始实行所谓“新政”；1906年宣布“预备仿行宪政”；1908年颁布《钦定宪法大纲》。

表面看起来好像越来越接近宪政。

但是1911年清政府成立所谓责任内阁时，13名大臣中有9名满族，其中7名还是皇族成员，于是社会讥讽它为：

“**皇族内阁**”。

这一下连原本支持君主立宪的立宪派都大失所望。

这件事情暴露出：

> 清政府所谓立宪，核心并不是“把权力交给人民”，而是在换一种形式维护皇族权力。

因此，《精讲精练》明确指出，预备立宪不仅没有挽救清王朝，反而进一步激化社会矛盾，使清政府陷入“**无法照旧统治下去**”的境地。

这实际上解释了为什么第二章的“改良道路”走到最后，会自然把历史推向第三章的“革命道路”。

## 四、资产阶级革命派为什么能够出现？

革命不能只有“社会不满”，还必须有相应的社会力量。

19世纪末20世纪初，中国民族资本主义有了一定的初步发展，因此民族资产阶级开始要求维护自己的政治利益、经济利益。

这构成了资产阶级革命派产生的**阶级基础**。

革命派的骨干则主要是一批：

**资产阶级、小资产阶级知识分子**。

这一批人的成长又和戊戌维新以后兴办新式学堂、派遣留学生等因素有关。

所以要区分：

| 概念       | 答案             |
| -------- | -------------- |
| 革命派的阶级基础 | 民族资产阶级的发展      |
| 革命派的骨干力量 | 资产阶级、小资产阶级知识分子 |

这类“基础—骨干”非常适合出选择题。

## 五、孙中山为什么从“改革”转向“革命”？

孙中山并不是从一开始就认定必须武装革命。

1894年，他还曾经北上向李鸿章上书，希望通过自上而下的改革推动中国进步。

但李鸿章没有接受他的主张，而且孙中山在这一过程中进一步认识到清政府腐败程度已经非常严重。

于是他逐渐得出结论：

**仅仅改良清政府已经不够，必须推翻清政府**。

这个思想转变非常重要。

它体现了中国先进分子从：

**改良清政府**

转向：

**推翻清政府**。

## 六、兴中会：孙中山革命活动真正开始组织化

1894年11月，孙中山在檀香山成立：

**兴中会**。

这是孙中山建立的**第一个革命团体**。

纲领是：

“**驱除鞑虏，恢复中国，创立合众政府**。”

1895年孙中山策划广州起义，失败后继续在海外进行革命活动。

1904年，他又发表《中国问题的真解决》，提出只有推翻清政府、建立新的进步政府，把君主政体变成“中华民国”，才能真正解决中国问题。

这里已经把革命派和维新派的根本区别表现得非常清楚：

> **革命派主张用革命、武装起义推翻清王朝；改良派仍希望通过改革改造现有政权**。

这也是一个高频判断点。

## 七、革命思想是怎么传播开的？

革命首先要解决一个问题：

> 为什么普通知识分子会认为“推翻清政府”是合理的？

因此革命派进行了大量思想宣传。

比较重要的对应关系是：

| 人物      | 著作         | 核心作用               |
| ------- | ---------- | ------------------ |
| **章炳麟** | 《驳康有为论革命书》 | 批判保皇思想，主张革命        |
| **邹容**  | 《革命军》      | 号召推翻清朝，建立“中华共和国”   |
| **陈天华** | 《警世钟》《猛回头》 | 揭露清政府是“洋人的朝廷”，号召革命 |

这些革命宣传使民主革命思想得到越来越广泛的传播。

这里尤其注意人物—著作对应，史纲非常爱考。

## 八、中国同盟会：革命终于有了全国性的政治组织

这是本章非常重要的时间点：

**1905年8月20日**。

孙中山、黄兴、宋教仁等人在日本东京成立：

**中国同盟会**。

机关报：

《**民报**》

它的历史定位非常重要：

**近代中国第一个领导资产阶级革命的全国性政党**。

它的成立标志着：

**中国资产阶级民主革命进入了一个新的阶段**。

这里一定要和兴中会区分：

| 组织    | 定位                        |
| ----- | ------------------------- |
| 兴中会   | 孙中山组建的**第一个革命团体**         |
| 中国同盟会 | 近代中国**第一个领导资产阶级革命的全国性政党** |

因此题目如果说：

“1905年同盟会成立标志孙中山第一个革命团体诞生。”

就是错的。

第一个革命团体早在1894年已经有了。

## 九、本章核心中的核心：三民主义

同盟会的纲领是：

“**驱除鞑虏，恢复中华，创立民国，平均地权**。”

1905年11月，孙中山在《民报》发刊词中把它进一步概括为：

**民族主义、民权主义、民生主义**。

即：

**三民主义**。

这是第三章选择题最重要的知识点之一。

### 1. 民族主义——民族革命

对应：

**驱除鞑虏，恢复中华**。

它的主要目的不是简单“仇视满族”。

孙中山的真正主张是：

推翻清政府，结束它的专制统治和民族压迫政策，建立一个独立的民族国家。

所以：

**民族主义 = 民族革命**。

但它有一个非常致命的局限：

**没有正面、鲜明地提出反对帝国主义**。

革命派当时对于帝国主义本质认识不够深入，甚至幻想通过承认列强已有特权等方式换取列强对革命政府的承认。

另外，它也没有明确把汉族军阀、官僚、地主都列为革命对象。

这后来直接成为辛亥革命失败的重要思想原因。

## 十、民权主义——政治革命

对应：

**创立民国**。

目标是：

**推翻封建君主专制制度，建立资产阶级民主共和国**。

孙中山把它称作：

**政治革命**。

这里有一个很经典的说法。

民族革命是扫除：

“**现在的恶劣政治**”。

政治革命则进一步扫除：

“**恶劣政治的根本**”。

也就是说，仅仅把清朝皇族赶走还不够，还必须把**君主专制制度**本身废掉。

但是民权主义也存在局限：

它主要从资产阶级共和国的角度理解民权，没有充分考虑广大劳动群众在国家中的实际政治地位。

因此：

**它并不能真正保证广大人民群众获得充分的民主权利**。

## 十一、民生主义——社会革命

对应：

**平均地权**。

孙中山希望解决资本主义发展中可能出现的贫富悬殊和社会矛盾。

基本思路是：

**核定地价，土地增值归公**。

所以：

**民生主义 = 社会革命**。

《政治考点》对此概括得很清楚：民族主义是民族革命，民权主义是政治革命，民生主义是社会革命。

但问题是：

孙中山的“平均地权”并没有真正废除封建地主土地所有制。

因此它：

**无法真正满足广大农民“得到土地”的要求**。

这是非常重要的考试陷阱。

“平均地权”绝对不能理解成共产党后来实行的：

**没收地主土地归农民所有**。

二者完全不是一回事。

## 十二、三民主义到底应该怎么评价？

必须同时看到两面。

一方面，它很进步。

它是：

**一个比较完整而明确的资产阶级民主革命纲领**。

它第一次比较系统地描绘了一个中国过去没有过的：

**资产阶级共和国方案**。

因此对推动革命发展起到了重大积极作用。

另一方面，它又是不彻底的。

核心缺陷可以记成三句话：

| 主义   | 最大局限                 |
| ---- | -------------------- |
| 民族主义 | **没有明确反帝**           |
| 民权主义 | **没有真正解决劳动人民民主权利问题** |
| 民生主义 | **没有真正解决农民土地问题**     |

可以发现，这三个缺陷实际上已经预示了辛亥革命最后为什么不能完成反帝反封建任务。

## 十三、革命派和改良派为什么要大论战？

1905—1907年，中国究竟应该：

> 改？

还是：

> 革？

变成了一个极其尖锐的问题。

革命派以：

《**民报**》

为主要阵地。

改良派以：

《**新民丛报**》

为主要阵地。

双方展开了著名的：

**革命与改良大论战**。

## 十四、论战到底争什么？

三个问题必须原话掌握。

| 问题                | 地位       |
| ----------------- | -------- |
| **要不要以革命手段推翻清王朝** | **论战焦点** |
| 要不要推翻帝制、实行共和      | 政体问题     |
| 要不要进行社会革命         | 社会经济问题   |

最重要的是第一个：

**要不要革命**。

2020年考研政治直接考过这一点，答案就是：

**要不要以革命手段推翻清王朝**。

## 十五、最容易混淆的“两次论战”

这在真题中已经明确考过。

|      | 维新派 vs 守旧派         | 革命派 vs 改良派          |
| ---- | ------------------ | ------------------- |
| 性质   | 资产阶级思想与封建主义思想的正面交锋 | **资产阶级内部两种政治路线的论战** |
| 核心   | 要不要变法              | **要不要革命**           |
| 政治主张 | 君主立宪               | 共和国                 |
| 主要阵地 | 维新宣传               | 《民报》vs《新民丛报》        |

因此2023年真题有一个非常典型的错误选项：

> 革命派与改良派论战“实质上是资产阶级思想与封建主义思想的交锋”。

错。

这是把它和**维新派—守旧派论战**混淆了。

2023年真题这道多选正确的是：

**A、C、D**。

即论战聚焦革命手段，传播了民主革命思想，同时也暴露革命派自己的思想理论弱点。

## 十六、为什么说这场论战既有成功又暴露问题？

成功在于：

**划清了革命与改良的界限；传播民主革命思想；促进革命形势发展**。

但是革命派自己的理论缺陷也暴露出来。

比如，他们害怕革命会招致帝国主义干涉，所以不能理直气壮地提出彻底反帝；他们所谓“国民”主要仍然是资产阶级及知识分子，而不是广大工农群众；他们对封建土地制度问题也不彻底，甚至反对贫苦农民“夺富人之田为己有”。

这很重要，因为史纲不是把“辛亥革命失败原因”突然放在章末才说明。

实际上从：

**三民主义的局限 → 革命与改良论战的局限**

就已经一步步埋下失败伏笔了。

## 十七、1911年革命是怎么真正爆发的？

在正式爆发前，同盟会发动过多次武装起义。

其中影响最大的一次是：

**1911年4月27日广州起义**。

即著名的：

**黄花岗起义**。

虽然失败，但是进一步扩大了革命影响。

真正把局势推向爆炸的另一个重要因素，则是：

**保路运动**。

1911年清政府宣布“铁路干线收归国有”，实际上把铁路权益出卖给帝国主义银行团，同时侵害国内商民利益。

湖北、湖南、广东、四川出现大规模保路运动。

其中：

**四川最激烈**。

这迫使清政府把湖北军队调往四川镇压保路运动，客观上使武汉地区清军防御力量削弱，为武昌起义创造了有利条件。

## 十八、武昌起义：辛亥革命进入高潮

最重要日期：

**1911年10月10日**。

湖北新军中的共进会、文学社等革命力量在武昌发动起义。

武昌起义迅速取得胜利。

起义军很快占领武汉三镇，并建立湖北军政府。

《精讲精练》使用了一个很重要的新表述：

**武昌城头枪声一响，拉开了中国完全意义上的近代民族民主革命的序幕**。

随后各省纷纷宣布脱离清政府。

清王朝的统治迅速土崩瓦解。

最终：

**1912年2月12日，清帝退位**。

中国延续两千多年的：

**封建君主专制制度**

终于被推翻。

注意这个措辞。

不是：

**错误**：“封建制度被彻底消灭”

不是：

**错误**：“半殖民地半封建社会结束”

而是：

**正确：封建君主专制制度结束**。

这是本章最大的选择题陷阱之一。

## 十九、中华民国成立

武昌起义以后，孙中山从海外回国。

各独立省代表选举孙中山为临时大总统。

**1912年1月1日**

孙中山在南京就任临时大总统，宣布成立：

**中华民国临时政府**。

并规定：

**1912年为民国元年**。

## 二十、南京临时政府是什么性质？

考试答案非常明确：

**资产阶级共和国性质的革命政权**。

为什么？

《精讲精练》从两个角度判断。

第一看：

**谁掌握政权**。

资产阶级革命派在政府中占领导和主体地位。

第二看：

**政府实行什么政策**。

南京临时政府的政策集中反映民族资产阶级利益，同时在一定程度上也符合广大人民的利益。

所以不能因为中华民国叫“民国”，就把它说成人民民主政权。

它的阶级性质是：

**资产阶级共和国性质**。

## 二十一、南京临时政府为什么又有明显局限？

因为资产阶级革命派并不彻底。

最重要有两个方面。

第一，对帝国主义妥协。

南京临时政府在《告友邦书》中试图通过承认清政府与列强签订的不平等条约以及清政府的外债，换取列强承认中华民国。

第二，对封建土地制度妥协。

它没有提出能够满足农民土地要求的政策，反而保护原有私有财产和地主土地。

所以这里再次对应前三民主义的缺陷：

> **不敢彻底反帝 + 不敢彻底解决土地问题**。

## 二十二、《中华民国临时约法》为什么特别重要？

1912年3月，临时参议院颁布：

《**中华民国临时约法**》。

它的历史定位一定要背准确：

**中国历史上第一部具有资产阶级共和国宪法性质的法典**。

它规定共和国的国体、政府组织以及人民享有的民主权利。

尤其重要的是：

**中华民国主权属于国民全体**。

国民在法律上一律平等，并享有一系列自由民主权利。

更重要的是，它以国家根本大法形式：

**废除了封建君主专制制度，确认了资产阶级共和国政治制度**。

因此毛泽东评价它具有：

**革命性、民主性**。

## 二十三、《临时约法》真题怎么挖坑？

2014年真题：

《中华民国临时约法》的革命性、民主性体现在哪里？

正确答案是：

**B、C、D**。

也就是：

国民一律平等；主权属于国民全体；以根本大法废除封建君主专制制度。

A：

> “不承认清政府与列强签订的一切不平等条约”

反而是错的。

因为南京临时政府实际上试图**承认这些条约和外债来换取列强承认**。

这就是非常典型的“把主观认为应该做的事，当成历史上实际做过的事”的干扰项。

## 二十四、辛亥革命究竟“成功”在哪里？

这一点必须特别理解。

辛亥革命当然不能简单说“一无是处”。

它取得了非常巨大的历史成果。

《精讲精练》总结了五个主要方面。

| 层面   | 历史意义                   |
| ---- | ---------------------- |
| 政治统治 | 推翻清王朝，沉重打击中外反动势力       |
| 政治制度 | 结束两千多年封建君主专制，建立资产阶级共和国 |
| 思想   | 推动思想解放，使民主共和观念传播       |
| 社会   | 推动社会经济、社会风俗和思想习惯发生积极变化 |
| 国际   | 打击帝国主义侵略势力，推动亚洲民族解放运动  |

其中最重要的考试词是：

“**结束封建君主专制制度**。”

## 二十五、如何理解“辛亥革命使民主共和深入人心”？

在辛亥革命以前：

> 皇帝存在两千多年。

对于很多人来说，“天下必须有皇帝”几乎是一种天然政治观念。

辛亥革命以后发生了一个根本思想变化：

> 国家可以没有皇帝。

> 政权的合法性不再天然来自皇权。

因此即便后来袁世凯想称帝，社会反对会如此强烈，一个重要原因就是：

**民主共和已经成为不可逆转的重要思想潮流**。

所以辛亥革命虽然没能建立稳定的民主共和国，但它改变了人们对于国家政治制度的想象。

这是“政治革命”带来的深层思想后果。

## 二十六、为什么今天对辛亥革命的评价更高？

**辛亥革命是完全意义上的近代民族民主革命，是中华民族伟大复兴征程上的里程碑，拉开了中国深刻社会变革的序幕**。

而传统《精讲精练》表述经常是：

“**一次比较完全意义上的资产阶级民主革命**。”

备考时两个都要认识。

看到旧教材、旧真题：

> “比较完全意义上的资产阶级民主革命”

不要判错。

看到当前重要政治表述：

> “完全意义上的近代民族民主革命”

也要会选。

## 二十七、既然成就这么大，为什么又说辛亥革命失败？

因为历史革命是否最终成功，不能只看：

> “皇帝有没有被赶走”。

还要看近代中国最根本的历史任务有没有完成。

近代中国两大历史任务中，首先必须实现：

**民族独立、人民解放**。

辛亥革命之后：

帝国主义仍然控制中国。

地主土地制度仍然存在。

中国仍然是：

**半殖民地半封建社会**。

广大人民的悲惨命运也没有根本改变。

因此辛亥革命：

> **推翻了皇帝，却没有完成反帝反封建的民主革命任务**。

这就是毛泽东说：

> 辛亥革命“只把一个皇帝赶跑”。

2015年考研真题直接考过，这句话的真正含义是：

**反帝反封建的革命任务没有完成**。

不是说它“没有推翻帝制”。

恰恰相反，帝制确实推翻了。

## 二十八、袁世凯是怎么窃取革命果实的？

清政府面临灭亡以后，帝国主义和国内反动势力逐渐把希望寄托在拥有北洋军队的袁世凯身上。

革命派本身力量又不足，最终对袁世凯作出妥协。

1912年2月12日：

**清帝退位**。

第二天：

孙中山提出辞职。

3月10日：

**袁世凯在北京就任临时大总统**。

4月1日：

孙中山正式卸任。

随后临时政府迁往北京。

南京临时政府仅存在了大约三个月。

于是：

> 清王朝虽然倒了，但真正掌握强大军事、行政力量的旧势力并没有消失。

这就是辛亥革命最典型的历史矛盾。

## 二十九、北洋政府是什么性质？

袁世凯建立的北洋军阀政权虽然仍然挂着：

“**中华民国**”

的牌子，但是阶级性质已经发生变化。

它代表的是：

**大地主和买办资产阶级利益**。

所以一定不要看政权名称判断性质。

“中华民国”不等于它就是资产阶级革命政权。

南京临时政府是：

**资产阶级共和国性质的革命政权**。

袁世凯的北京政府则是：

**代表大地主、买办资产阶级利益的北洋军阀反动政权**。

这也是史纲非常典型的：

> **名字相同，阶级性质不同**。

## 三十、为什么袁世凯死后会进入军阀割据？

1912—1928年属于北洋军阀统治时期。

袁世凯活着时依靠自己的军事力量，北洋政府还能维持形式上的统一。

1916年袁世凯死后，各个军阀集团开始争夺中央政权，形成长期军阀混战。

资料把形成军阀割据的深层原因概括为两个：

**中国主要仍然是地方性农业经济，没有形成统一强大的资本主义市场；帝国主义各国又在中国划分势力范围，分别扶植不同军阀作为自己的代理人**。

所以军阀割据不是简单因为“几个军阀性格不好”，它背后有近代中国半殖民地半封建社会的经济政治结构。

## 三十一、孙中山后来有没有放弃？

没有。

这也是孙中山历史地位很高的重要原因。

共和制度不断遭到破坏以后，孙中山先后进行了多次斗争。

| 时间        | 事件       | 对象/背景       | 结果        |
| --------- | -------- | ----------- | --------- |
| 1913      | **二次革命** | 宋教仁被刺后反袁    | 失败        |
| 1914      | 组织中华革命党  | 继续反袁        | 后来发展      |
| 1915—1916 | **护国运动** | 反对袁世凯称帝     | 袁世凯被迫取消帝制 |
| 1917以后    | **护法运动** | 维护《临时约法》和国会 | 最终失败      |

## 三十二、“二次革命”是什么？

1913年宋教仁遇刺。

孙中山由此进一步认识到袁世凯已经走上独裁道路，于是发动：

**二次革命**。

但北洋军阀掌握强大正规军。

国民党方面则组织松散、军事力量弱、内部意见不统一。

因此只坚持大约两个月就失败了。

## 三十三、护国运动为什么反而成功了一部分？

1915年袁世凯准备恢复帝制。

这已经触碰了辛亥革命以后形成的：

**共和政治底线**。

1915年12月，蔡锷等在云南组织护国军反袁。

全国反对帝制力量迅速扩大。

最终：

**1916年3月袁世凯被迫取消帝制**。

不久袁世凯去世。

这恰恰证明辛亥革命产生的思想影响非常深：

> 皇帝已经越来越缺乏政治合法性。

所以即便革命没有彻底成功，历史也不是简单退回1911年以前。

## 三十四、护法运动为什么又失败？

袁世凯死后，段祺瑞等北洋军阀继续破坏《临时约法》和国会。

孙中山于是提出：

**护法**。

1917年在广州组织护法军政府。

但孙中山没有自己可靠的军队，只能依靠与北洋军阀存在矛盾的西南军阀。

问题在于：

这些西南军阀并不是真正为了民主共和，而只是借孙中山扩大自身势力。

后来他们又和其他军阀妥协、排挤孙中山。

护法运动最终失败。

孙中山由此深刻认识到：

“**南与北如一丘之貉**。”

也就是：

北洋军阀不可靠。

南方军阀一样不可靠。

想靠一个军阀集团去打另一个军阀集团，无法真正救中国。

这使旧民主主义革命彻底陷入困境。

## 三十五、辛亥革命为什么失败？这是大题级知识

这里一定分成：

**根本原因**

和

**主观原因**。

首先是根本原因。

在帝国主义时代，在半殖民地半封建的中国：

**资本主义共和国的建国方案根本行不通**。

帝国主义不愿看到一个独立、富强的资本主义中国，因为这会损害它们在中国的殖民利益。

国内的封建势力、买办势力同帝国主义相互勾结。

最后：

> 帝国主义 + 国内反动势力

共同破坏了资产阶级革命派建立独立民主共和国的努力。

所以：

**袁世凯窃国只是辛亥革命失败的一种具体表现，而不是最根本原因**。

最根本层面是：

**资本主义建国方案在半殖民地半封建中国行不通**。

## 三十六、辛亥革命失败的主观原因

资产阶级革命派自身也存在严重弱点。

这些弱点从根源上来自：

**中国民族资产阶级的软弱性和妥协性**。

主要集中在三个方面：

> **没有提出彻底的反帝反封建革命纲领；不能充分发动和依靠人民群众；不能建立一个坚强的革命政党，作为团结一切革命力量的强有力核心**。

这三条非常重要。

其实前面所有内容都可以回扣回来。

为什么说没有彻底纲领？

因为三民主义：

民族主义没有彻底反帝。

民生主义没有真正解决土地问题。

为什么说没有依靠人民？

因为革命派主要依赖知识分子、新军、会党等，没有真正发动占人口绝大多数的农民。

为什么说没有坚强政党？

因为同盟会虽然是全国性政党，但组织不够严密，内部派系复杂、思想并不统一，革命高潮到来以后也没有能力掌握全国政权。

## 三十七、所以第三章真正想告诉我们的是什么？

前三章实际上共同证明了一件事：

**旧中国的各个旧阶级，都无法独立完成民族独立和人民解放的历史任务**。

农民阶级：

有伟大革命潜力，但存在阶级局限。

地主阶级：

试图“中体西用”，维护旧制度。

资产阶级维新派：

想改良而不革命。

资产阶级革命派：

终于敢于推翻君主制度，但又没有能力彻底反帝反封建、发动广大人民群众。

历史就由此产生一个新的问题：

> **既然资产阶级革命也救不了中国，那么下一步由谁领导中国革命**？

于是第四章自然出现：

**新文化运动 → 五四运动 → 马克思主义传播 → 中国共产党成立**。

这就是第三章和第四章之间最重要的历史逻辑。

## 四十、最后把整章压成一条“考研记忆链”

第三章可以直接记成：

《**辛丑条约》后民族危机加深 → 清末新政、预备立宪破产 → 民族资本主义发展使资产阶级革命派形成 → 孙中山由改良转向革命 → 1894兴中会 → 革命思想传播 → 1905同盟会 → 三民主义 → 1905—1907革命派与改良派论战 → 1911黄花岗起义、保路运动 → 10月10日武昌起义 → 1912年中华民国 → 《临时约法》 → 清帝退位、君主专制结束 → 袁世凯窃国 → 北洋军阀统治 → 二次革命、护国、护法 → 旧民主主义革命陷入绝境**。

整章最核心的结论只有两层：

> **第一层：辛亥革命“成功”在推翻清王朝、结束君主专制、建立共和国、推动思想解放**。

> **第二层：辛亥革命“失败”在没有改变半殖民地半封建社会性质，没有完成反帝反封建、民族独立和人民解放的历史任务**。

把这两个层面同时掌握，你就不会再被“辛亥革命到底成功还是失败”这一类题绕进去。它是**有巨大历史功绩的革命，又是一场没有完成近代中国根本革命任务的革命**。

如果按考研复习优先级排，第三章最值得你重点背熟的是：**三民主义三部分及局限、革命与改良论战、武昌起义、《中华民国临时约法》、辛亥革命五大意义、辛亥革命失败的根本原因与三条主观原因**。这几块基本就是本章的“得分骨架”。
