## 一、第16章整体框架

可以先把整章压缩成下面这张表。

| 层次 | 考点                   | 核心回答的问题         |
| -- | -------------------- | --------------- |
| 背景 | 考点106 世界百年变局加速演进     | 今天的世界怎么了？       |
| 总论 | 考点107 中国必须有自己特色的大国外交 | 中国外交总体怎么定位？     |
| 方法 | 考点108 全面推进中国特色大国外交   | 中国具体怎样处理国际关系？   |
| 目标 | 考点109 推动构建人类命运共同体    | 中国希望建设一个什么样的世界？ |

所以，本章不是四个孤立知识点。

它真正讲的是：

**面对百年未有之大变局，中国不能照搬传统大国“国强必霸”的外交逻辑，而是走和平发展道路，发展新型国际关系，在维护自身国家利益的同时促进人类共同进步，最终推动构建人类命运共同体**。

这条主线一定要先理解。

## 二、考点106：世界百年变局加速演进

这是整个第16章的**现实背景和逻辑起点**。

《精讲精练》把世界百年变局概括成五个方面。

### 1. 世界又一次站在历史的十字路口

这里需要同时看到两个方面。

一方面，**世界多极化、经济全球化、社会信息化、文化多样化深入发展**，和平、发展、合作、共赢仍然是不可阻挡的历史潮流。

另一方面，世界面临的**不稳定性、不确定性突出**，全球性问题增多，各类危机、风险相互交织。

所以，教材并不是说：

> 世界已经彻底进入战争与对抗时代。

也不是说：

> 和平与发展已经没有任何问题。

正确理解是：

**和平、发展、合作、共赢的大趋势没有改变，但世界进入了风险更加突出、矛盾更加复杂的动荡变革期**。

选择题很喜欢把这两面割裂开。

## 三、国际力量对比发生深刻变化

资料中的关键词是：

“**东升西降”“中治西乱”更加鲜明**。

并且教材评价这是：

**近代以来国际力量对比中最具革命性的变化**。

注意，这里的“东升西降”不是说：

> 西方马上消失，东方已经完全取代西方。

而是讲**国际力量对比变化的长期趋势**。

因此，一看到“已经完全改变”“西方已经彻底衰落”“旧国际格局已经完全消失”之类绝对化表述，一般都要警惕。

## 四、新一轮科技革命和产业变革深入发展

这个知识点通常不单独考背诵，而是和当前时政材料结合。

例如人工智能、数字经济、新能源、量子科技、生物技术等，都可能改变：

**国家竞争力、产业格局、全球分工以及国际力量对比**。

所以科技革命不仅是一个“科技问题”，本章把它放在世界百年变局里，是因为：

**科技实力越来越成为国际竞争和国家综合实力的重要变量**。

## 五、国际体系和国际秩序深度调整

这里重点理解“调整”，而不是“推倒重来”。

国际力量变化之后，原来的国际治理体系会面临：

全球治理赤字、发展失衡、安全问题、治理代表性不足等问题。

于是教材后面自然就引出：

**中国要积极参与全球治理体系改革和建设**。

所以这里实际上是在给考点109铺路。

## 六、世界进入新的动荡变革期

前四点最后落到这一判断：

**世界百年未有之大变局加速演进，世界进入新的动荡变革期**。

可以这样记：

> **力量在变、科技在变、秩序在变、风险在增**。

这就是为什么新时代中国外交必须进行理论和实践创新。

## 七、补充重点：“全球南方”

资料指出：

“**全球南方”大踏步走上历史舞台，是世界大变局的鲜明标志**。

中国始终是“全球南方”的重要成员，并倡导“全球南方”国家共同成为：

| 领域 | 定位        |
| -- | --------- |
| 和平 | 维护和平的稳定力量 |
| 发展 | 开放发展的中坚力量 |
| 治理 | 全球治理的建设力量 |
| 文明 | 文明互鉴的促进力量 |

这非常适合结合时政出多选题。

## 八、考点107：中国必须有自己特色的大国外交

接下来逻辑变成：

> 世界变了，中国怎么办？

答案就是：

**推进中国特色大国外交**。

资料把它概括为四层。

### 1. 三个“观”：历史观、大局观、角色观

中国特色大国外交建立在正确的：

**历史观、大局观、角色观**

基础上。

理解即可：

**历史观**强调从历史发展规律认识国际局势；

**大局观**强调不能只看某一个事件，而要站在国际国内两个大局上判断问题；

**角色观**强调正确认识中国自身在国际体系中的地位、责任和作用。

选择题很可能直接问：

> 中国特色大国外交建立在什么基础之上？

答案就是：

**正确的历史观、大局观、角色观**。

## 九、一条主线：服务民族复兴、促进人类进步

这是本章特别值得记忆的一句话：

**中国特色大国外交牢牢把握“服务民族复兴、促进人类进步”这条主线**。

为什么是两个方面？

因为中国外交既不是只管世界、不管中国，也不是只管中国、不管世界。

前半句：

**服务民族复兴**

强调外交必须服务于中国自身发展和中华民族伟大复兴。

后半句：

**促进人类进步**

强调中国的发展同世界发展相联系。

所以整章一直在强调：

> **自身发展和世界发展相统一**。

这也是为什么后面会出现一句非常重要的话：

**通过维护世界和平发展自己，又通过自身发展维护世界和平**。

## 十、一个总目标：推动构建人类命运共同体

这是超级容易混淆的知识点。

**新时代对外工作的总目标**：

> **推动构建人类命运共同体**。

一定注意“总目标”三个字。

题目特别容易给出换成：

“坚持走和平发展道路”

但和平发展道路是什么？

是**新时代中国外交的基本原则**。

所以：

| 提法           | 对应内容               |
| ------------ | ------------------ |
| 新时代对外工作的总目标  | **推动构建人类命运共同体**    |
| 新时代中国外交的基本原则 | **坚持走和平发展道路**      |
| 外交工作的出发点和落脚点 | **维护国家主权、安全、发展利益** |
| 中国外交的宗旨      | **维护世界和平、促进共同发展**  |

这张表是本章选择题最重要的区分之一。

## 十一、中国外交的旗帜与宗旨

中国始终高举：

**和平、发展、合作、共赢**

的旗帜。

中国特色大国外交始终坚持：

**维护世界和平、促进共同发展**

的宗旨。

不要把这几个词混在一起。

“和平、发展、合作、共赢”是**旗帜**；

“维护世界和平、促进共同发展”是**宗旨**；

“构建人类命运共同体”是**总目标**。

## 十二、党的领导是外交工作的根本保证

中国特色大国外交还强调：

**坚持和加强党对对外工作的集中统一领导，坚持外交大权在党中央**。

这是这一章和第三章“坚持党的全面领导”的一个跨章节联系。

原因很简单：

外交涉及国家主权、安全、发展利益，涉及重大国家战略，因此必须保证全国外交工作：

**统一意志、统一部署、统一行动**。

## 十三、考点108：全面推进中国特色大国外交

如果107是回答：

> 中国外交“总体是什么”？

那么108就是回答：

> 中国外交“具体怎么做”？

这里是本章选择题最密集的地方。

## 十四、第一，坚持走和平发展道路

这是本章的一个核心K点：

**坚持走和平发展道路，是我们党根据时代发展潮流和我国根本利益作出的战略抉择，是新时代中国外交的基本原则**。

为什么中国走和平发展道路？

资料给了三个理由。

| 原因   | 核心                    |
| ---- | --------------------- |
| 制度原因 | 由中国共产党性质宗旨和我国社会主义制度决定 |
| 文化原因 | 基于中国历史文化传统作出的必然选择     |
| 时代原因 | 符合历史潮流、顺应世界大势         |

可以记成：

> **党和制度决定 + 历史文化选择 + 世界大势要求**。

## 十五、和平发展绝不等于放弃国家利益

这是非常容易误解的地方。

教材同时强调：

**走和平发展道路，就要坚定奉行独立自主的和平外交政策**。

同时必须维护：

**国家主权、安全、发展利益**。

所以“和平发展”绝不是：

“什么事情都退让。”

而是：

> **坚持和平发展，但涉及国家核心利益和原则问题时必须坚定维护**。

因此后面教材会专门讲：

**敢于斗争、善于斗争**。

这两者并不矛盾。

和平发展讲的是我国总体战略选择；

敢于斗争讲的是面对损害我国主权、安全、发展利益行为时的原则立场。

## 十六、中国发展和世界和平是双向关系

这句话特别值得理解：

**既要通过维护世界和平发展自己，又要通过自身发展维护世界和平**。

不是：

> 世界为中国发展服务。

也不是：

> 中国的发展完全依赖外部环境。

而是强调中国与世界之间的互动关系。

中国需要和平的国际环境发展；

中国发展起来以后，也要为世界和平发展提供更多机会和公共产品。

## 十七、第二，推动构建新型国际关系

这是考点108第二块的重要知识。

新型国际关系坚持三个原则：

**相互尊重、公平正义、合作共赢**。

这一组一定背下来。

注意与其他三词、四词组合区分。

其核心交往方式是：

**对话而不对抗，结伴而不结盟**。

这实际上是在突破传统大国关系中的：

“阵营政治、集团政治、零和博弈”。

同时中国坚持在：

**和平共处五项原则**

基础上同各国发展友好合作，深化：

**平等、开放、合作的全球伙伴关系**。

教材评价：

**推动构建新型国际关系，是新时代中国特色大国外交理论和实践的重要创新**。

## 十八、中国外交布局——最容易考匹配题

这组内容非常适合直接出单选、多选。

| 对象     | 中国外交的提法                              |
| ------ | ------------------------------------ |
| 大国     | 推进大国协调合作，构建**和平共处、总体稳定、均衡发展**的大国关系格局 |
| 周边国家   | **亲诚惠容**周边外交理念                       |
| 周边外交方针 | **与邻为善、以邻为伴**                        |
| 发展中国家  | **真实亲诚理念和正确义利观**                     |
| 政党关系   | **求同存异、相互尊重、互学互鉴**                   |

其中最常考的是：

#### 周边

**理念：亲诚惠容**。

**方针：与邻为善、以邻为伴**。

不要反过来。

#### 发展中国家

**真实亲诚 + 正确义利观**。

#### 新型国际关系总体原则

**相互尊重 + 公平正义 + 合作共赢**。

资料中的模拟题也直接按这种方式设问。

## 十九、第三，坚决维护国家主权、安全、发展利益

这一句话建议原句记忆：

**维护国家主权、安全、发展利益，是我国对外工作的出发点和落脚点，是中国外交的神圣使命**。

这是本章又一个“地位型”考点。

注意：

不是“推动构建人类命运共同体”是出发点和落脚点。

人类命运共同体是：

**总目标**。

出发点和落脚点是：

**国家主权、安全、发展利益**。

而维护这些利益：

**必须敢于斗争、善于斗争**。

所以可以总结：

> **讲和平，不等于不要斗争；讲合作，不等于放弃原则**。

## 二十、第四，坚持外交为民

外交并不只是国家之间的宏观交往，也直接涉及普通中国公民。

资料强调：

**人民外交是中国共产党的一个创举，也是中国外交的力量源泉**。

坚持外交为民，要坚定维护：

**我国海外公民和法人正当权益**。

同时：

**积极开展民间外交，是中国外交的优良传统和鲜明特色**。

因此如果材料出现：

海外撤侨、海外领事保护、保护中国企业和中国公民合法权益等，

很可能对应：

**外交为民**。

## 二十一、考点109：推动构建人类命运共同体

这是整个第16章最后的落脚点，也是本章真正的理论高潮。

《精讲精练》将其标为**重要考点**，而且资料明确收录了2022年考研真题。

## 二十二、为什么提出人类命运共同体？

核心判断是：

今天各国之间相互联系、相互依存越来越深。

全球性问题也越来越难以由一个国家单独解决。

因此面对：

和平问题、发展问题、安全问题、治理问题、生态问题等，

如果仍然按照：

> 你输我赢、零和博弈、强权政治

处理世界问题，就无法应对共同挑战。

因此中国提出：

**构建人类命运共同体**。

资料对其性质的评价非常重要：

它是当代中国共产党人回答和解决人类前途命运时代之问的：

**中国方案**；

是应对人类共同挑战、建设更加繁荣美好世界的：

**人间正道**；

还是：

**新时代对外工作的总目标**。

## 二十三、人类命运共同体到底要建设什么样的世界？

这是必须原句记忆的“五个世界”：

**持久和平、普遍安全、共同繁荣、开放包容、清洁美丽**。

可以这样理解：

| 世界   | 解决的问题          |
| ---- | -------------- |
| 持久和平 | 战争、冲突问题        |
| 普遍安全 | 各类传统和非传统安全问题   |
| 共同繁荣 | 发展不平衡问题        |
| 开放包容 | 文明、制度、发展道路差异问题 |
| 清洁美丽 | 生态环境问题         |

最简单记忆：

> **和平—安全—发展—文明—生态**。

分别对应：

> **持久和平—普遍安全—共同繁荣—开放包容—清洁美丽**。

## 二十四、价值基础：全人类共同价值

政治考点资料进一步明确：

构建人类命运共同体要弘扬：

**和平、发展、公平、正义、民主、自由**

的全人类共同价值。

六个词建议分三组：

> **和平、发展**

> **公平、正义**

> **民主、自由**

资料解释得也很清楚：

和平与发展是人类的共同事业；

公平正义是人类的共同理想；

民主自由是人类的共同追求。

这里有一个重要理解：

全人类共同价值不是要求：

> 世界所有国家使用完全相同的制度和文明模式。

恰恰相反，它强调寻找不同文明、不同国家价值观念中的：

**最大公约数**。

其实践基础是：

**包容性的，而不是排他性的**。

## 二十五、文明多样性：非常重要的真题方向

这一部分已经直接考过2022考研政治多选。

材料用：

**中国人喝茶、比利时人喝啤酒**

来比喻不同文明。

核心思想是：

不同文明可以不同，但：

**不同不等于优劣**。

资料中的2022年第26题四个选项分别指出：

人类文明多样性是世界基本特征；

文明因多样而交流，因交流而互鉴，因互鉴而发展；

不同文明没有高低优劣之分；

文明差异不应成为冲突根源，而应成为文明进步动力。

这道题答案是：

**ABCD**。

这道真题实际上把这一章一个非常典型的命题逻辑体现出来了：

> **文明多样 ≠ 文明冲突**。

正确关系是：

**尊重差异 → 交流 → 互鉴 → 共同发展**。

## 二十六、参与全球治理体系改革和建设

构建人类命运共同体不能只停留在理念上，还必须落实到全球治理。

《精讲精练》指出：

**推进全球治理体系改革和建设，是完善全球治理、增进世界各国人民福祉的客观要求，也是构建人类命运共同体的内在要求**。

政治考点资料进一步给出：

坚持：

**共商、共建、共享**

的全球治理观。

并且坚定维护：

**以联合国为核心的国际体系**，

以及：

**以国际法为基础的国际秩序**。

目标不是另起炉灶，而是推动全球治理体系：

**朝着更加公正合理的方向发展**。

所以看到：

“中国要完全推翻现行国际体系”

通常就是错误项。

## 二十七、高质量共建“一带一路”

这是构建人类命运共同体从“理念”走向“实践”的重要抓手。

必须记两个定位：

**共建“一带一路”是中国与世界实现开放共赢路径的顶层设计**；

**是推动构建人类命运共同体的实践平台**。

其次记三句话：

**根植历史、更面向未来**；

**源于中国、更属于世界**；

**追求的是发展，崇尚的是共赢，传递的是希望**。

这几个原句特别适合出多选题。

## 二十八、27版肖1000已经怎样考这一章？

现有资料里的新题库直接安排了两道题。

第一题问“走和平发展道路”的判断，其中：

A. 由中国共产党性质宗旨和社会主义制度决定；

B. 基于中国历史文化传统；

C. 是新时代对外工作的总目标；

D. 符合历史潮流、顺应世界大势。

正确答案：

**ABD**。

为什么C错？

因为：

**和平发展道路 = 新时代中国外交基本原则**；

而：

**构建人类命运共同体 = 新时代对外工作总目标**。

这就是本章最典型的“张冠李戴”。

第二题问“一带一路”，四个选项分别是：

顶层设计、实践平台、根植历史源于中国、追求发展共赢希望。

答案：

**ABCD**。

所以从肖1000的出题方式看，本章首先必须把各种“定位词”分清。

## 二十九、政治考点资料中的“五条实践路径”

可以直接串成：

**和平、发展、安全、文明、治理**。

对应关系如下：

| 路径 | 核心要求                      |
| -- | ------------------------- |
| 和平 | 走和平发展道路，推动构建新型国际关系        |
| 发展 | 坚持互利共赢开放战略，推动全球发展更加平衡协调包容 |
| 安全 | 坚持共同、综合、合作、可持续的安全观        |
| 文明 | 坚持文明交流互鉴                  |
| 治理 | 坚持共商共建共享的全球治理观            |

这是理解“人类命运共同体”的最好框架。

也就是说：

**人类命运共同体不是一句口号，而是分别从和平、发展、安全、文明、治理五个领域提出解决方案**。

## 三十一、把整章真正理解成一条因果链

如果不想死背，可以用下面的逻辑记。

**第一层：现实**。

世界正在经历：

> 百年未有之大变局。

国际力量、科技、国际体系都在变化，全球性风险越来越突出。

↓

**第二层：中国的选择**。

中国不走“国强必霸”式道路，而是：

> 中国特色大国外交。

主线：

> 服务民族复兴、促进人类进步。

↓

**第三层：中国怎么做**。

基本原则：

> 和平发展。

国家关系：

> 相互尊重、公平正义、合作共赢。

同时：

> 坚定维护国家主权、安全、发展利益。

↓

**第四层：世界怎么办**。

各国不能零和博弈，而要：

> 构建人类命运共同体。

↓

**第五层：最后建设什么**？

建设：

> **持久和平、普遍安全、共同繁荣、开放包容、清洁美丽的世界**。

因此整个第16章实际上是在回答一个非常大的问题：

> **在世界百年变局中，一个不断发展壮大的中国如何处理自己与世界的关系**？

教材给出的答案就是：

**既坚定维护中国自身发展利益，又坚持和平发展、合作共赢；既服务中华民族伟大复兴，又促进人类进步；最终推动构建人类命运共同体**。

## 三十二、本章考研复习优先级

结合《精讲精练》、真题和题库，复习第16章时不用平均用力。资料目前明确收录的本章经典真题是**2022年第26题文明交流互鉴多选题**，而新题库又直接考查“和平发展道路”和“一带一路”，因此本章特别适合以**选择题关键词辨析**为主。

最优先掌握的是：

**第一梯队：必须背准**

“总目标”“基本原则”“出发点和落脚点”“宗旨”“主线”，以及新型国际关系三个原则、“五个世界”、全人类共同价值、“一带一路”两个定位。

**第二梯队：容易配对考**

大国、周边、发展中国家、政党关系分别对应的外交理念。

**第三梯队：理解型**

百年未有之大变局、文明多样性、全球治理、人类命运共同体为什么提出。

如果这三层吃透，第16章大多数选择题都可以解决。
