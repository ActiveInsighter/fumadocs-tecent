## 一、先用一句话搞懂整章在讲什么

可以先记成：

> **在半殖民地半封建的中国，由无产阶级领导人民大众，反对帝国主义、封建主义和官僚资本主义；不照搬俄国城市起义道路，而走农村包围城市、武装夺取政权的道路；依靠统一战线、武装斗争、党的建设三大法宝，完成新民主主义革命，为向社会主义革命转变创造条件**。

这句话已经包含了整章绝大多数核心考点。

进一步对应：

| 问题       | 本章答案                   |
| -------- | ---------------------- |
| 为什么革命？   | 半殖民地半封建社会的基本国情和社会矛盾    |
| 革谁？      | 帝国主义、封建主义、官僚资本主义       |
| 靠谁？      | 无产阶级、农民、城市小资产阶级、民族资产阶级 |
| 谁领导？     | 无产阶级及其先锋队中国共产党         |
| 革命是什么性质？ | 新式的、特殊的资产阶级民主主义革命      |
| 革命前途是什么？ | 社会主义                   |
| 成功后建立什么？ | 新民主主义共和国及相应政治、经济、文化制度  |
| 怎么取得胜利？  | 农村包围城市、武装夺取政权          |
| 靠什么保证胜利？ | 统一战线、武装斗争、党的建设         |

下面逐层展开。

## 二、新民主主义革命理论为什么会产生？

这是整个第二章的逻辑起点。

### 1. 第一前提：先认清近代中国的国情

资料强调：

**认清中国国情，是认清和解决中国革命问题的基本依据**。

而近代中国最基本的国情是：

**半殖民地半封建社会**。

在这个社会中，最重要的两对矛盾是：

| 主要矛盾         | 地位         |
| ------------ | ---------- |
| 帝国主义和中华民族的矛盾 | **最主要的矛盾** |
| 封建主义和人民大众的矛盾 | 另一主要矛盾     |

正是这个国情和矛盾结构，决定了中国革命首先不是去解决一般资本主义社会里“无产阶级和资产阶级”的矛盾，而是要解决民族独立和人民解放问题。

因此近代中国革命的根本任务，就是推翻**帝国主义、封建主义和官僚资本主义**的统治，改变阻碍生产力发展的社会关系，为国家独立、人民当家作主和社会发展扫清障碍。

这里有一个很重要的因果链：

**社会性质 → 社会主要矛盾 → 革命任务 → 革命性质**。

也就是：

> 半殖民地半封建
> ↓
> 民族矛盾、封建压迫
> ↓
> 反帝反封建
> ↓
> 首先属于资产阶级民主革命，而不是社会主义革命

这条链特别重要。

## 三、为什么叫“新”民主主义革命？

很多人最容易在这里混乱：

**既然中国共产党领导，为什么革命性质不是社会主义革命**？

这是第二章的核心难点之一。

### 1. 旧民主主义革命和新民主主义革命，性质其实属于同一大类

二者首先都是：

**资产阶级民主主义革命**。

因为它们首先都要解决反帝反封建等民主革命任务，而不是直接消灭整个资本主义制度。

“新”并不是说革命性质一下子变成了社会主义革命，而是它已经成为一种**新式的、特殊的资产阶级民主主义革命**。

资料明确提醒：不要因为新民主主义革命已经属于世界无产阶级社会主义革命的一部分，就误认为它本身是社会主义革命。

### 2. “新”到底新在哪里？

核心区别可以这样看：

| 比较     | 旧民主主义革命      | 新民主主义革命          |
| ------ | ------------ | ---------------- |
| 领导阶级   | 资产阶级         | **无产阶级及其政党**     |
| 指导思想   | 资产阶级民主思想等    | **马克思列宁主义**      |
| 世界革命范畴 | 旧的世界资产阶级民主革命 | 世界无产阶级社会主义革命的一部分 |
| 革命前途   | 资本主义         | **社会主义**         |

其中最重要的是：

> **区别新旧民主主义革命的根本标志，是革命领导权掌握在无产阶级还是资产阶级手中**。

不是革命对象。

不是革命性质。

不是是不是有农民参加。

而是**领导权**。

## 四、新民主主义革命从什么时候开始？

这里要把“十月革命”和“五四运动”分清。

俄国十月革命胜利之后，中国革命的国际时代背景发生重大变化，中国的资产阶级民主革命开始成为世界无产阶级社会主义革命的一部分。

而：

> **五四运动标志着中国新民主主义革命的开端**。

所以做题时：

| 题干问法                 | 对应答案 |
| -------------------- | ---- |
| 改变中国民主革命的时代背景、世界革命范畴 | 十月革命 |
| 中国进入新民主主义革命阶段        | 五四运动 |

## 五、新民主主义革命理论不是凭空想出来的

这是2024年真题直接考过的。

理论还有一个非常重要的来源：

**革命实践**。

旧民主主义革命一次次失败，说明过去的道路走不通；中国共产党成立以后，又经历成功、失败、再探索，才逐渐认识中国革命的规律。

所以教材的逻辑是：

**旧民主主义革命失败 → 呼唤新的革命理论**

以及：

**新民主主义革命艰辛探索 → 为新理论提供实践基础和源泉**。

2024年真题引用毛泽东所说的“两次胜利、两次失败”，考的正是这一点。正确理解是：

**马克思主义必须同中国革命具体实际相结合；党认识民主革命规律有一个过程；新民主主义革命理论是在总结正反两方面经验的基础上形成的**。

因此2024年第22题选 **BCD**，“已经完全掌握革命规律”的A太绝对。

## 六、全章最重要的一句话：新民主主义革命总路线

必须直接背下来：

> **无产阶级领导的、人民大众的、反对帝国主义、封建主义和官僚资本主义的革命**。

这句话短，但实际上把五件事全部装进去了：

**对象、动力、领导力量、性质、前途**。

### 总路线提出过程

有两个著作特别容易混：

| 时间    | 著作            | 地位                 |
| ----- | ------------- | ------------------ |
| 1939年 | 《中国革命和中国共产党》  | 提出“新民主主义的革命”的科学概念  |
| 1948年 | 《在晋绥干部会议上的讲话》 | **完整概括新民主主义革命总路线** |

为什么1948年叫“完整”？

因为革命对象中进一步明确加入了：

**官僚资本主义**。

所以真题如果问：

> “完整地提出新民主主义革命总路线和总政策的著作是什么？”

答案一定是：

《**在晋绥干部会议上的讲话**》。

这道题真题考过。

## 七、总路线第一部分：革命对象——“三座大山”

即：

**帝国主义 + 封建主义 + 官僚资本主义**。

### 1. 帝国主义——首要对象

注意关键词：

> **首要对象**

帝国主义是近代中国遭受民族压迫的重要根源，因此反帝首先解决民族独立问题。

不要看到“封建主义历史久”就选封建主义为首要对象。

考试中：

**首要对象 → 帝国主义**。

## 八、封建主义为什么也是革命对象？

封建地主阶级不仅意味着政治上的专制统治，还建立在封建土地所有制基础上。

所以反封建有政治、经济两个方面：

**经济上消灭封建土地所有制；政治上消灭封建专制统治**。

这样才能解放被土地制度束缚的广大农民和社会生产力。

这也解释了为什么后面会出现：

> **农民问题是中国革命的基本问题**。

因为中国是一个农业人口占绝大多数的国家，而封建土地制度正是压迫广大农民的核心经济基础。

## 九、为什么还要反官僚资本主义？

官僚资本主义并不是一般意义上的民族资本主义。

它具有非常特殊的性质：

依靠帝国主义，勾结封建势力，又利用国家政权形成垄断，是一种买办的、封建的国家垄断资本主义，并且成为国民党反动统治的重要经济基础，严重阻碍生产力发展。

这里会出现一个非常重要的选择题陷阱：

> 新民主主义革命反对官僚资本主义
> ≠ 新民主主义革命反对一切资本主义
> ≠ 新民主主义革命要立即消灭整个资产阶级。

实际上后面经济纲领反而明确规定：

**保护民族工商业**。

所以必须区分：

| 类型     | 新民主主义革命态度     |
| ------ | ------------- |
| 官僚资本主义 | 没收、反对         |
| 民族资本主义 | 在一定条件下保护      |
| 官僚资产阶级 | 革命对象          |
| 民族资产阶级 | 革命动力之一，同时有两面性 |

这也是理解“为什么新民主主义革命仍然是资产阶级民主革命”的关键。

## 十、总路线第二部分：革命动力——到底哪些人参加革命？

教材主要讲四种力量：

| 阶级      | 地位              |
| ------- | --------------- |
| 无产阶级    | **最基本的动力、领导力量** |
| 农民      | **主力军**         |
| 城市小资产阶级 | 可靠同盟者           |
| 民族资产阶级  | 革命动力之一，但具有两面性   |

这一块特别容易考各种“最”“基本”“主要”的匹配。

## 十一、无产阶级：最基本动力，同时还是领导力量

为什么中国无产阶级可以领导革命？

除了无产阶级的一般特点，中国无产阶级还有特殊优势：受帝国主义、封建主义、资本主义的多重压迫，因此革命性更强；产业工人相对集中，便于组织；同时又同广大农民存在天然联系，便于形成工农联盟。

但考试最重要的不是罗列优势，而是知道：

> **无产阶级领导权，是中国革命的中心问题，也是新民主主义革命理论的核心问题**。

这个表述一定要精确。

## 十二、农民：为什么重要到这种程度？

这里有三个极易混的表述：

| 说法         | 答案                |
| ---------- | ----------------- |
| 中国革命的基本问题  | **农民问题**          |
| 中国革命的主力军   | **农民**            |
| 新民主主义革命的实质 | **中国共产党领导下的农民革命** |

但是：

> **农民不是领导阶级**。

领导阶级仍然是无产阶级。

所以可以这样理解：

**人最多、出力最大的是农民；掌握方向、领导革命的是无产阶级及其政党**。

这是很多选择题故意混淆的地方。

## 十三、城市小资产阶级和民族资产阶级

城市小资产阶级包括知识分子、小商人、手工业者、自由职业者等，是无产阶级的**可靠同盟者**。

民族资产阶级则复杂得多。

它具有：

**革命性 + 妥协性**。

为什么有革命性？

因为它受到帝国主义、封建主义和官僚资本主义压迫。

为什么又有妥协性？

因为它经济力量弱，并且同封建势力、外国资本存在千丝万缕联系，同时自己也拥有私有资本。

所以它：

> 可以成为革命动力和统一战线对象，但不能成为革命领导力量。

## 十四、全章核心中的核心：无产阶级领导权

一定把下面几个概念彻底分开：

| 教材表述           | 答案                |
| -------------- | ----------------- |
| 中国革命的中心问题      | **无产阶级领导权**       |
| 新民主主义革命理论的核心问题 | **无产阶级领导权**       |
| 中国革命的基本问题      | **农民问题**          |
| 新民主主义革命的主要内容   | **没收地主土地归农民所有**   |
| 新民主主义革命的实质     | **中国共产党领导下的农民革命** |

这是本章最重要的一组辨析。

## 十五、无产阶级怎样真正实现领导权？

光说“中国共产党领导”还不够，教材进一步说明如何实现领导。

可以理解成五层保障：

| 层次   | 内容                               |
| ---- | -------------------------------- |
| 基本条件 | 带领被领导者同共同敌人斗争并取得胜利，同时给予物质利益和政治教育 |
| 关键   | 建立以**工农联盟**为基础的广泛统一战线            |
| 基本策略 | 对资产阶级坚持独立自主，实行**又联合又斗争**         |
| 坚强支柱 | 建立无产阶级领导、以农民为主体的强大革命武装           |
| 根本保证 | **加强党的建设**                       |

这其实已经把后面的“三大法宝”提前串起来了。

## 十六、新民主主义革命到底是什么性质？

这是最容易被“共产党领导”误导的一道题。

正确答案：

> **新式的、特殊的资产阶级民主主义革命**。

不是无产阶级社会主义革命。

为什么？

因为判断革命性质，关键看这个革命阶段**要完成什么社会任务**。

新民主主义革命首先解决的是：

反帝、反封建、反官僚资本主义的问题。

并没有要求立即消灭所有私有制和所有资本主义生产关系，甚至还要保护有利于国计民生的民族工商业。

所以其性质仍属于资产阶级民主革命。

## 十七、既然是资产阶级民主革命，为什么前途又是社会主义？

因为：

**革命性质 ≠ 革命前途**。

这两个概念一定分开。

新民主主义革命的性质：

> 资产阶级民主主义革命。

革命的前途：

> 社会主义。

为什么能够连接？

因为新民主主义革命内部已经存在社会主义因素，例如无产阶级领导、共产党领导、国营经济成分、没收官僚资本等。

因此经典表述是：

> **民主主义革命是社会主义革命的必要准备，社会主义革命是民主主义革命的必然趋势**。

所以中国革命是“两步走”：

**第一步：新民主主义革命**。

**第二步：社会主义革命**。

两步之间：

**既不能合并，也不能割裂**。

## 十八、“一次革命论”和“二次革命论”怎么理解？

这是非常典型的哲学式辨析题。

### “左”倾的一次革命论

它只看到了：

**民主革命和社会主义革命之间的联系**。

却忽略：

**两个革命阶段性质不同**。

于是企图“毕其功于一役”，在反帝反封建阶段就把民族资产阶级也一起作为敌人。

错误在于：

**否定革命的阶段性**。

### 右的“二次革命论”

它恰恰相反。

只看到了：

**民主革命和社会主义革命不同**。

却看不到：

**二者存在内在联系**。

于是设想民主革命完成后，要先建立长期的资产阶级共和国，再等很久以后搞社会主义革命。

结果实际上会放弃无产阶级对民主革命的领导权。

所以考试可以记成：

> “**一次革命论”——只看联系，不看区别**。

> “**二次革命论”——只看区别，不看联系**。

## 十九、新民主主义革命成功以后，到底要建设一个什么社会？

这就进入：

## 基本纲领

总路线说明：

**革命是怎么一回事**。

基本纲领则进一步说明：

**革命成功以后具体要建立什么政治、经济、文化制度**。

因此教材说：

> **基本纲领是总路线的进一步展开和体现**。

## 二十、政治纲领

核心表述：

> **推翻帝国主义和封建主义的统治，建立一个无产阶级领导的、以工农联盟为基础的、各革命阶级联合专政的新民主主义共和国**。

其中国体可以理解为：

**各革命阶级联合专政**。

政权并不是资产阶级一个阶级专政，也不是当时直接建立单一的无产阶级专政，而是由参加革命的各革命阶级联合起来。

相应政体是：

**民主集中制的人民代表大会制度**。

## 二十一、经济纲领——极高频

经济纲领有三句话，必须逐字熟悉：

| 经济纲领                    | 考试定位                     |
| ----------------------- | ------------------------ |
| 没收封建地主阶级的土地归农民所有        | **新民主主义革命的主要内容**         |
| 没收官僚资产阶级的垄断资本归新民主主义国家所有 | **具有新民主主义革命和社会主义革命双重性质** |
| 保护民族工商业                 | **新民主主义经济纲领中极具特色的内容**    |

### 为什么“土地归农民”是主要内容？

因为中国革命的基本问题是农民问题。

而农民问题的核心又是：

**土地问题**。

要真正发动中国人口最多的农民参加革命，就必须解决封建地主土地所有制问题。

所以：

> **农民问题是基本问题**。

> **土地革命是解决农民问题的重要内容**。

> **没收封建地主土地归农民所有，是新民主主义革命的主要内容**。

## 二十二、没收官僚资本为什么有“双重性质”？

这是选择题常客。

一方面，官僚资本是国民党反动政权的重要经济基础，所以没收官僚资本属于打击革命对象，是完成民主革命任务的一部分。

另一方面，大规模官僚资本被没收以后转变成国家所有，又形成了社会主义性质的国营经济因素。

所以它兼有：

**新民主主义革命性质 + 社会主义革命性质**。

因此称：

> **双重性质**。

## 二十三、为什么还要“保护民族工商业”？

这句话第一次学很容易觉得奇怪：

共产党领导革命，怎么还保护私人资本主义？

因为此时革命仍然是：

**新民主主义革命**。

不是立即全面消灭资本主义的社会主义革命。

中国当时生产力水平十分落后，只要民族资本主义有利于国计民生、没有操纵国计民生，它在一定阶段仍有利于发展生产力。

而民族资产阶级在反帝反封建方面也具有一定革命性。

所以：

> 反对官僚资本主义，不等于反对一切资本主义。

这个辨析特别重要。肖1000题目也专门围绕这一点设置选项。

## 二十四、文化纲领——“民族的、科学的、大众的”

新民主主义文化是：

> **无产阶级领导的人民大众的反帝反封建的文化，即民族的、科学的、大众的文化**。

三个词不是三个漂亮口号，而分别有准确含义：

| 特征  | 含义                                           |
| --- | -------------------------------------------- |
| 民族的 | 内容上反对帝国主义压迫，维护民族独立；形式上具有中国风格、中国气派，同时吸收外国进步文化 |
| 科学的 | 反对封建思想和迷信，主张实事求是、客观真理、理论联系实际                 |
| 大众的 | 为广大工人阶级和劳动群众服务，文化既要普及于群众又要提高群众               |

这里特别容易出现：

“民族的”是不是拒绝外国文化？

**不是**。

它反对的是帝国主义文化压迫，不是拒绝人类文明优秀成果。

## 二十五、本章第二个超级重点：为什么中国必须走农村包围城市道路？

这就是新民主主义革命理论最具有“中国特色”的地方之一。

马克思、列宁并没有直接给中国写好一个“中国革命操作手册”。

俄国十月革命大体上是：

**城市起义 → 夺取中心城市 → 向全国扩展**。

中国共产党成立初期也曾把工作重点主要放在城市。

但1927年大革命失败后，一系列以占领城市为目标的革命斗争遭遇挫折，事实逐渐说明：

> **俄国道路不能机械照搬到中国**。

大革命失败以后，党的工作重心逐步向农村转移；秋收起义以后，毛泽东率部走向井冈山，开始在农村建立革命根据地。相关实践逐渐形成了农村包围城市、武装夺取政权的理论。

## 二十六、农村包围城市道路的理论形成

重要著作要建立时间联系：

| 时间    | 著作                | 作用                   |
| ----- | ----------------- | -------------------- |
| 1928年 | 《中国的红色政权为什么能够存在？》 | 分析红色政权存在发展的条件        |
| 1928年 | 《井冈山的斗争》          | 总结井冈山斗争实践            |
| 1930年 | 《星星之火，可以燎原》       | 进一步阐明农村红色政权和全国革命高潮关系 |
| 1930年 | 《反对本本主义》          | 强调调查研究、中国革命必须了解中国情况  |

这一系列探索逐渐形成：

**工农武装割据思想**

和：

**农村包围城市、武装夺取政权道路理论**。

这个理论的形成标志着毛泽东思想的**初步形成**。

所以要和第一章串起来：

**毛泽东思想初步形成的标志 → 农村包围城市、武装夺取政权理论形成**。

**毛泽东思想成熟的标志 → 新民主主义革命理论得到系统阐述**。

两者不要混。

## 二十七、为什么中国必须“农村包围城市”？

可以从中国国情理解。

首先，中国：

**内无民主制度，外无民族独立**。

反动统治主要依靠武装力量维持，所以共产党不可能像资本主义民主国家政党那样仅靠长期合法议会斗争取得政权。

因此革命的主要形式必须是：

**武装斗争**。

其次，中国是农业大国，农民人口占绝大多数，而农民又是革命主力军，所以革命不可能离开农村。

再次，反动统治在中心城市最强，广大农村相对是统治薄弱区域。

最后，中国政治经济发展极端不平衡，使一些地区能够出现和长期存在农村红色政权。

2011年真题直接问过：

> 农村革命根据地能够长期存在发展的**根本原因**是什么？

对应：

**中国是政治、经济、文化发展极不平衡的半殖民地半封建大国**。

所以看到“根本原因”，优先想到：

> **政治经济发展不平衡**。

## 二十八、农村根据地能够存在，还有哪些条件？

教材把条件大致分成客观和主观。

| 类型     | 条件                     |
| ------ | ---------------------- |
| 客观根本条件 | 中国政治经济发展不平衡            |
| 客观条件   | 某些地区群众革命基础好、全国革命形势继续发展 |
| 主观条件   | 相当力量的正式红军存在            |
| 主观条件   | 共产党的领导以及正确政策           |

所以如果题目不是问“根本原因”，而是问“能够存在发展的条件”，往往就是多项。

2010年真题又把道路依据概括成：中国内无民主、外无独立；农民占绝大多数；反动派力量集中城市、农村相对薄弱；政治经济发展不平衡。

## 二十九、“工农武装割据”到底是什么？

又一个必考辨析。

它的核心是三者统一：

> **土地革命 + 武装斗争 + 农村革命根据地建设**。

但是三者地位不同：

| 内容      | 定位       |
| ------- | -------- |
| 土地革命    | **基本内容** |
| 武装斗争    | **主要形式** |
| 农村革命根据地 | **战略阵地** |

理解起来非常简单：

**土地革命**解决“为什么农民跟着共产党革命”的问题。

**武装斗争**解决“用什么力量保卫革命成果”的问题。

**根据地建设**解决“革命力量在哪里生存、发展、壮大”的问题。

所以三者缺一不可。

不是“只要打仗”。

也不是“只在农村分土地”。

而是在党的领导下，把三者结合起来。

## 三十、武装斗争的实质是什么？

2018年真题直接考过：

> 中国新民主主义革命中的武装斗争，本质上是什么？

答案：

**工人阶级领导的农民战争**。

为什么？

因为：

领导力量是无产阶级；

军队和革命群众的主要社会基础则是广大农民。

于是形成：

**无产阶级领导 + 农民主体**。

## 三十一、不要把“工农武装割据三要素”和“三大法宝”混了

这是全章非常经典的陷阱：

| 名称          | 内容                        |
| ----------- | ------------------------- |
| 工农武装割据的三个方面 | **土地革命、武装斗争、农村革命根据地建设**   |
| 新民主主义革命三大法宝 | **统一战线、武装斗争、党的建设**        |
| 党的三大优良作风    | **理论联系实际、密切联系群众、批评与自我批评** |
| 毛泽东思想活的灵魂   | **实事求是、群众路线、独立自主**        |

四组三个词，考试特别喜欢串换。

## 三十二、新民主主义革命三大法宝

必须背：

> **统一战线、武装斗争、党的建设**。

毛泽东在《〈共产党人〉发刊词》中总结了这三大法宝；后来又在《论人民民主专政》中集中总结革命经验。政治考点资料也专门将其作为本章背诵重点。

为了理解，可以把三者分别看作：

**统一战线——团结谁**。

**武装斗争——怎么打**。

**党的建设——谁来保证方向正确**。

## 三十三、第一大法宝：统一战线

为什么中国革命特别需要统一战线？

因为近代中国的阶级结构具有：

> “**两头小，中间大**”

的特点。

“两头”主要是：

一头是人数较少但掌握统治权的地主阶级、大资产阶级；

另一头是人数较少但革命性很强的无产阶级。

中间则是广大的农民、小资产阶级、民族资产阶级等。

仅靠人数有限的无产阶级自身，无法完成反对强大敌人的革命任务。

同时，中国革命具有长期性、残酷性、不平衡性，也要求尽可能联合一切能够联合的力量。

## 三十四、统一战线里有两个联盟

这是高频。

| 联盟                            | 地位                   |
| ----------------------------- | -------------------- |
| 工人阶级同农民、知识分子及其他劳动者的联盟，主要是工农联盟 | **基本的、主要的，是统一战线的基础** |
| 工人阶级同非劳动人民的联盟，主要是同民族资产阶级的联盟   | 非基本、辅助性的，但重要且不可缺少    |

因此如果题目问：

> 新民主主义革命统一战线中基本的、主要的联盟是什么？

答案：

**工农联盟为主体的劳动者联盟**。

不是民族资产阶级联盟。

## 三十五、共产党怎样处理和民族资产阶级的关系？

不是简单地：

“联合。”

也不是简单地：

“斗争。”

而是：

> **又联合又斗争**。

因为民族资产阶级本身就具有两面性。

同时必须：

**坚持独立自主**。

不能因为组成统一战线，就放弃共产党在政治、思想和组织上的独立性。

抗日统一战线时期又形成：

> **发展进步势力、争取中间势力、孤立顽固势力**。

这些都是统一战线部分常见选项。

## 三十六、第二大法宝：武装斗争

为什么革命必须主要依靠武装斗争，前面已经讲过：

中国“内无民主、外无独立”，反动统治依靠军事力量维持，因此必须：

> **以武装的革命反对武装的反革命**。

但“武装斗争”不是单纯军事技术问题，它还涉及建设什么样的军队。

其中最重要的几个关键词是：

| 问题            | 答案                  |
| ------------- | ------------------- |
| 建设新型人民军队的根本原则 | **党对军队的绝对领导**       |
| 毛泽东建军思想的核心    | **党对军队的绝对领导**       |
| 人民军队唯一宗旨      | **全心全意为人民服务**       |
| 政治工作重要原则      | 官兵一致、军民一致、瓦解敌军和优待俘虏 |

这里与史纲中的古田会议可以连起来理解：

1929年古田会议确立了：

**思想建党、政治建军原则**。

它解决了在农村环境、党员和军队成员大量来自农民的情况下，怎样保持党的无产阶级先锋队性质、建设党领导的新型人民军队的问题。

## 三十七、第三大法宝：党的建设

为什么党的建设在中国革命中特别重要？

因为中国共产党是在一个农民人口占绝大多数、长期处于农村革命战争环境中的国家发展起来的。

党内大量党员出身于农民和小资产阶级。

因此：

**党员的阶级出身可以发生变化，但必须用无产阶级思想改造各种非无产阶级思想**。

所以党的建设中：

> **思想建设放在首位**。

同时组织上实行：

**民主集中制**。

作风建设形成：

**理论联系实际、密切联系群众、批评与自我批评**。

这就是著名的：

> **党的三大优良作风**。

再次强调：

“党的三大优良作风”

不是“三大法宝”。

## 三十八、这三大法宝到底如何联系起来？

为了做题，可以理解成一个革命运行系统：

| 问题                | 对应法宝 |
| ----------------- | ---- |
| 谁可以团结起来一起革命？      | 统一战线 |
| 用什么方式战胜武装的敌人？     | 武装斗争 |
| 谁保证统一战线和武装斗争方向正确？ | 党的建设 |

所以三大法宝不是三个孤立知识点，而是中国革命的三方面基本经验。

## 三十九、新民主主义革命理论的历史意义

资料把这一部分概括得比较集中。

新民主主义革命理论解决了：

**在一个半殖民地半封建的东方大国究竟怎样进行革命的问题**。

它揭示了近代中国革命规律，形成了具有中国特点的一整套革命理论；同时创造性地发展了马克思主义革命理论，丰富了马克思主义理论宝库，是马克思主义中国化时代化的重要成果，并为马克思主义中国化时代化开辟了发展道路。

从毛泽东思想发展史看，这一章还有一个非常重要的地位：

> **新民主主义革命理论的系统阐明，是毛泽东思想走向成熟的重要标志**。

而此前“农村包围城市、武装夺取政权理论”的形成，则对应毛泽东思想的**初步形成**。

## 四十二、最后把整章真正“串起来”

如果你现在要脱离教材自己讲一遍第二章，可以按照下面这条逻辑讲：

中国近代成为**半殖民地半封建社会**，帝国主义和中华民族、封建主义和人民大众的矛盾决定中国首先必须进行反帝反封建的民主革命。但旧民主主义革命没有解决中国问题，十月革命和五四运动又改变了中国革命的时代条件，于是中国进入由无产阶级领导的**新民主主义革命**阶段。

新民主主义革命的总路线，就是：

> **无产阶级领导的、人民大众的、反对帝国主义、封建主义和官僚资本主义的革命**。

其中，**无产阶级领导权**既是中国革命的中心问题，又是新民主主义革命理论的核心问题；**农民问题**是中国革命的基本问题，农民是革命主力军。

革命性质仍然是**新式、特殊的资产阶级民主主义革命**，但它的前途是社会主义。因此新民主主义革命和社会主义革命既有区别又有联系：前者是后者的**必要准备**，后者是前者的**必然趋势**。

革命胜利后，在政治上要建立各革命阶级联合专政的新民主主义共和国；经济上实行**土地归农民、官僚资本归国家、保护民族工商业**；文化上建设**民族的、科学的、大众的文化**。

由于中国特殊国情，不能照搬俄国城市革命模式，而必须走：

> **农村包围城市、武装夺取政权**。

其实践结构是：

> **土地革命 + 武装斗争 + 农村革命根据地**。

最后，中国共产党总结革命成功的三大基本经验：

> **统一战线 + 武装斗争 + 党的建设**。
